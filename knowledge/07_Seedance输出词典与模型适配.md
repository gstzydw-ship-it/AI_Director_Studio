# 第一部分：Seedance中文短句输出词典

日期：2026-04-09  
版本：v5.4-image-only-style-anchor  
用途：用于约束最终输出语言，使结果呈现为结构化、可执行、适配 Seedance 参考图模式的中文导演 prompt，而不是过短碎片词串、分析说明或分镜审稿稿。

---

## 一、总原则
最终输出必须像"导演编译结果"，不是"解释过程"。  
最终 Seedance prompt 不得过短，不得只写标签式短词串，也不得写成分析说明或教学话术。

一句话要求：  
**结构化、中等长度、信息密度高、层级清楚、镜头内完成、分镜基底明确、参考锚点明确、约束可执行。**

---

## 二、输出目标

### 规则 01：最终输出应像可直接执行的导演 prompt
最终 Seedance prompt 要能直接承载：
- 场面空间
- 人物位置
- 动作推进
- 台词落点
- 主分镜切换
- 同一主分镜内部的子分镜变化
- 表情细节
- 光线关系
- 连续性约束
- 参考图继承关系

因此不再追求"越短越好"。  
应优先追求：
- 结构清楚
- 句子完整
- 信息足够
- 可直接执行
- 参考调用明确
- 每段都能看出是怎么拍

### 规则 02：纯编译模式的标准层级
纯编译 / Seedance 模式下，默认按以下顺序输出：
1. 角色参考总控（如用户上传了人物参考图）
2. 空间与首帧总控（如用户上传了位置图、场景图或上一镜尾帧静帧）
3. 风格锚点（如用户单独提供了画风）
4. 时间轴
5. 约束
6. 参考调用

### 规则 03：单独片段时间轴从 0 秒开始
若当前任务是单独片段生成，时间轴一律从 `0秒` 开始。  
只有当用户明确要求"整场连续时间轴"时，才允许使用整场绝对秒数。

### 规则 03-1：最终句子的隐性组织顺序
每个时间段内部，默认优先自然覆盖以下顺序：  
主体分镜基底 → 主动作 → 场景 / 空间 → 光线 → 台词 / 受击 → 镜头内推进 → 风格 → 约束

这里的"主体分镜基底"指：
- 当前主体是谁
- 当前景别是什么
- 机位高度是什么
- 拍摄角度是什么
- 当前以固定、跟拍、推近、横移、摇摄或其他哪种镜头基底进入

注意：
- 这是内部组织顺序，不是让你把它们写成表单；
- 必须写成自然中文完整句；
- 缺失其中个别维度时，只写必要部分，不要硬凑；
- 但不能把动作放在最前面，让分镜信息拖到句尾才补。

### 规则 03-2：长度以"中等、够用、可执行"为准
单个时间段不要短到只剩标签词，也不要长到堆满无效修辞。  
默认优先：
- 避免低于 30 个字就匆忙结束
- 避免超过 200 个字还在堆叠同义形容
- 让每一句都承担画面功能

## 三、角色参考总控写法（仅参考图）

### 规则 04：人物参考图先绑定，再进入时间轴
若用户上传了人物参考图，先在最前面输出角色参考总控。  
角色参考总控只负责固定：
- 人物身份
- 五官
- 发型
- 体态
- 服装一致性
- 年龄感与气质基底

推荐写法：
- `@图片1 徐斯礼人物参考，仅用于徐斯礼的人物身份、五官、发型、身形、服装一致性。`
- `@图片2 时知渺人物参考，仅用于时知渺的人物身份、五官、发型、体态、服装一致性。`

### 规则 05：人物参考图不得污染场景主体
人物参考图只负责角色本体，不负责场景背景。  
不得把人物参考图的背景直接带入场景主体，也不得把人物参考图的色调错误覆盖到全场光线。

### 规则 05-1：参考图数量控制
只有参考图时，优先控制在 3—5 张核心图内完成绑定，通常按以下顺序选：
1. 主角身份图
2. 对手角色身份图
3. 所有人位置关系图
4. 场景空间图
5. 上一镜尾帧静帧（若有）

不要为了"更稳"而无节制堆图。

## 四、空间与首帧总控写法

### 规则 06：空间与首帧总控放在时间轴之前
空间与首帧总控只用于建立：
- 人物相对位置
- 场面轴线
- 关键空间锚点
- 首帧继承关系
- 主要光线关系
- 参考图继承关系

空间与首帧总控：
- 不写时间码
- 不写成单独分镜
- 不承担具体动作节拍

### 规则 07：首帧继承优先级
首帧继承优先级固定为：
1. `@上一镜尾帧静帧`
2. `@所有人位置关系图 / 空间总控图`
3. 当前场景参考图

若用户上传了上一镜尾帧静帧，优先继承该静帧的：
- 首帧构图
- 人物朝向
- 镜头连续性
- 空间逻辑
- 光线基底
- 已成立的微小状态

若无上一镜尾帧静帧，则继承空间总控图 / 所有人位置关系图。

### 规则 07-1：尾帧静帧只服务续接生成，不反向改拆片
若 `@上一镜尾帧静帧` 是在上一片段生成后补充进入当前任务，它只负责下一片段的：
- 首帧构图继承
- 人物朝向继承
- 镜头连续性继承
- 空间逻辑继承
- 光线基底继承
- 已成立微小状态继承

它不负责：
- 改写已确定的时间轴边界
- 重算下一片段起止点
- 触发新的主分镜重划分
- 反向打散已成立的完整发言单元

默认工作流应为：
先锁定拆片骨架，再用尾帧静帧续接生成。除非用户明确要求重新拆片，否则不得回改既定片段结构。

### 规则 07-2：尾帧图优先于文字复述
当存在上一段尾帧图时，最终 Seedance prompt 应把尾帧图作为最高优先级首帧与场景锚点，而不是把尾帧分析报告改写成长篇场景描述。

推荐写法：
- `@图片N（上一段尾帧图）作为本段首帧、场景、构图、光线和空间锚点，直接从图中状态继续。`
- `@图片N（上一段尾帧图）同时作为本段场景参考；不再重复调用单独场景参考图。`

只补充图像不容易稳定传达但影响动作执行的必要状态：
- 人物面朝方向
- 手中道具
- 身体接触
- 门/车门是否开合
- 当前戏份人物与退场人物

不要写：
- 长篇复述尾帧里的窗、门、沙发、灯光、地面纹理
- 同时调用尾帧图和重复场景参考图
- 把尾帧分析报告逐字塞进【空间与首帧总控】

原则：尾帧图负责“长相、场景、构图、光线、首帧状态”；文字负责“从尾帧之后发生的新动作”。

### 规则 08：场景参考图只负责环境与空间
场景参考图只负责：
- 空间关系
- 场面轴线
- 环境纹理
- 首帧构图
- 光线基底

不得把场景参考图的环境纹理错误覆盖到人物脸部或服装上。

## 五、时间轴写法

### 规则 09：时间轴外层仍以主分镜为段落单位
每个时间段优先对应一个主分镜。  
主分镜段落都要写清：
- 当前戏剧任务
- 当前主体
- 当前动作段
- 当前主要台词（如有）
- 当前主要镜头组织方式
- 当前主要空间关系
- 当前主要光线与氛围

### 规则 09-1：每个时间段必须先起一个分镜基底
每个时间段的第一句或第一分句，必须先让人看见"这是怎么拍的"，再进入动作。
至少应明确以下四项中的三项：
- 主体景别
- 机位高度
- 拍摄角度
- 镜头运动方式

若当前段更适合静态观察，也必须明确写出：
- 固定机位
- 稳定观察
- 守住双人关系镜头
- 越肩观察
- 正反打中的哪一侧仍在成立

错误方向：
- `商北琛迈步走进大堂……镜头稳定后退并轻微横移`
- `乔熙抬头愣住……镜头随后切近`

正确方向：
- `商北琛中景，平视 3/4 角度，稳定后退跟拍，他迈步走进大堂……`
- `乔熙胸部以上中近景，平视，轻微推近，她抬头愣住……`

### 规则 10：同一时间段内部自然写子分镜变化
若同一主分镜内部需要景别变化、信息炸点重音、受击者反应或局部动作落点，可在该时间段内部自然写出变化。  
子分镜只负责：
- 切近
- 切特写
- 切受击者
- 切局部动作
- 切表情重音

不应把子分镜变化机械拆成新的时间轴主段。  
也不应在纯编译模式下显式写成"子分镜 2.1 / 2.2"的教学标签。

### 规则 10-1：工作流为"先出上一段，再接下一段"时，拆片边界保持锁定
若当前轮是在上一片段生成完成后，用户补充尾帧静帧要求继续生成下一片段，则时间轴仍沿用已确定的下一片段边界与主分镜骨架；  
尾帧静帧只负责把下一片段接得更顺，不负责重新决定"第二段从哪开始、到哪结束"。

### 规则 10-1-1：状态合同必须被翻译进最终 Prompt
如果上游提供 `active_cast / offscreen_cast / state_contract`，最终 prompt 必须显式执行：
- `active_cast` 决定时间轴中可见人物，不得额外增加尾帧人物。
- `offscreen_cast` 决定哪些人物不再出现，可在【约束】中负绑定。
- `entry_state` 写进【空间与首帧总控】。
- `object_state_transitions` 写进【时间轴】，并保持单向变化。
- `exit_state` 写进尾段或【约束】，作为下一段尾帧锚点。
- `forbidden_continuity` 写进【约束】，禁止人物复活、门状态回弹、道具重置。

不要把状态合同改写成含混形容词。状态合同是执行边界，不是氛围建议。

### 规则 10-2：含对白必须禁止字幕与屏幕文字
Seedance prompt 中只要嵌入台词，就必须在【约束】段明确写：
- 禁止字幕
- 禁止屏幕文字
- 禁止英文字幕
- 禁止文字浮层
- 台词只作为声音或口型存在

不要写“字幕显示”“画面出现文字”“英文字幕”等会诱发模型生成文字的表达。  
如果需要台词落点，直接写人物说出口型与声音，不让文字出现在画面中。

### 规则 10-3：门缝/电梯口写法要避免状态回弹
电梯口、房门口、车门口的 Seedance prompt 应用连续物理状态写法：
- `电梯门尚未合拢，门缝仍够一人侧身进入。`
- `乔熙从将合未合的门缝冲入，身体短促挡住门缝。`
- `她进入后，门页继续向中间合拢。`

不要写：
- `电梯门重新打开`
- `门缝被冲开`
- `门已经收窄到一人宽后又被推开`
- `商北琛已进入电梯后，门又打开`

### 规则 10-4：尾帧人物的负绑定写法
如果上一段尾帧里有人物可见，但当前片段没有该人物戏份，最终 prompt 可以在【约束】里用负绑定方式处理：
- `严飞不再出现，不保留在电梯门外或侧后方。`
- `上一段中的员工只作为已结束背景，不进入本段画面。`

但不要同时写正向站位和负向禁止。  
错误：`严飞位于门外侧后方，同时禁止严飞抢画面。`  
正确：`严飞不再出现；电梯口只保留商北琛与乔熙的动作关系。`

### 规则 11：时间轴不是关键词串，也不是表单
禁止写法：
- 冷白灯，近景，悲伤，电影感，压迫，镜头推进
- 女孩A解释，时知渺震惊，特写，情绪拉满
- 主分镜 2，焦段 85mm，机位平视，景别近景，镜头切受击者

正确方向：
- 用完整中文句把主体、动作、空间、光线、镜头与落点写在一起；
- 让镜头变化体现在自然句里，而不是体现在技术表头里；
- 但每个时间段起手必须先给分镜基底。

### 规则 11-1：一镜一主动作
一个时间段里只能有一个主驱动动作。  
其他动作只能作为：
- 承接动作
- 表情反应
- 视线变化
- 局部动作落点  
不能把"起身、奔跑、回头、挥手、推门、坐下、抢东西"并列塞进同一句主镜头里。

### 规则 11-2：同句多人时不用歧义代词
若同一句内出现两个以上可被"她 / 他"指代的人物，后续动作必须重复写角色名，不用代词承接。  
避免模型把动作错误分配给最近人物。

### 规则 11-3：关键动作后补表情锚点
时间轴不能只写功能动作。  
凡关键动作、羞辱点、反转点、信息炸点与受击点，尽量补一个可见表情或身体反应；  
其中信息炸点、羞辱点、反转点后，必须补一个受击表情锚点。  
优先写眼神、睫毛、嘴唇、下颌、吞咽、呼吸、鼻翼、手指与肩背等可见反应，不写空泛情绪词。

### 规则 11-4：摄影机运动与主体动作分句
正确：
- `她先停住，看向对面的人；镜头缓慢推近到胸部以上。`
错误：
- `镜头跟着她猛地冲过去又突然切到她脸上。`

### 规则 11-5：运镜模态要写清
时间轴中出现运镜时，应尽量让模型直接看懂是哪一类动作：
- 推镜：机位物理推进
- 变焦：焦距变化
- 横移：机位平移
- 摇摄：机位固定扫视
- 俯仰：机位固定上下调整

不要把它们写成一个模糊混合词团。

### 规则 11-6：分镜基底不是教学标签，而是自然起手句
不要写：
- `主分镜 1：商北琛中景……`
- `镜头参数：中景，平视，3/4 角度……`

要写成：
- `商北琛中景，平视 3/4 角度，稳定后退跟拍，他迈步走进大堂……`
- `商北琛中近景，严飞只在右前方边线形成轻虚侧前景，半侧身让出中轴说话，商北琛视线越过他……`

## 六、约束与参考调用

### 规则 12：约束段只管逻辑，不管镜头
约束段负责防止模型在物理和逻辑连贯性上跑偏。
**【最高禁令】**：约束条款内**严禁对镜头、运镜、主体焦点锁定做出任何约束**！所有的切镜、运镜、焦点切换必须且只能在【时间轴】中由分镜控制，绝对禁止在约束段写“锁定主体为A”、“B不抢中心”、“镜头保持稳定”等词，这会直接凌驾于导演的切镜规则之上并吃掉动作。

约束段**只能写**以下容易出现逻辑错误的内容：
- 服装、发型特征是否要接续
- 关键道具（如手里的文件、杯子）是否必须保持可见
- 空间场景是否连续（不能跳出该房间/不能突然跳轴）
- 禁止增加剧本外的多余台词、旁白或极其夸张的演法

### 规则 13：参考调用写在最后，但不承担首次绑定
【参考调用】必须保留。  
但角色、空间与首帧继承的第一次绑定必须发生在前面的对应段落里，不得拖到结尾再第一次说明。

---

## 七、一句话总纲
**最终 Seedance prompt 不是"先把动作说完，再补一句镜头"，而是每个时间段一开头就让镜头身份成立，再让动作、台词、受击和子分镜推进接上去。**

# 第二部分：Seedance模型适配硬规则（仅参考图版）

日期：2026-04-09  
版本：v1.3  
用途：补足导演框架之外的 Seedance 模型适配层，专门解决"写得像导演，但不一定被模型稳定执行"的问题。  
适配前提：用户仅提供参考图，不提供参考音频和参考视频；允许用户先单独提供画风作为风格锚点。

---

## 一、总原则
这份文件不替代导演工作流，也不重写现有主分镜 / 子分镜体系。  
它只负责把已有导演逻辑翻译成对 Seedance 更稳定的执行写法。

一句话要求：  
**保持导演框架不动，把输出改成更容易被模型稳定解码、并且每段都先显出分镜基底的句子。**

---

## 二、默认输出顺序
最终时间段内部，默认优先自然覆盖以下顺序：
1. 主体分镜基底
2. 主动作
3. 场景 / 空间
4. 光线
5. 台词 / 受击
6. 镜头内推进
7. 风格
8. 约束

这里的"主体分镜基底"默认至少包含以下四项中的三项：
- 主体景别
- 机位高度
- 拍摄角度
- 镜头运动方式

注意：
- 这是隐性组织顺序，不是表格式字段；
- 可以在自然中文里打散，但不要丢掉主体前置原则；
- 若用户已单独提供画风，则该信息只作为【风格锚点】固定段进入最终 prompt，不得反向改写前面的导演层判断；
- 不得把动作放在最前面，让分镜信息拖到句尾才补。

---

## 三、基础硬规则

### 规则 01：主体前置
每个时间段先让模型知道"谁在画面里最重要"。  
不要先写气氛、风格、镜头参数，再迟迟不说主体是谁。

### 规则 01-1：每段先立分镜基底
每个时间段开头，必须先立当前主体的分镜基底，再进入动作。  
正确方向：
- `商北琛中景，平视 3/4 角度，稳定后退跟拍，他迈步走进大堂……`
- `乔熙胸部以上中近景，平视，轻微推近，她抬头愣住……`

错误方向：
- `商北琛迈步走进大堂……镜头稳定后退并轻微横移`
- `乔熙抬头愣住……镜头随后切近`

### 规则 01-2：静态镜头也要写清基底
若当前段更适合静态观察，也不能省略分镜基底。  
要明确写出：
- 固定机位
- 守住关系镜头
- 越肩观察
- 平视正反打中的哪一侧
- 稳定观察当前主体

### 规则 02：一镜一主动作
一个时间段只能有一个主驱动动作。  
其他信息只能作为：
- 表情承接
- 视线变化
- 局部动作
- 受击反应
- 机位调整

### 规则 03：核心角色尽量控制在 1—2 人
一个时间段若出现 3 人以上，必须写清：
- 当前主体是谁
- 其他人是对视对象、陪衬对象还是背景关系点

### 规则 04：角色称谓稳定
同一角色在同一条输出里，尽量只用一个主称谓。  
例如：
- 一直写"时知渺"
- 或一直写"女孩A"  
不要来回切成：
- 她
- 对方
- 年轻女人
- 主角

### 规则 05：摄影机运动与主体运动分句
正确：
- `她停住，眼神看向桌对面的男人；镜头缓慢推近到胸部以上。`
错误：
- `镜头跟着她停住又冲到她脸上。`

### 规则 06：中文优先
默认用自然中文。  
不要把中文 prompt 先翻成英文再硬译回中文。

### 规则 07：时间段只写可拍、可执行的动作
尽量优先写现实摄影里也能成立的动作与机位。  
越接近真实可拍，模型越稳。

---

## 四、运镜质量防火墙

### 规则 08：运镜模态必须明确区分
Seedance 对不同摄影机运动的理解并不对称，写法必须明确：
- 推镜（Dolly In）= 机位物理推进，背景透视会变化
- 变焦（Zoom In）= 焦距光学变化，机位本体不移动
- 横移（Truck）= 机位平移，透视关系随位置变化
- 摇摄（Pan）= 机位固定，只做水平扫视
- 俯仰（Tilt）= 机位固定，只做上下视角调整

### 规则 09：不要把不同模态混成一个模糊动作团
错误：
- `镜头一边推近一边变焦一边横移一边扫过去`
- `镜头快速冲过去又横扫又变焦`
正确方向：
- 先立分镜基底
- 再选主模态
- 若必须叠加，改写成时间节拍：
  `先固定；随后缓慢推近；最后轻微摇到受击者。`

### 规则 10：不要把推镜写成变焦，不要把横移写成摇摄
推镜与变焦、横移与摇摄在透视逻辑上不同。  
写混后，模型容易出现空间冲突、脸部拉扯、背景漂移或无动机跳切。

### 规则 11：运镜遵循"动静分离"
先立主体分镜基底，再写主体动作，最后写镜头如何响应。  
不要把人物运动、摄影机运动、环境变化挤成一个同时爆发的复合句。

### 规则 12：默认慢、稳、可拍
Seedance 更稳的是：
- 慢推
- 稳定平移
- 固定机位
- 轻跟随
- 受控切近
- 小幅摇摄 / 俯仰

### 规则 13：快只能快一个维度
如果必须快，只允许以下三者之一快：
- 主体动作快
- 镜头运动快
- 环境复杂

三者不得叠加。

### 规则 14：禁止三快叠加
以下组合视为高危写法：
- 快速奔跑 + 快速推拉镜 + 杂乱人群
- 快速回头 + 快速环绕 + 闪烁霓虹背景
- 剧烈打斗 + 快速横移 + 大量前景遮挡

### 规则 15：摇摄与俯仰要补稳定性约束
若使用摇摄、俯仰、扫视类运镜，建议补入：
- 平稳阻尼
- 视平线稳定
- 不突然甩动
- 不无动机漂移

### 规则 16：避免高危词团
以下表述默认视为高危，除非任务明确需要且能承受风险：
- 暴力变焦
- 极速摇摄
- 疯狂环绕
- 甩镜
- 无规则漂移
- 连续急推急拉

---

## 五、光线优先级规则

### 规则 17：光线比空泛形容词更重要
与其堆"高级感、电影感、氛围感"，不如明确写：
- 冷还是暖
- 软还是硬
- 主光来自哪里
- 是否有明显阴影
- 是否有轮廓光 / 边光 / 逆光

### 规则 18：禁止光线自相矛盾
错误：
- `平光均匀，同时强烈侧逆光切脸`
- `温柔柔光，同时高反差硬阴影`
- `自然日光，同时霓虹主导全场`

### 规则 19：风格与光线必须对上
- 审讯 / 压迫 / 都市冷感：冷色、硬光、侧逆光、阴影清楚
- 温暖 / 治愈 / 回忆：暖色、柔光、漫散射、边缘温和
- 现实纪实：自然实景灯、不过分造型、不乱加色光
- 霓虹赛博：冷蓝紫或受控霓虹，但人物皮肤不能被污染到失真

---

## 六、焦段与景深的模型表达规则

### 规则 20：技术判断可保留，最终表达优先感知语言
内部可以判断：
- 35mm
- 50mm
- 85mm
- 135mm

但最终对 Seedance 优先改写为：
- `轻广角纪实感`
- `自然视角`
- `中长焦压缩感`
- `长焦观察感`

### 规则 21：不要把精确参数当主要叙事信息
不要让 `f1.4 / T2.0 / ISO` 承担主要视觉叙事。  
优先写：
- `前后景都清楚`
- `背景退成柔虚色块`
- `前景肩线轻虚`
- `空间被压平`

---

## 七、参考图分配规则（仅参考图）

### 规则 22：只建立参考图体系
本系统默认只使用：
- 人物身份图
- 所有人位置关系图
- 场景空间图
- 上一镜尾帧静帧

### 规则 23：推荐参考图最小组合
默认最稳的最小组合：
1. 主角身份图
2. 对手角色身份图
3. 所有人位置关系图
4. 场景空间图
5. 上一镜尾帧静帧（若有）

### 规则 24：视频参考与音频参考
若系统提供了【上一段尾帧/视频分析】结果，该结果来自原生视频解析，是上一段的**实际画面记录**。
编写 Prompt 时应充分利用视频分析中的空间信息（人物最终位置、朝向、空间锚点），但最终输出优先调用 `@图片N（上一段尾帧图）` 作为首帧和场景锚点，不要把视频分析报告长篇复述进正文。

若用户未上传视频且系统没有提供视频分析结果，则不要假装存在视频参考。
用户没有给参考音频时，也不要写：
- `@音频1 同步口型`
- `如有音频则……`

### 规则 25：图像角色要写死
每张图都应在文中写明职责：
- `@图片1 仅用于主角身份锁定`
- `@图片2 仅用于对手角色身份锁定`
- `@图片3 仅用于所有人位置关系`
- `@图片4 仅用于场景空间与光线基底`
- `@上一镜尾帧静帧 仅用于首帧继承`

### 规则 26：@图片 调用要稀疏，不要密集堆叠
@图片 的高价值调用只出现在：
- 角色参考总控
- 空间与首帧总控
- 角色第一次成为当前主体时

同一时间段或同一主分镜内反复堆叠 @图片，会让动作失去自然流动感。

---

## 八、一句话总纲
**Seedance 更稳的不是"先把动作说完再补镜头"，而是先把当前段的分镜基底立住，再让动作、台词、受击和内部推进压上去。**

# 第三部分：时间轴主体景别显式化补丁

日期：2026-04-09  
版本：v1.0  
用途：补足最终时间轴中"主体景别容易被省略"的问题；本文件不改写原导演体系，只把已有景别规则提升为最终输出层硬约束。

## 一、总原则
景别不是可选修饰，而是时间轴中的最低控制量。  
最终输出可以写成自然中文，不必表格化，但不能省略"主体+景别"。

## 二、硬规则
1. 时间轴每个时间段都必须显式出现至少一次"主体+景别"锚点。  
2. 凡出现切镜、切回、转镜、切近、切受击者、切局部，都必须写清：
   - 切到谁；
   - 对应什么景别或局部；
   - 切后具体看什么。
3. 禁止只写：
   - 镜头切回商北琛
   - 镜头更近
   - 镜头切过去
   - 镜头转到乔熙
4. 允许写法：
   - 商北琛胸部以上中近景稳稳压住画面，继续追问。
   - 镜头切至乔熙面部特写，看她把难堪硬说成武器。
   - 画面转到乔熙手指与下颌的局部特写，承接那一下停顿。
5. 景别与焦段互不替代。即使已写 50mm、85mm、浅景深、压缩感、背景虚化，也不能省略主体景别。
6. 自然中文不等于镜头信息弱化；凡镜头真正发生切换，必须在句内保留：
   - 切到谁；
   - 什么景别/局部；
   - 切后看什么。

## 三、自检
输出前至少检查：
1. 每个时间段是否显式写出至少一个"主体+景别"；
2. 是否存在"切回某人 / 更近 / 切过去"这类只写切换对象、不写景别的模糊句；
3. 是否把焦段、景深、压缩感、虚化感误当成景别；
4. 是否有时间段只写动作和台词，没有写当前主体景别。

## 四、适用边界
本补丁只解决"最终时间轴中主体景别显式化"问题，不改变：
- 15 秒拆片规则；
- 主分镜 / 子分镜层级；
- 台词嵌入方式；
- 信息炸点落点；
- 受击反应分配；
- 空间关系与连续性；
- 参考图分工；
- 风格锚点机制。
