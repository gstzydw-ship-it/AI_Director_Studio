# 镜头表达核心格式

## 总原则

镜头表达要像可直接生成的视频提示词，不像摄影坐标说明书。

最终镜头语言采用短而清楚的导演句式：**景别 + 有动机的简洁机位/运动 + 人物动作/台词/反应 + 切镜触发**。

“同侧”只表示不越轴，不是机位模板；“固定机位”只是可选方案，不是默认答案；“中近景”只负责对白或反应，不得替代所有景别。

空间只在【空间与首帧总控】和【约束】里轻量锁定；单个镜头句不要反复解释空间层级。

核心判断：给 `prompt_compiler` 的镜头句必须是自然可执行表达。可以写“从谁肩后看向哪里、谁站在门口做什么”，也可以写“低机位贴近孩子”“短切手部动作”；不要写“某物形成某种构图效果”。

## 标准段落结构

```text
片段1｜场景名｜戏剧任务｜~秒数

【风格锚点】
一句到两句，写光线、气质和压力来源。

【画幅锚点】
9:16竖屏，列出本段主力景别组合。

【空间与首帧总控】
只写场景、核心阻隔物、人物初始关系、光线。

【人物】
- 人物名：身份、年龄感、服装、表演基底。

【镜头序列】
镜头1【秒数】【主体】景别，简洁机位，人物动作/台词/反应（切镜触发）。

【约束】
- 主体锁定
- 空间锁定
- 连续性
- 禁止项
```

## 单镜头句式

每个镜头按这个顺序写：

```text
镜头编号【时长】【主体】景别，简洁机位，画面动作或台词落点（切镜触发）。
```

可选景别：

- 双人中景
- 半身中景
- 中近景
- 胸部以上中近景
- 肩部以上短特写
- 手部或衣服局部短镜头
- 全身关系景
- 门口关系景
- 桌边关系景

可选机位与运动：

- 同侧过肩机位
- 同侧固定机位
- 同侧正面微侧机位
- 正面固定机位
- 侧面固定机位
- 办公桌侧面固定机位
- 门口侧面固定机位
- 从某人肩后看向某人或门口
- 低机位贴近孩子
- 俯一点看手忙脚乱的动作
- 侧面平稳跟拍
- 背后跟拍
- 平稳跟拍
- 短切手部动作

选择原则：

- 建立关系：双人中景、半身关系景、门口关系景、桌边关系景。
- 忙乱动作：侧面固定机位、侧面平稳跟拍、手部或衣服局部短镜头。
- 孩子抗拒：低机位贴近孩子、半身中景、中近景。
- 电话对白：乔熙半身中景或胸部以上中近景，可用正面微侧或侧面机位。
- 哄劝和情绪缓和：从乔熙肩后看向孩子、双人半身关系景、轻微贴近但不写成复杂运镜。
- 反应落点：中近景、肩后过肩、短特写；真正情绪顶点才用特写。

变化要求：

- 一个片段超过四个镜头时，至少变化三类：主体、景别、机位/运动或声音承载。
- 固定机位连续出现不能超过两个镜头，除非本段戏剧任务就是静止对峙或压迫停顿。
- 中近景不能连续承担三镜以上；需要穿插关系景、半身景、局部短镜头或跟拍。
- 允许大胆使用镜头语言，但必须落在可见动作上，不得写成抽象构图术语。

## 自然表达与不稳定构图

推荐：

```text
同侧过肩机位，从乔熙肩后看向门口，小豆丁站在门口等她（乔熙反应出现后→镜头2）。
门口侧面固定机位，乔熙停在门边，小豆丁背着书包看着她。
```

这里的稳定点是：人物关系清楚，门只表示“门口/门边”这个空间边界，不把门写成独立构图装置。

禁止把门、窗、桌、栏杆写成“框住人物”的构图术语。视频模型容易把这些词理解成新生成的孤立结构，导致人物站进没有门的空框、空间断裂或道具变形。

## 对白覆盖

长对白或压迫台词不能一个镜头吃完。优先拆成：

1. 说话者起句。
2. 听者同侧过肩或中近景反应。
3. 关系景复位或对手反应。

台词必须保留原文，不新增台词。允许英文台词原文出现在引号内，因为这是剧本文本，不属于代理输出字段。

## 轴线规则

同一片段保持同侧轴线。需要听者反应时，写“同侧过肩机位”“同侧固定机位”“同侧正面微侧机位”，不要写人物左前方、右前方、左后方、右后方。

如果必须反打，交给拆段处理；单个片段内禁止写“反打至”。

## 禁止写法

禁止在镜头句里使用这些表达方式：

- 坐标式空间说明
- 方位层级堆叠
- 机位锚点和景别硬拼
- 摄影机位置说明书
- 主体区域说明书
- 框住人物的构图术语
- 门窗形成前景或压线的抽象说明
- 人物站进门框、窗框或抽象框架
- 数字角度和默认高度模板
- 人物相对左右机位
- 复杂摄影字段、英文运镜术语、内部结构化字段

## 正确示例

```text
镜头1【2秒】【商北琛、乔熙】双人中景，办公桌侧面固定机位，两人隔着办公桌对峙，商北琛占主动位置，乔熙正面承接压力（关系和轴线建立后→镜头2）。
镜头2【3秒】【商北琛】半身中景，同侧正面微侧机位，商北琛平静看着乔熙，说：“Starting today, you are reassigned as my Chief Secretary.”（台词意群断点后→镜头3）。
镜头3【2秒】【乔熙】中近景，同侧过肩机位，乔熙眼神停住，听见后半句压过来，商北琛画外继续：“You'll be on call 24/7.”（反应出现后→镜头4）。
```
