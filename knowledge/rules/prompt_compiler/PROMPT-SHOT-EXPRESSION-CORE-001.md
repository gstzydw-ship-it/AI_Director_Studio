# 镜头表达核心格式

## 总原则

镜头表达要像可直接生成的视频提示词，不像摄影坐标说明书。

最终镜头语言采用短而清楚的导演句式：**景别 + 有动机的简洁机位/运动 + 人物动作/台词/反应 + 切镜触发**。

“同侧”只表示不越轴，不是机位模板；“固定机位”只是可选方案，不是默认答案；“中近景”只负责对白或反应，不得替代所有景别。

空间只在【空间与首帧总控】和【约束】里轻量锁定；单个镜头句不要反复解释空间层级。

核心判断：给 `prompt_compiler` 的镜头句必须是自然可执行表达。可以写“从谁肩后看向哪里、谁站在门口做什么”，也可以写“低机位贴近人物”“局部特写”；具体特写对象必须来自当前剧本动作或已有道具，不得把某一剧集的手、衣服、手机、文件等细节固化成通用模板；不要写“某物形成某种构图效果”。

## 标准段落结构

```text
片段1｜场景名｜戏剧任务｜~秒数

【风格锚点】
一句到两句，写光线、气质和压力来源。

【画幅锚点】
9:16竖屏，列出本段主力景别组合。

【空间与首帧总控】
只写场景、核心阻隔物、人物初始关系、光线。

【人物】
- 人物名：身份、年龄感、服装、表演基底。

【镜头序列】
镜头1【秒数】【主体】景别，简洁机位，人物动作/台词/反应（切镜触发）。

【约束】
- 主体锁定
- 空间锁定
- 连续性
- 禁止项
```

## 单镜头句式

每个镜头按这个顺序写：

```text
镜头编号【时长】【主体】景别，简洁机位，画面动作或台词落点（切镜触发）。
```

可选景别不是固定模板，而是按戏剧任务调用的景别池。最终输出只写中文自然表达，不写英文缩写，不把专业分类解释给视频模型。

空间与环境景别：

- 大远景：只用于新场景、城市/建筑/广阔空间建立，竖屏里少用。
- 远景：交代人物和环境的关系。
- 全景：人物全身可见，适合入场、离开、站位变化。
- 中远景：人物和周围行动空间都清楚，适合动作调度。
- 建立关系全景：先看清人物、阻隔物和行动路线，再进入近景。
- 场景关系景：围绕当前已有空间边界建立关系，如门口、桌边、床边、车门外、走廊转角；只在剧本确实存在时使用。

人物尺度景别：

- 全身景：人物从头到脚完整可见，适合走动、躲避、追赶、站位对峙。
- 膝上景：保留身体姿态和表情，适合竖屏里承接行动。
- 大腿以上景：比中景更宽，适合权力压迫、拦路、拉扯前的距离感。
- 腰部以上中景：适合对白、身体动作和手部动作同时存在。
- 半身中景：适合常规对白、电话、命令、解释。
- 中近景：适合情绪反应、听见重点、说出关键句。
- 胸部以上近景：适合压低声音、停顿、质问、压迫感靠近。
- 肩部以上近景：适合眼神变化、强反应、忍耐和爆发前一拍。
- 面部特写：只用于情绪顶点或决定性反应。
- 极近特写：只用于眼神、唇角、泪水、按键、戒指等当前剧本明确存在且承载信息的细节。
- 局部特写：只拍当前剧本动作或已有道具承载的信息，不固定成手、衣服、手机、文件等通用模板。

人数与关系景别：

- 单人景：人物独立承压、行动、反应。
- 单人关系景：单人和门口、桌边、床边、镜子、车门等已有空间发生关系。
- 双人关系景：两人对峙、并行、错身、靠近或拉开。
- 三人关系景：三人同场时交代权力中心、被夹在中间的人和视线归属。
- 多人关系景：多人同场时交代站位层级和谁主导局面。
- 群体景：会议、围观、家庭餐桌、公共空间等多人信息。
- 过肩关系景：从一个人物肩后看向另一个人物或目标方向。
- 主观视线景：先明确谁在看，再拍他/她看见的人、物或动作。
- 反应景：听者、旁观者或被压迫者的表情和身体变化。
- 插入镜头：已有道具、文本、门把、铃声来源、餐盘、药瓶等信息点；必须来自当前剧本。
- 切离镜头：从当前冲突短暂切到同场反应、空间边界或信息物，再回主线。

可选机位与运动按“轴线安全、观察位置、机位高度、镜头运动”分开选择。轴线安全不等于连续使用同侧固定机位；只要不越轴，机位应为戏剧任务服务。

观察位置：

- 同侧过肩机位。
- 同侧正面微侧机位。
- 正面机位。
- 侧面机位。
- 侧背机位。
- 背后机位。
- 场景固定机位。
- 门口侧面机位。
- 桌边侧面机位。
- 走廊侧面机位。
- 车内固定机位或车门外侧机位；只在剧本有车时使用。
- 从某人肩后看向某人、门口、桌边、目标物或行动方向。
- 主观视角或半主观视角；必须先写清是谁在看。
- 反应机位。
- 关系复位机位。

机位高度与角度：

- 平视机位：让对白自然、判断中性。
- 略低机位：增强人物压迫、威胁、强势或孩子仰视成人的关系。
- 低机位贴近人物或动作：只在行动、压迫、摔倒、蹲下、儿童视角等有依据时使用。
- 略高机位：看清桌面、床边、整理衣物、找东西等动作。
- 俯一点看动作关系：用于密集动作和多人交错。
- 高位俯视：用于空间关系、群体调度、人物弱势或困住感，少用。
- 顶视机位：只用于明确空间图形、倒地、餐桌、床面、文件铺开等强信息画面，少用。
- 倾斜机位：只用于失衡、眩晕、危机或精神不稳，必须自然化为“画面轻微倾斜”，少用。

镜头运动：

- 固定机位。
- 平稳跟拍。
- 侧面跟拍。
- 背后跟拍。
- 人物前方平稳后退跟拍。
- 横移跟随。
- 推近到人物反应。
- 拉开回到关系景。
- 摇摄跟随视线或动作。
- 俯仰承接抬头、低头、起身、蹲下或物体落下。
- 升降镜头：用于权力高度、空间揭示或人物从低处到高处的变化，少用。
- 手持跟随：用于慌乱、追赶、争执、急救、逃离等不稳定动作。
- 焦点转换：只用于同一画面里信息从人物转向已有道具，或从前景人物转向背景人物。

选择原则：

- 新场景或空间复杂：先用远景、全景、中远景或建立关系全景，再进入人物近景；竖屏里避免长时间大远景。
- 单人心理：从半身中景、中近景、胸部以上近景推进到面部特写；不要一上来连用特写。
- 双人对白：在双人关系景、过肩关系景、说话者近景、听者反应景之间变化，不做机械正反打。
- 三人或多人同场：先用三人关系景、多人关系景或群体景交代权力中心，再切主导者、被压迫者和关键旁观者。
- 动作调度：优先全身景、膝上景、中远景、侧面跟拍、背后跟拍、横移跟随；动作落点可接局部特写。
- 电话、语音、屏幕信息：先拍说话者或听者反应，再用插入镜头交代信息来源；不新增剧本外手机或屏幕内容。
- 安抚、劝说、试探：可用从说话者肩后看向对方、半主观视角、缓慢推近、关系景复位。
- 压迫、威胁、命令：可用略低机位、胸部以上近景、反应景、拉开回到权力关系；不要把压迫只写成固定机位。
- 慌乱、赶时间、追赶：可用手持跟随、背后跟拍、侧面跟拍、局部特写和反应景交替。
- 信息物或动作细节：只在剧本已有且影响剧情时使用插入镜头或局部特写；镜头句必须写清具体可见物和动作。
- 反应落点：中近景、胸部以上近景、肩部以上近景、面部特写按情绪强度逐级使用；极近特写只给真正关键点。
- 特殊角度和复杂运镜：每个片段少量使用，必须有剧情理由，最终写成视频模型能看懂的自然动作句。

变化要求：

- 一个片段超过四个镜头时，至少变化三类：主体、景别、机位/运动或声音承载。
- 固定机位连续出现不能超过两个镜头，除非本段戏剧任务就是静止对峙或压迫停顿。
- 中近景不能连续承担三镜以上；需要穿插关系景、半身景、局部特写或跟拍。
- 允许大胆使用镜头语言，但必须落在可见动作上，不得写成抽象构图术语。

## 自然表达与不稳定构图

推荐：

```text
同侧过肩机位，从说话者肩后看向门口，对方站在门口等候（说话者反应出现后→镜头2）。
门口侧面固定机位，说话者停在门边，对方看着说话者。
```

这里的稳定点是：人物关系清楚，门只表示“门口/门边”这个空间边界，不把门写成独立构图装置。

禁止把门、窗、桌、栏杆写成“框住人物”的构图术语。视频模型容易把这些词理解成新生成的孤立结构，导致人物站进没有门的空框、空间断裂或道具变形。

## 对白覆盖

长对白或压迫台词不能一个镜头吃完。优先拆成：

1. 说话者起句。
2. 听者同侧过肩或中近景反应。
3. 关系景复位或对手反应。

台词必须保留原文，不新增台词。允许英文台词原文出现在引号内，因为这是剧本文本，不属于代理输出字段。

## 轴线规则

同一片段保持同侧轴线。需要听者反应时，写“同侧过肩机位”“同侧固定机位”“同侧正面微侧机位”，不要写人物左前方、右前方、左后方、右后方。

如果必须反打，交给拆段处理；单个片段内禁止写“反打至”。

## 禁止写法

禁止在镜头句里使用这些表达方式：

- 坐标式空间说明
- 方位层级堆叠
- 机位锚点和景别硬拼
- 摄影机位置说明书
- 主体区域说明书
- 框住人物的构图术语
- 门窗形成前景或压线的抽象说明
- 人物站进门框、窗框或抽象框架
- 数字角度和默认高度模板
- 人物相对左右机位
- 复杂摄影字段、英文运镜术语、内部结构化字段

## 正确示例

```text
镜头1【2秒】【人物甲、人物乙】双人中景，桌边侧面固定机位，两人隔着桌面对峙，人物甲占主动位置，人物乙正面承接压力（关系和轴线建立后→镜头2）。
镜头2【3秒】【人物甲】半身中景，同侧正面微侧机位，人物甲平静看着人物乙，说出原台词（台词意群断点后→镜头3）。
镜头3【2秒】【人物乙】中近景，同侧过肩机位，人物乙眼神停住，听见后半句压过来，人物甲画外继续原台词（反应出现后→镜头4）。
```
