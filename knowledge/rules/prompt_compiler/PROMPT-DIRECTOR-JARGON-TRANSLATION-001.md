# 导演调度口语必须翻译成可见画面语言

## 规则

`prompt_compiler` 不得把上游导演口语原样输出给 Seedance。最终 prompt 必须把调度意图翻译成模型可见的镜头序列句：主体、景别、简洁视角、人物动作、视线和切镜触发。

生活动作、冲突动作、道具动作、进入/离开、拉扯、躲避、翻找、收拾等行为，不能输出“动作主链”“状态单向推进”“关系建立”“抗拒位置”“尾帧承接”等内部判断词。必须改写为可拍动作：谁的哪只手或身体部位，从哪里开始，碰到什么道具或身体部位，往哪里移动，最后停在哪里。

## 禁止

```text
稳定器在同一运动里带到人物B和旁观者胸部以上受压反应。
顺势带到众员工被权力压住。
空气收紧，沉默就是回应。
炸点后尾帧悬停，留足回味。
前慢后碎，电梯暧昧段保持凝滞和张力。
纵深中全景到人物A半身中景，人物A右前方眼平高度。
同一镜头内横移 truck right 到人物B反应，再 truck left 回到主位。
动作叠压，双人关系主链继续，道具状态单向推进，人物B停在抗拒位置。
```

## 改写方向

```text
镜头切至人物B和几名旁观者胸部以上中近景，同侧固定视角；人物B微微低头，旁观者肩膀收紧、屏住呼吸、避开人物A视线。
人物A右手把道具X从位置A移到位置B，左手接触人物B的身体部位或道具Y；人物B肩膀后缩，被接触的身体部位朝相反方向移动，后退半步停住，道具Y保持未完成状态。
```

## 翻译表

- `稳定器在同一运动里带到` -> `镜头切至同侧反应 / 平稳跟拍 / 同侧固定视角`
- `受压反应` -> `低头 / 屏住呼吸 / 肩膀收紧 / 眼神回避 / 身体僵住`
- `权力压住 / 空气收紧` -> `停顿 0.5-1 秒 / 无人说话 / 人群停步 / 让开通道`
- `压入 / 卡断 / 炸点 / 钩子` -> `台词说完后停0.8秒 / 手刚要抬起时切镜 / 门尚未完全闭合时冲入 / 画面停在身体接触瞬间`
- `凝滞 / 粘滞 / 暧昧感 / 张力` -> `两人相距半步 / 对视1秒 / 手停在身体一侧不移动 / 人物嘴唇停住`
- `气口 / 留白 / 回味 / 泄压` -> `镜头保持固定0.5-1秒 / 无人说话 / 人物停在原位 / 呼吸放慢`
- `纵深中全景到半身中景 / 中景转关系景` -> `双人中景 / 人物A半身中景 / 关键空间锚点固定中景`
- `truck right/left / 同一镜头内横移到反应再回主位` -> `镜头切至同侧听者反应 / 镜头切回主角`
- `眼平高度 / 同轴线偏右 / 人物右前方` -> 通常删除或简化为 `正面固定视角 / 侧面固定视角 / 从某人肩后看向某人 / 办公桌侧面固定视角`
- `门窗框住人物 / 前景压线 / 框景压迫` -> `从某人肩后看向门口，某人站在门口或门边做具体动作`
- `动作主链 / 状态单向推进 / 关系建立 / 抗拒位置 / 尾帧承接` -> `道具X从位置A到位置B / 道具Y保持未完成或已改变状态 / 人物B后退半步停住 / 人物A空出的手停在半空`

## 分类翻译表

> 本表是“导演/剪辑/表演术语 -> Seedance 可生成画面句式”的降级表。规则层只使用通用槽位：人物A、人物B、人物C、道具X、道具Y、空间锚点、位置A、位置B、身体部位。具体角色名和道具名只能来自当前剧本或上游镜头资产，不能写死在规则里。

### 关系与空间

- `建立关系 / 建场` -> `人物A和人物B同框，二者距离、朝向、视线方向和中间的空间锚点清楚可见`
- `master shot / 主关系镜头` -> `固定中景或双人中景，人物A、人物B和关键空间锚点同时在画面内`
- `关系复位 / 空间复位` -> `镜头切回关系景，确认人物仍在同一空间，距离、朝向和道具位置延续上一镜`
- `同场关系保留` -> `单人镜保留对方肩线、手臂、衣角、影子或道具边缘；或下一镜切回关系景确认位置`
- `单人镜不代表离场` -> `另一个人物仍在画面边缘或画外同一侧，下一镜切回时站位不变`
- `空间压迫 / 被空间夹住` -> `人物A和人物B距离缩短，人物B背后靠近墙/桌边/门框等空间锚点，身体后撤空间有限`
- `空间打开 / 让出通道` -> `人物群体向两侧退开，中心路径露出，人物A可以从中间通过`
- `空间混乱` -> `只保留1个主空间锚点和人物最终停位，不堆前景/中景/后景/远端/近侧`
- `人物消失感` -> `切镜前后保留同一空间锚点，说明画外人物在画面哪一侧或用关系景补回`

### 轴线、视线与屏幕方向

- `轴线锁定 / 不跨轴` -> `人物A始终在画面同一侧，人物B始终在相对侧；切镜仍保持同一左右关系`
- `视线匹配 / eyeline match` -> `人物A看向画面外某方向，下一镜人物B位于该方向，或道具X出现在对应位置`
- `看向对方 / 视线撞上` -> `人物A抬眼看向人物B眼部，人物B同时回看，停0.3-0.8秒`
- `视线回避` -> `人物B眼神从人物A脸上移开，转向地面、道具X或空间锚点`
- `主观感 / POV` -> `从人物A视线方向看向人物B或道具X，保留人物A的手/肩/身体边缘作为前景锚点`
- `过肩 / OTS` -> `从人物A肩后看向人物B，人物A肩线虚化在前景，人物B占画面中心`
- `反打` -> `单段内优先写同侧听者反应；真反打必须拆到相邻片段或明确同一轴线`
- `画面左/右混乱` -> `删除多余方位词，只保留人物A在画面左、人物B在画面右、空间锚点在中间或一侧`

### Blocking 与人物调度

- `blocking / 走位调度` -> `人物A从位置A移动到位置B，经过空间锚点，在位置B停住并面向人物B或道具X`
- `起势 / 行动起势` -> `人物A身体重心前移，脚尖转向目标，手从身体一侧抬起`
- `压近 / 逼近` -> `人物A向人物B走近半步或一步，人物B保持原位或后退，二者距离明确变短`
- `后退 / 撤开` -> `人物B脚向后退半步，肩膀后缩，身体停在位置B`
- `转身` -> `人物A肩膀先转，脚跟随后转向，身体朝向从方向A变成方向B`
- `入画` -> `人物A从画面某侧进入，先出现身体边缘或手臂，再停在主体位置`
- `出画` -> `人物A从当前位置向画面某侧离开，身体完全离开后画面保留空间锚点或人物B反应`
- `停住 / 定住` -> `人物脚步停止，肩膀不再移动，手或视线停在明确位置`
- `群体散开 / 围拢` -> `人物群体从中心向两侧退开，或从两侧向人物A靠近，中心距离变化可见`

### 动作路径与身体接触

- `动作主链` -> `起点 -> 路径 -> 接触点 -> 终点 -> 停留姿势`
- `动作叠压` -> `人物A右手做动作1，左手同时做动作2；两只手的接触对象分开写清`
- `抓住` -> `人物A的手指合拢在人物B的身体部位或道具X上，接触点保持可见`
- `拉扯` -> `人物A手向方向A用力，人物B身体或道具X向相反方向偏移`
- `推开 / 挡住` -> `人物A手掌接触人物B身体部位或道具X，推动到位置B后停住`
- `挣脱` -> `被抓住的身体部位从对方手心滑出，人物B后退半步，接触断开`
- `抗拒 / 躲避` -> `人物B肩膀后缩、下巴偏开、被接触的身体部位往相反方向移动`
- `碰撞` -> `人物A身体部位接触人物B身体部位，双方重心停顿，接触后各自停在明确位置`
- `扶住 / 接住` -> `人物A手掌贴住人物B身体部位或道具X，阻止其继续移动，人物B重心停止`
- `松手` -> `人物A手指张开，手掌离开接触点，手落回身体一侧或停在半空`
- `交接` -> `道具X从人物A手中移到人物B手中，两人的手短暂同框接触，随后人物A松开`

### 道具与物体状态

- `状态单向推进 / 不得回弹` -> `道具X从位置A移动到位置B后保持在位置B，不回到位置A`
- `手持道具状态推进` -> `道具X从位置A被拿起，移到位置B，结尾仍停在位置B`
- `未完成道具状态` -> `道具Y靠近目标位置 -> 被拉偏/卡住/停住 -> 保持未完成状态`
- `开合状态` -> `门/盒/包/文件从关闭到半开再到打开，或从打开到半合再到关闭，不能反向跳回`
- `遮挡/显露` -> `道具X先被手/衣物/桌边遮住，随后露出关键部分，露出后保持可见`
- `信息道具落点` -> `道具X只显示关键信息；信息看清后立即切回人物动作`
- `掉落` -> `道具X从人物A手边滑落，沿固定方向落到地面/桌面位置B，结尾停在位置B`
- `捡起` -> `人物A手从身体一侧伸向位置B，手指接触道具X，把道具X带回身体前`
- `打翻 / 溢出 / 破损` -> `道具X倾斜或断裂，液体/碎片停在桌面或地面位置B，不自动复原`
- `穿戴/安装未完成` -> `道具Y只到达身体部位或目标边缘，卡住、歪斜或悬在外侧，未完成状态可见`

### 情绪与身体表演

- `焦虑 / 慌乱` -> `肩颈绷紧、呼吸短、眼神快速扫向关键道具、出口或对手，手部动作变快`
- `犹豫 / 迟疑` -> `手停在半空，视线在人物B和道具X之间来回，脚步没有继续前进`
- `震惊 / 受击` -> `嘴唇停住、下颌收紧、眼睛定住，手或身体动作中断`
- `压迫感 / 张力` -> `两人距离缩短到半步，无人说话0.5-1秒，被压一方肩膀收紧或后退受限`
- `愤怒` -> `下颌绷紧、眉头压低、身体前倾，手指收紧或拍向桌面/道具X`
- `害怕 / 退缩` -> `人物B肩膀上提、身体后缩，视线避开人物A，脚尖向后`
- `委屈 / 克制` -> `人物B嘴唇抿住，眼神下落，手指攥紧衣角或道具X`
- `放松 / 泄压` -> `人物肩膀下沉，呼吸放慢，手从紧握变松，视线离开压力源`
- `亲近 / 暧昧` -> `两人距离缩短，动作变慢，手停在接触点附近不继续推进，视线停留0.5-1秒`
- `决心 / 转折` -> `人物A抬眼定住目标，身体转向目标，脚步向位置B迈出`

### 对白覆盖与反应镜

- `承载对白` -> `人物A说出台词起句，人物B同框或画面边缘可见，台词落点后切到人物B反应`
- `长台词不断` -> `声音连续；画面可切到听者反应、过肩、道具插入或关系景，不等于单镜头说完`
- `听者反应` -> `镜头切至人物B中近景，人物B眼神、下颌、呼吸或手部出现变化`
- `画外音 / L-cut` -> `画面停在人物B或道具X上，人物A后半句在画外继续`
- `J-cut / 声音先入` -> `下一句声音先出现，画面仍停在当前人物或道具状态，随后切到说话者`
- `沉默就是回应` -> `无人说话0.5-1秒，人物B停在原位，视线或手部动作发生可见变化`
- `质问压迫` -> `说话者身体前倾或视线压向听者，听者肩膀收紧或后退半步`
- `打断` -> `人物B开口前人物A抢先说话，人物B嘴唇停住或手停在半空`

### 剪辑、插入镜与切点

- `信息落点` -> `某个可读/可见信息看清后切镜，例如数字、文件边角或道具状态看清后切回人物`
- `情绪落点` -> `表情或身体反应出现后切镜，例如手停住、眼神避开后切回关系景`
- `动作顶点` -> `手刚碰到道具X、身体刚停住、门缝刚变窄、道具刚落地时切镜`
- `match on action / 动作匹配` -> `上一镜动作在中途开始，下一镜从同一动作的后半段继续，不从头重做`
- `insert / 插入镜` -> `短局部镜只拍手、道具X、门缝、文件角等信息点，前后必须回到人物关系`
- `cutaway / 切出镜` -> `短镜头切到旁观者、环境反应或道具状态，随后切回主动作`
- `reaction shot / 反应镜` -> `镜头切至人物B中近景，保留人物A肩线或空间锚点，人物B出现可见反应`
- `节奏加快` -> `镜头时长变短，每镜只保留一个动作或一个信息点`
- `节奏放慢 / 留白` -> `镜头固定0.5-1秒，无人说话，人物保持可继承姿势`
- `尾帧锁定 / 尾帧承接` -> `最后0.5-1秒保持可继承姿势：人物位置、视线方向、关键道具状态不变`

### 景别、构图与主体选择

- `建立空间` -> `全景或中景，人物和空间锚点同时出现`
- `建立人物关系` -> `双人中景/半身关系景，人物距离和朝向可见`
- `强调反应` -> `人物B胸部以上中近景，保留人物A肩线或空间锚点`
- `强调手部/道具` -> `局部近景，只拍手和道具X，时长短，前后回到关系景`
- `主观视角` -> `从人物A视线方向看向目标，保留人物A手、肩或身体边缘作为前景`
- `前景压迫 / 框景压迫` -> `改为可见空间关系：人物B靠近门框/桌边/墙面，移动空间被限制`
- `画面重心变化` -> `主体从人物A变为道具X或人物B时，写成切镜或明确的视线引导`
- `过多空间方位词` -> `删除多余前景/中景/后景/远端/近侧，只保留当前镜头必要的1个空间锚点`

### 视角与运动

- `带到 / 顺势带到` -> `镜头切至目标主体；或平稳跟拍目标主体短距离后停住`
- `pan / 摇镜` -> `镜头水平转向，从人物A转到人物B或空间锚点，不改变摄影机位置`
- `tilt / 俯仰` -> `镜头上下转向，从人物身体部位转到脸部或道具X，不改变摄影机位置`
- `dolly in / push in` -> `摄影机向人物A或道具X缓慢靠近，主体逐渐变大`
- `dolly out / pull back` -> `摄影机后退，人物和空间锚点同时变得可见`
- `truck left/right / 横移` -> `摄影机横向移动，露出人物B或道具X；避免同一镜横移过去又横移回来`
- `track/follow / 跟拍` -> `摄影机跟随人物A从位置A移动到位置B，保持距离稳定`
- `handheld` -> `轻微手持晃动，但主体保持在画面中心或稳定区域`
- `locked-off / 固定机位` -> `固定视角，只让人物动作和道具状态变化`
- `rack focus / 焦点转换` -> `焦点从前景道具X转到后景人物B，或从人物A转到道具X；主体位置不跳变`
- `zoom` -> `只改变画面大小，不改变人物与空间锚点的相对位置；通常优先改成 push in 或 cut in`

### 节奏、时间与复杂度

- `高信息密度` -> `每个镜头只放一个新信息：新人物、新道具、新位置、新动作不要同时出现`
- `动作过密` -> `拆成主关系镜头 + 短插入镜 + 切回关系镜头`
- `快速混乱` -> `动作速度快，但镜头任务简单，关键道具和人物位置不跳`
- `慢镜 / 情绪停顿` -> `动作变慢或停住0.5-1秒，人物呼吸、视线或手部状态可见`
- `并行动作` -> `分别绑定人物A左手、右手、视线、脚步或人物B的反向动作`
- `压缩过程` -> `只拍开始状态、关键中间态、结束状态，不逐步展示全部过程`
- `跨镜连续` -> `下一镜继承上一镜的道具位置、身体接触、人物距离和视线方向`

### 禁止透传的抽象词

- `戏剧任务 / 画面任务 / 覆盖职责` -> 改成镜头里实际可见的主体、动作和信息点
- `情绪升级 / 关系升级 / 压力升级` -> 改成距离变化、停顿、视线、身体紧张或道具动作变重
- `单向推进 / 状态链 / 连续性锁定` -> 改成每个道具和身体接触的前后位置
- `抗拒位置 / 尾帧位置 / 继承位置` -> 改成人物站位、身体朝向、手停在哪里、道具停在哪里
- `更有电影感 / 更有张力 / 更抓人` -> 删除，改为具体景别、切点、动作顶点或反应镜
