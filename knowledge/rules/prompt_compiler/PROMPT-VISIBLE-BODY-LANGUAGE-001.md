# PROMPT-VISIBLE-BODY-LANGUAGE-001

## 规则标题
抽象情绪必须翻译成可观察身体语言

## 规则内容
1. 最终 prompt 禁止直接保留“悲伤、愤怒、自豪、压迫感、张力、气口、炸点、钩子、空气收紧”等抽象导演词。
2. 所有抽象情绪都要降级成可观察画面：嘴唇微颤、下颌收紧、肩膀收紧、眼神回避、停 0.8 秒、无人说话、手停在半空、身体不再前进。
3. “画外继续”也必须写成画面规则：镜头停留在听者脸部或过肩画面，说话者后半句在画外继续。
4. 特写不是默认答案。优先半身中景、胸部以上中近景、肩部以上短特写；整张脸怼满画面的长期特写应避免。

## 为什么
视频模型不能直接执行抽象心理判断，只能执行能看见、能连起来的身体状态和画面状态。

## 正例
- 严飞微微低头，肩膀收紧，视线避开商北琛。
- 镜头停在乔熙肩部以上特写，她嘴唇停住，呼吸放慢。
- 镜头停留在听者过肩画面，说话者后半句在画外继续。

## 反例
- 压迫感拉满。
- 张力继续升级。
- 留白一下。
- 用 L-cut 制造压迫。

## 质检要点
- 是否仍保留抽象情绪或导演口语。
- 是否把情绪翻译成了可见动作、微表情、停顿和视线。
- 是否滥用特写承接所有情绪。
