# 22_多机位分镜与镜头多样性规则

日期：2026-04-15  
版本：v2.0  
用途：指导 story_planner、shot_director 和 prompt_compiler 实现真正的多机位分镜叙事。本文件是多机位方法论的核心参考。

主分镜/子分镜的定义与切换规则见 03 号文件，本文件不重复定义。

---

## 一、两大核心理念

### 理念 A：同一动作单元，多角度覆盖

像真正的短剧导演一样思考：同一个关键动作不是只拍一次跟随中景就完事。  
导演应该在 15 秒导演片段内为它规划 2-3 个有动机的主分镜/子分镜，必要时让 Seedance prompt 直接承载这些镜头切换。

示例——"商北琛走进电梯"这个动作单元：
- 片段A（背面中景）：商北琛背影迈步走向电梯
- 片段B（侧面特写）：手按下电梯按钮，侧身进入
- 片段C（正面中景）：商北琛面向镜头，电梯门缓缓关闭

每个 15 秒导演片段 = 一个完整的戏剧编排单位。  
同一片段内可以包含不同机位、不同景别、不同角度/距离的主分镜与子分镜。  
最终成片的多角度效果既可以由单条 prompt 内的分镜切换实现，也可以由人工后期挑选版本补强。

### 理念 B：机位切换即减法——用切换省略无用片段

**短剧要做减法。** 机位/景别/主体的切换天然省略了中间的垃圾时间。

示例——传统做法（错误）：
```
一个15秒片段内拍完全程：商北琛说完话→转身→走5步→到电梯前→按按钮→进电梯→电梯关门
结果：中间8秒走路毫无信息量，AI模型还容易生成乱七八糟的动作
```

正确做法（机位切换减法）：
```
片段A（跟随中景，3秒）：商北琛说完"Meeting in ten minutes"，转身迈步
  ↓ 切换到侧面机位（中间走路的8秒自动消失）
片段B（侧面特写，2秒）：手按下电梯按钮
  ↓ 切换到正面机位
片段C（正面中景，5秒）：商北琛面向镜头站在电梯内，电梯门缓缓关闭
```

不需要"出画"指令，不需要"跳切"标签——仅仅因为换了一个拍摄角度，无聊的走路就自然消失了。

**导演必须学会识别"哪些动作不值得拍完整过程"：**
- 走路/位移 → 只拍起步和到达，中间用机位切换省略
- 开门/上车 → 只拍关键瞬间（手拉门把、车门打开），不拍走向车门的全过程
- 进入新空间 → 直接从新空间的另一个角度起拍，不拍"走进来"的全程

**这样做的额外好处：** 每个片段只需要描述 1-2 个简单动作，AI视频模型的执行准确率大幅提升。

### 理念 C：动作顶点前切——在动作完成前一秒切换机位

**这是最实用的切镜技巧，适用于一切场景。**

原理：任何动作都有一个"顶点"——喝水的顶点是杯子到达嘴边，开门的顶点是门被完全推开，转身的顶点是身体正对新方向。**切镜时机应该选在动作顶点前一秒，而不是动作完成后。**

```
示例——喝水：
片段A（中景）：人物拿起水杯，杯子正在向嘴边举起——
  ↓ 在杯子即将到达嘴边时切（动作顶点前1秒）
片段B（侧面特写）：杯口已贴在嘴唇上，人物轻抿一口

示例——推门进入：
片段A（走廊中景）：人物伸手推门，门开始向内推开——
  ↓ 在门半开时切（动作顶点前1秒）
片段B（室内反向机位）：门完全打开，人物迈步走入

示例——转身：
片段A（正面中景）：人物说完话，身体开始转动——
  ↓ 在身体转到侧面时切（动作顶点前1秒）
片段B（背面/侧面机位）：人物已面朝新方向，迈步离开

示例——扑倒/冲撞：
片段A（电梯内中景）：乔熙冲来，身体即将撞上商北琛——
  ↓ 在即将接触时切（动作顶点前1秒）
片段B（双人特写）：乔熙已扑在商北琛胸前，双手抓住西装前襟
```

**为什么这样切：**
1. 观众大脑会自动补完中间过程，不需要拍
2. 两个机位各拍动作的一半，AI模型只需执行简单动作
3. 比在动作完成后才切更有节奏感和冲击力
4. 即使两段画面衔接不完美，因为"动作正在进行中"切的，观众不会注意到

**通用规则：任何需要切换机位的时刻，优先选在动作正在进行、尚未完成的那一秒切。**

## 二、核心镜头类型定义

### 类型 01：建立镜头（Establishing Shot）
- **景别**：全景 / 中全景
- **功能**：交代空间关系、环境气氛、人物站位
- **何时使用**：新场景的第一个镜头、人物关系发生空间重组后
- **注意**：建立镜头不写角色特写表情，重点是空间+人物站位

### 类型 02：跟随镜头（Following Shot）
- **景别**：中景 / 半身景
- **功能**：跟拍人物的动作/位移
- **何时使用**：人物有明确位移的段落
- **注意**：不要让跟随镜头超过5秒，用机位切换做减法

### 类型 03：过肩镜头（OTS）
- **景别**：中近景，前景有A的肩线虚化，后景B清晰
- **功能**：建立对话空间关系，替代站桩正反打
- **变体**：干净过肩（前景只露一点）、脏过肩（前景占较大面积）
- **注意**：前景人物只是参照物，焦点始终在后景人物脸上

### 类型 04：反应镜头（Reaction Shot）
- **景别**：中近景 / 特写
- **功能**：捕捉受击者被信息命中后的表情和身体反应
- **何时使用**：信息炸点命中后、主角发出命令离开后
- **注意**：反应镜头通常作为独立片段。但若受击者已在当前画面中（过肩/双人同框/虚焦可见），可通过子分镜在同一片段内承接。具体判断见 05 规则07（三级决策树）

### 类型 05：细节/局部镜头（Insert / Detail Shot）
- **景别**：特写 / 极特写
- **功能**：放大关键细节——手部动作、道具状态、微表情
- **注意**：必须有叙事动机，不是为了"好看"

### 类型 06：双人同框镜头（Two-Shot）
- **景别**：中景 / 中近景，两人同时在画面中
- **功能**：展示两人的关系动态——距离、对峙、亲密、权力
- **注意**：必须写清谁是焦点主体（谁清晰、谁可轻微虚化）

## 三、反站桩正反打规则

### 规则 01：禁止呆板正反打作为默认对话方案
片段A拍甲说话→片段B拍乙说话→片段C拍甲说话的 ABAB 模式会让成片像视频会议录屏。

### 规则 02：对话场景的合法拍法（按推荐优先级）
1. **过肩构图**：从A肩后拍B说话
2. **双人同框**：两人同时在画面中
3. **反应特写**：不拍说话者，拍听者被击中的表情（说话者声音画外）
4. **动作中的对话**：人物边走边说，镜头跟随动作
5. **渐进推近**：同一片段内镜头从中景缓慢推到中近景

### 规则 03：正面单人镜头的使用限制
只在以下场景合法：
- 人物独处的内心独白
- 面对镜头的权力宣言
- 极关键的特写表情——每场戏最多 1-2 次

## 四、场景拆片的多机位规划流程

### 流程 A：先确定场景的"镜头菜单"
拿到剧本后，先列出这场戏需要哪些类型的镜头。

### 流程 B：识别可省略的垃圾时间
标注剧本中哪些动作不值得完整拍摄，可以通过机位切换省略：
- 人物从A点走到B点 → 只拍起步+到达
- 开门/关门的走向过程 → 只拍手抓门把的瞬间
- 进出车辆/电梯 → 只拍关键瞬间

### 流程 C：把镜头菜单映射为片段
每个片段对应一个机位/镜头类型。注意利用机位切换自然省略垃圾时间。

示例映射（天御大堂场景）：
```
片段 F01（跟随中景，~5秒）— 商北琛进场+下令，说完转身迈步
片段 F02（反应中近景，~5秒）— 主管们受击反应，快速散开
片段 F03（侧面特写，~3秒）— 商北琛手按电梯按钮（通过切换省掉走路）
片段 F04（正面中景，~5秒）— 乔熙冲入，扑到商北琛身上
片段 F05（双人中近景，~5秒）— 电梯内对白，电梯门关闭
```

### 流程 D：镜头多样性自检
检查：
1. 所有片段中是否至少包含 2 种以上不同镜头类型
2. 是否存在连续 3 个片段都用同一种景别/角度
3. 对话段落是否避免了 ABAB 正反打模式
4. 是否有效利用机位切换省略了垃圾时间

## 五、AI 视频生成的多机位适配规则

### 规则 04：15 秒导演片段允许多主分镜/子分镜
AI 视频模型每次生成的是一个可执行的视频段，但本系统的 15 秒导演片段可以包含多个主分镜/子分镜。因此：
- 片段内部可以切换机位、景别、主体或局部特写
- 每次切换必须由动作锚点、台词落点、受击反应、视线或空间调度触发
- 切换前后必须保持人物、道具、轴线、情绪残留和动作状态连续
- 禁止无动机跳空间、跳轴、跳主体或只为炫技堆镜头

### 规则 05：单段只描述 1-2 个连贯动作
AI视频模型的动作理解能力有限。利用机位切换做减法后，每个片段变得更短更简单：
- 只包含 1 个主驱动动作
- 最多叠加 1 个伴随动作（说话时的表情变化）
- 禁止在一段中塞入 3 个以上不相关动作

### 规则 06：人物参考图是多机位一致性的关键
不同片段代表不同机位，但拍的是同一个人物。每个片段的首帧总控都必须调用人物参考图锁定身份。

### 规则 07：利用机位切换减少模型出错
机位切换不仅是叙事工具，也是降低 AI 生成错误的技术手段：
- 每个片段只需要执行简单动作 → 模型准确率高
- 复杂连续动作被拆成多个简单片段 → 每段独立可控
- 如果某一段生成效果不好 → 只重新生成这一段，不影响其他

## 六、每种场景类型的多机位推荐方案

### 场景类型 A：人物入场/到达
1. **建立镜头**（全景）— 交代空间，人物从远处走来
2. **跟随镜头**（中景）— 跟拍入场动作，说完台词后迈步（不拍完整走路）
3. **反应镜头**（中近景）— 拍在场其他人的反应
4. **细节镜头**（特写）— 到达目标处的关键动作（按按钮、推门）

### 场景类型 B：两人对话/对峙
1. **过肩镜头**（中近景）— 从A肩后拍B说话
2. **反应特写**（中近景/特写）— 关键台词时拍听者反应
3. **双人同框**（中景）— 展示关系变化
4. **细节镜头**（特写）— 手部、道具等关键细节

### 场景类型 C：多人群戏
1. **建立镜头**（全景）— 所有人的站位关系
2. **跟随镜头**（中景）— 跟拍核心人物
3. **反应镜头群** — 分别拍 2-3 个受击者的反应
4. **过肩/越肩** — 从旁观者角度看核心冲突

## 七、常见错误与纠偏

### 错误 01：全片只有"跟随中景"
纠偏：强制加入反应镜头、细节镜头或过肩镜头。

### 错误 02：对话戏全程正反打
纠偏：用过肩镜头替代至少一半的正面单人镜头。

### 错误 03：用走路填满片段时长
纠偏：用机位切换省略走路，只拍起步和到达。

### 错误 04：一个片段内塞太多动作导致AI生成失败
纠偏：利用机位切换把复杂动作拆成多个简单片段。

### 错误 05：细节镜头没有叙事动机
纠偏：只有当动作承载剧情信息时才用细节镜头。

## 九、一句话总纲
**像真正的导演一样用多机位覆盖关键动作，用机位切换做减法省略垃圾时间；每个片段是一个独立机位的连续拍摄，动作越简单AI执行越准确；短剧要做减法，不做加法。**
