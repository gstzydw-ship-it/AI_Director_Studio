# 22_多机位分镜与镜头多样性规则

日期：2026-04-15  
版本：v2.0  
用途：指导 story_planner、shot_director 和 prompt_compiler 实现真正的多机位分镜叙事。本文件是多机位方法论的核心参考。

主分镜/子分镜的定义与切换规则见 03 号文件，本文件不重复定义。

本文件中的旧版英文术语和缩写只作为内部索引，不得进入最终代理输出。输出给用户、视频模型或最终 YAML 时，必须改写为中文自然镜头句：例如“过肩关系镜头”“近主观视角”“面部特写”“声音先行”“声音延续”“人物视线所见画面”。不得输出 `OTS`、`POV`、`CU`、`ECU` 等缩写。

## 一、两大核心理念

### 理念 A：同一动作单元，多角度覆盖

像真正的短剧导演一样思考：同一个关键动作不是只拍一次跟随中景就完事。  
导演应该在 15 秒导演片段内为它规划 2-3 个有动机的主分镜/子分镜，必要时让 Seedance prompt 直接承载这些镜头切换。

示例——“角色进入新空间”这个动作单元：
- 镜头段A（背面中景）：角色迈步走向入口
- 镜头段B（局部特写）：当前剧情需要的进入动作被清楚拍到
- 镜头段C（正面中景）：角色已经进入新空间，入口缓慢关闭或环境变化完成

每个 15 秒导演片段 = 一个完整的戏剧编排单位。  
同一 15 秒导演片段内可以包含不同机位、不同景别、不同角度/距离的主分镜与子分镜。
最终成片的多角度效果既可以由单条 prompt 内的分镜切换实现，也可以由人工后期挑选版本补强。

### 理念 B：机位切换即减法——用切换省略无用片段

**短剧要做减法。** 机位/景别/主体的切换天然省略了中间的垃圾时间。

示例——传统做法（错误）：
```
一个 15 秒导演片段内拍完全程：角色说完话→转身→走几步→到入口前→完成进入动作→进入新空间→入口关闭
结果：中间8秒走路毫无信息量，AI模型还容易生成乱七八糟的动作
```

正确做法（机位切换减法）：
```
镜头段A（跟随中景，3秒）：角色说完关键台词，转身迈步
  ↓ 切换到另一个安全机位（中间走路的8秒自动消失）
镜头段B（局部特写，2秒）：当前剧情需要的进入动作完成
  ↓ 切换到新的关系机位
镜头段C（中景，5秒）：角色已经站在新空间里，环境变化完成
```

不需要"出画"指令，不需要"跳切"标签——仅仅因为换了一个拍摄角度，无聊的走路就自然消失了。

**导演必须学会识别"哪些动作不值得拍完整过程"：**
- 走路/位移 → 只拍起步和到达，中间用机位切换省略
- 开门/上车 → 只拍关键瞬间（手拉门把、车门打开），不拍走向车门的全过程
- 进入新空间 → 直接从新空间的另一个角度起拍，不拍"走进来"的全程

**这样做的额外好处：** 每个镜头段只需要描述 1-2 个简单动作，AI视频模型的执行准确率大幅提升。

### 理念 C：动作顶点前切——在动作完成前一秒切换机位

**这是最实用的切镜技巧，适用于一切场景。**

原理：任何动作都有一个"顶点"——喝水的顶点是杯子到达嘴边，开门的顶点是门被完全推开，转身的顶点是身体正对新方向。**切镜时机应该选在动作顶点前一秒，而不是动作完成后。**

```
示例——喝水：
镜头段A（中景）：人物拿起水杯，杯子正在向嘴边举起——
  ↓ 在杯子即将到达嘴边时切（动作顶点前1秒）
镜头段B（侧面特写）：杯口已贴在嘴唇上，人物轻抿一口

示例——推门进入：
镜头段A（走廊中景）：人物伸手推门，门开始向内推开——
  ↓ 在门半开时切（动作顶点前1秒）
镜头段B（室内反向机位）：门完全打开，人物迈步走入

示例——转身：
镜头段A（正面中景）：人物说完话，身体开始转动——
  ↓ 在身体转到侧面时切（动作顶点前1秒）
镜头段B（背面/侧面机位）：人物已面朝新方向，迈步离开

示例——扑倒/冲撞：
镜头段A（关系中景）：一个角色冲向另一个角色，身体即将接触——
  ↓ 在即将接触时切（动作顶点前1秒）
镜头段B（双人近景）：冲撞结果已经发生，两人的身体关系和受击反应清楚可见
```

**为什么这样切：**
1. 观众大脑会自动补完中间过程，不需要拍
2. 两个机位各拍动作的一半，AI模型只需执行简单动作
3. 比在动作完成后才切更有节奏感和冲击力
4. 即使两段画面衔接不完美，因为"动作正在进行中"切的，观众不会注意到

**通用规则：任何需要切换机位的时刻，优先选在动作正在进行、尚未完成的那一秒切。**

## 二、核心镜头类型定义

### 类型 01：建立镜头（Establishing Shot）
- **景别**：全景 / 中全景
- **功能**：交代空间关系、环境气氛、人物站位
- **何时使用**：新场景的第一个镜头、人物关系发生空间重组后
- **注意**：建立镜头不写角色特写表情，重点是空间+人物站位

### 类型 02：跟随镜头（Following Shot）
- **景别**：中景 / 半身景
- **功能**：跟拍人物的动作/位移
- **何时使用**：人物有明确位移的段落
- **注意**：不要让跟随镜头超过5秒，用机位切换做减法

### 类型 03：过肩镜头（OTS）
- **景别**：中近景，前景有A的肩线虚化，后景B清晰
- **功能**：建立对话空间关系，替代站桩正反打
- **变体**：干净过肩（前景只露一点）、脏过肩（前景占较大面积）
- **注意**：前景人物只是参照物，焦点始终在后景人物脸上

### 类型 04：反应镜头（Reaction Shot）
- **景别**：中近景 / 特写
- **功能**：捕捉受击者被信息命中后的表情和身体反应
- **何时使用**：信息炸点命中后、主角发出命令离开后
- **注意**：反应镜头通常作为独立镜头段。但若受击者已在当前画面中（过肩/双人同框/虚焦可见），可通过子分镜在同一 15 秒导演片段内承接。具体判断见 05 规则07（三级决策树）

### 类型 05：细节/局部镜头（Insert / Detail Shot）
- **景别**：特写 / 极特写
- **功能**：放大关键细节——当前场景真正承载信息的动作、物件状态或微表情
- **注意**：必须有叙事动机，不是为了"好看"；不要把手机、衣服、手部、门把等任何固定元素默认成通用模板

### 类型 06：双人同框镜头（Two-Shot）
- **景别**：中景 / 中近景，两人同时在画面中
- **功能**：展示两人的关系动态——距离、对峙、亲密、权力
- **注意**：必须写清谁是焦点主体（谁清晰、谁可轻微虚化）

## 二-B、专业景别/机位/运动池

镜头多样性不是随机换角度，而是按戏剧任务调用专业工具。以下内容用于给分镜导演提供“可选池”，不得把任何单一组合固定成默认模板。

### 景别池

| 景别 | 适合承担的任务 | 纠偏 |
|------|----------------|------|
| 大远景/远景 | 新空间、孤立、危险距离、群体规模 | 没有空间信息时不硬上 |
| 全景/中全景 | 多人关系、动作全貌、空间重组 | 不用来拖时长 |
| 中景 | 对话基底、关系变化、动作承接 | 不连续占满全段 |
| 中近景 | 逼问、识破、隐忍、试探 | 不把它当所有对白默认景别 |
| 近景/特写 | 炸点、受击、决定、停顿 | 每次必须有情绪或信息落点 |
| 极特写 | 线索、细微反应、心理裂缝 | 不默认拍某类固定物件或身体部位 |

### 机位与视角池

| 机位/视角 | 适合承担的任务 | 纠偏 |
|----------|----------------|------|
| 平视 | 中性关系、信息交代 | 可用但不能全片只有它 |
| 略低视角 | 压迫、命令、权力上升 | 受仰拍限额约束 |
| 略高视角 | 失势、被审视、孤立 | 必须服务处境 |
| 斜侧/三分之二角度 | 同时保留表情与关系压力 | 优先替代呆板正面单人镜头 |
| 背后/跟随 | 进入、离开、追踪、隐瞒 | 只拍必要起势和到达 |
| 近主观/POV | 惊恐、醉酒、受伤、发现 | 必须与人物心理和身体状态一致 |
| 高位/俯瞰 | 群体结构、包围、空间压迫 | 先让空间可读 |
| 贴近局部 | 动作锚点、线索、冲击结果 | 由本场剧情决定拍什么 |

### 运镜池

| 运镜 | 适合承担的任务 | 纠偏 |
|------|----------------|------|
| 固定 | 炸点、受击、停顿、压迫 | 让演员和动作承担冲击 |
| 轻推近 | 逼近、心理压力升高 | 必须有台词或动作触发 |
| 轻拉远 | 疏离、真相扩大、孤立 | 不用于钩子后泄气 |
| 平移/摇移 | 新焦点压入、视线转移 | 不扫无关环境 |
| 跟拍 | 入场、追逐、边走边说 | 超过必要时长就切 |
| 手持/轻微失衡 | 失控、逃跑、受伤视角 | 不全场无差别晃 |
| 弧形移动 | 关系包围、局势反转 | 空间必须已经清楚 |

## 二-C、按戏剧任务选镜头

| 戏剧任务 | 推荐组合 | 禁止倾向 |
|----------|----------|----------|
| 信息交代 | 中景关系 + 必要反应 + 线索局部 | 全程拍说话者说明 |
| 冲突升级 | 中景起势 → 中近景压近 → 受击反应 | 均速正反打 |
| 权力压制 | 关系景 + 高低视角差 + 稳定停顿 | 只靠一句“压迫构图” |
| 权力反转 | 旧秩序关系景 + 新主导者稳定镜头 + 失势方受击 | 反转后立刻拉远泄力 |
| 悬念揭晓 | 发现前停顿 + 线索镜头 + 发现者反应 | 答案刚出现就讲透 |
| 多人群戏 | 全景/高位建立 + 焦点人物 + 旁观反应 | 把三人以上硬写成双人对话模板 |
| 动作爆发 | 可读全景 + 贴近冲击 + 结果反应 | 一镜塞完整复杂动作 |
| 情绪停顿 | 固定近景/中近景 + 呼吸、姿态或沉默 | 用更多调度替代消化 |

## 二-D、自然中文输出桥接

内部可以使用专业术语做规划，但交给视频模型的 prompt 必须是自然、可拍、少歧义的中文。

1. **把术语翻译成画面**：内部“低机位近景”输出为“镜头从略低的位置靠近人物上半身，对方显得更有压迫感”；内部“反应镜头”输出为“听到这句话的人停住，表情僵住一瞬”。
2. **不用抽象构图词当指令**：避免把“三分法、画面重心、框中框、门框压线、人物站进门框”等词直接写给模型。
3. **不用人物左右相对方位当主指令**：内部可维护轴线和屏幕侧，最终输出用“说话者、听者、被质问的人、刚进场的人、坐着的人、退后的人”等身份和动作关系。
4. **同侧是轴线安全，不是镜头模板**：同一侧拍摄只保证空间连续；在这个安全边界内仍应变化景别、视角、高度、焦点和运动。
5. **细节必须来自剧情**：局部镜头只写本场真正有信息的动作或物件，不预设固定清单。

## 三、反站桩正反打规则

### 规则 01：禁止呆板正反打作为默认对话方案
镜头段A拍甲说话→镜头段B拍乙说话→镜头段C拍甲说话的 ABAB 模式会让成片像视频会议录屏。

### 规则 02：对话场景的合法拍法（按推荐优先级）
1. **过肩关系镜头**：从一个人的肩背附近看向对方，保留两人的关系压力
2. **双人同框**：两人同时在画面中
3. **反应特写**：不拍说话者，拍听者被击中的表情（说话者声音画外）
4. **动作中的对话**：人物边走边说，镜头跟随动作
5. **渐进推近**：同一 15 秒导演片段内镜头从中景缓慢推到中近景

### 规则 03：正面单人镜头的使用限制
只在以下场景合法：
- 人物独处的内心独白
- 面对镜头的权力宣言
- 极关键的特写表情——每场戏最多 1-2 次

## 四、场景拆片的多机位规划流程

### 流程 A：先确定场景的"镜头菜单"
拿到剧本后，先列出这场戏需要哪些类型的镜头。

### 流程 B：识别可省略的垃圾时间
标注剧本中哪些动作不值得完整拍摄，可以通过机位切换省略：
- 人物从A点走到B点 → 只拍起步+到达
- 开门/关门的走向过程 → 只拍手抓门把的瞬间
- 进出车辆/电梯 → 只拍关键瞬间

### 流程 C：把镜头菜单映射为时间轴段
每个时间轴段对应一个机位/镜头类型。注意利用机位切换自然省略垃圾时间。

示例映射（天御大堂场景）：
```
时间轴段 F01（跟随中景，~5秒）— 核心角色进场并下令，说完转身迈步
时间轴段 F02（反应中近景，~5秒）— 主管们受击反应，快速散开
时间轴段 F03（局部特写，~3秒）— 角色完成当前剧情需要的进入动作（通过切换省掉走路）
时间轴段 F04（关系中景，~5秒）— 另一角色突然压入，打断原本行动
时间轴段 F05（双人中近景，~5秒）— 新空间内的对白与关系变化
```

### 流程 D：镜头多样性自检
检查：
1. 所有时间轴段中是否至少包含 2 种以上不同镜头类型
2. 是否存在连续 3 个时间轴段都用同一种景别/角度
3. 对话段落是否避免了 ABAB 正反打模式
4. 是否有效利用机位切换省略了垃圾时间

## 五、AI 视频生成的多机位适配规则

### 规则 04：15 秒导演片段允许多主分镜/子分镜
AI 视频模型每次生成的是一个可执行的视频段，但本系统的 15 秒导演片段可以包含多个主分镜/子分镜。因此：
- 15 秒导演片段内部可以切换机位、景别、主体或局部特写
- 每次切换必须由动作锚点、台词落点、受击反应、视线或空间调度触发
- 切换前后必须保持人物、道具、轴线、情绪残留和动作状态连续
- 禁止无动机跳空间、跳轴、跳主体或只为炫技堆镜头

### 规则 05：单段只描述 1-2 个连贯动作
AI视频模型的动作理解能力有限。利用机位切换做减法后，每个生成片段变得更短更简单：
- 只包含 1 个主驱动动作
- 最多叠加 1 个伴随动作（说话时的表情变化）
- 禁止在一段中塞入 3 个以上不相关动作

### 规则 06：人物参考图是多机位一致性的关键
不同生成片段代表不同机位，但拍的是同一个人物。每个生成片段的首帧总控都必须调用人物参考图锁定身份。

### 规则 07：利用机位切换减少模型出错
机位切换不仅是叙事工具，也是降低 AI 生成错误的技术手段：
- 每个生成片段只需要执行简单动作 → 模型准确率高
- 复杂连续动作被拆成多个简单生成片段 → 每段独立可控
- 如果某一段生成效果不好 → 只重新生成这一段，不影响其他

## 六、每种场景类型的多机位推荐方案

### 场景类型 A：人物入场/到达
1. **建立镜头**（全景）— 交代空间，人物从远处走来
2. **跟随镜头**（中景）— 跟拍入场动作，说完台词后迈步（不拍完整走路）
3. **反应镜头**（中近景）— 拍在场其他人的反应
4. **细节镜头**（特写）— 到达目标处的关键动作（按按钮、推门）

### 场景类型 B：两人对话/对峙
1. **过肩镜头**（中近景）— 从一个人的肩背附近看向对方说话
2. **反应特写**（中近景/特写）— 关键台词时拍听者反应
3. **双人同框**（中景）— 展示关系变化
4. **细节镜头**（特写）— 当前剧情真正需要观众看清的关键细节

### 场景类型 C：多人群戏
1. **建立镜头**（全景）— 所有人的站位关系
2. **跟随镜头**（中景）— 跟拍核心人物
3. **反应镜头群** — 分别拍 2-3 个受击者的反应
4. **过肩/越肩** — 从旁观者角度看核心冲突

### 场景类型 D：单人心理/独处
1. **环境关系镜头**（中景/全景）— 让人物与空间处境产生关系
2. **近景停顿**（近景/中近景）— 捕捉呼吸、眼神、姿态变化
3. **焦点转移** — 从人物转到本场真正触发心理变化的信息点
4. **固定留白** — 给情绪消化时间，不用多余动作填满

### 场景类型 E：动作爆发/追逐
1. **可读全景**（全景/中全景）— 交代动作方向和危险关系
2. **动作锚点镜头**（中景/近景）— 在动作完成前切换，承接关键碰撞或闪避
3. **局部冲击**（特写/极特写）— 只拍当前动作真正需要强调的接触、落点或结果
4. **结果反应**（中近景）— 给被影响的人或环境一个明确反馈

### 场景类型 F：空间压入/新人物闯入
1. **原关系镜头**（中景）— 先稳住原本局面
2. **压入镜头**（平移/摇移/切入）— 新信息或新人物直接打断
3. **受击反应**（近景/中近景）— 拍真正承受变化的人
4. **新关系镜头**（中景/全景）— 重新交代局面如何变化

## 七、常见错误与纠偏

### 错误 01：全片只有"跟随中景"
纠偏：强制加入反应镜头、细节镜头或过肩镜头。

### 错误 02：对话戏全程正反打
纠偏：用过肩镜头替代至少一半的正面单人镜头。

### 错误 03：用走路填满生成片段时长
纠偏：用机位切换省略走路，只拍起步和到达。

### 错误 04：一个生成片段内塞太多动作导致AI生成失败
纠偏：利用机位切换把复杂动作拆成多个简单生成片段。

### 错误 05：细节镜头没有叙事动机
纠偏：只有当动作承载剧情信息时才用细节镜头。

## 九、一句话总纲
**像真正的导演一样用多机位覆盖关键动作，用机位切换做减法省略垃圾时间；每个生成片段是一个独立机位的连续拍摄，动作越简单AI执行越准确；短剧要做减法，不做加法。**
