# 24_戏剧微粒识别与节奏触发规则

日期：2026-04-21  
版本：v1.0  
用途：把“权力反转 / 冲突升级 / 悬念揭晓 / 误解错位 / 情绪极点 / Cliffhanger”六类戏剧微粒，转成上游 Agent 可执行的节拍触发规则。  
本文件负责回答三件事：
- 当前片段到底属于哪一种戏剧推进
- 该用什么节拍结构，而不是先用什么镜头
- 哪些内容属于上游节奏判断，哪些内容必须留给下游执行层

---

## 一、总原则

戏剧微粒不是镜头模板，也不是情绪形容词。  
它是上游 Agent 用来判断“这一拍为什么成立”的节奏信号。

一句话要求：  
**先识别戏剧微粒，再决定片段边界、节拍顺序和 Hook 权重；镜头、机位、运镜只能是下游执行结果，不能反向替代节拍判断。**

---

## 二、适用范围与边界

本文件适用于：
- `rhythm_rewrite_director` 对动作层与氛围层的节拍增补
- `story_planner` 对片段边界、Hook 权重、受击空间和收束方式的判断
- `quality_inspector` 对节拍是否被正确兑现的回查

本文件不负责：
- 直接决定景别、焦段、机位和运镜
- 直接改写原剧本对白
- 让上游 Agent 发明下游不存在的新字段

兼容要求：
- 若当前节点输出结构支持显式字段，应优先输出 `rhythm_function / hook_weight / script_basis / boundary_reason / reaction_need`
- 若当前节点结构暂不支持新增字段，则至少必须在文字说明中体现这些判断，不能只给抽象结论

---

## 三、触发工作流

### 流程 A：先识别“当前最强信号”
每个片段必须先判断一个**主戏剧微粒**。  
必要时可附加一个次级微粒，但不得把所有信号堆满。

### 流程 B：再判断 Hook 权重
Hook 权重只服务片段轻重，不服务镜头炫技。  
推荐权重基准：
- `1.0`：权力反转、Cliffhanger
- `0.9`：冲突升级、情绪极点
- `0.8`：悬念揭晓
- `0.7`：误解错位

### 流程 C：再决定节拍结构
每种戏剧微粒必须先落成节拍结构，例如：
- 预压 -> 命中 -> 受击
- 命中 -> 停顿 -> 压入
- 误会加深 -> 反应 -> 关系冻结

### 流程 D：最后才交给下游执行
上游输出的重点是：
- 为什么在这里开段/收段
- 为什么这里要留受击空间
- 为什么这里必须阻断

不是：
- 这里一定用特写
- 这里一定 Crash Zoom
- 这里一定黑屏

---

## 四、六类戏剧微粒

### 规则 01：权力反转（`power_reversal`）
触发词示例：
- 跪下
- 其实我是
- 你以为
- 开除
- 财产转移
- 真面目

节拍判断：
- 前半拍通常是预压或旧秩序维持
- 中段必须出现明确命中
- 后半拍必须给失势方受击或群体冻结

`rhythm_rewrite_director` 执行要求：
- 增补权力失衡被看见的外在反应
- 优先补“谁忽然失去控制、谁忽然掌握场面”
- 不得把反转写成纯解释性独白

`story_planner` 执行要求：
- 允许围绕反转点微调片段边界
- 反转命中后必须留出受击或黄金停顿空间
- 不得把反转和反转解释全部塞进同一拍说满

禁止：
- 低权重嘲讽、普通压人、日常嘴硬，不能冒充权力反转
- 不得把“反转成立”简化成一句台词说完就结束

### 规则 02：冲突升级（`conflict_escalation`）
触发词示例：
- 猛地
- 狠狠
- 冲向
- 闭嘴
- 去死
- 砸

节拍判断：
- 旧压力未解除
- 新压力继续抬高
- 速度、距离或语言强度明显升级

`rhythm_rewrite_director` 执行要求：
- 优先补动作前摇、压迫距离、呼吸变化、手部收紧、停顿压住
- 不得凭空升级出剧本没有的暴力等级

`story_planner` 执行要求：
- 片段应更短、更硬、更少废动作
- 必须预留受击或反应承接
- 若动作复杂，优先拆出可生成的短节拍，而不是一口气拍完

禁止：
- 把冲突升级误做成单纯更吵
- 把升级后的段落继续写成均速说明文

### 规则 03：悬念揭晓（`suspense_reveal`）
触发词示例：
- 这是什么
- 不可能
- 门缓缓打开
- 抽屉的夹层
- 文件袋
- 监控画面

节拍判断：
- 先逼近或停顿
- 再揭示可见信息
- 再给反应或认知塌陷

`rhythm_rewrite_director` 执行要求：
- 优先把“发现前的半拍”写清楚
- 把概括性的“震惊”拆成可见反应
- 不得把揭晓直接写成总结答案

`story_planner` 执行要求：
- 给线索或目标物保留独立信息落点
- 若是关键揭示，优先安排“发现 -> 反应”，必要时解释延后
- 不得在发现前先把答案讲穿

禁止：
- 把悬念揭晓写成背景说明文
- 把低权重道具误升格成重大线索

### 规则 04：误解错位（`misunderstanding`）
触发词示例：
- 听我解释
- 根本不是你看到的那样
- 偷听
- 视角盲区
- 误会

节拍判断：
- 关键不在“谁说得更完整”
- 而在“谁先被错误信息命中”
- 关系冻结通常比真相澄清更重要

`rhythm_rewrite_director` 执行要求：
- 优先补听者反应、眼神躲闪、停顿、关系发冷
- 不得提前替角色解释明白

`story_planner` 执行要求：
- 多给反应承接，少给解释堆叠
- 若误会尚未解除，收束应停在关系僵住而非事情讲透

禁止：
- 把误会段拍成连续说明会
- 误会成立前就提前替角色洗白

### 规则 05：情绪极点（`emotional_peak`）
触发词示例：
- 崩溃
- 无声落泪
- 绝望
- 说不出话
- 心死

节拍判断：
- 外部动作通常减弱
- 内部压力达到顶点
- 节拍应允许显著停留，而不是继续抢速度

`rhythm_rewrite_director` 执行要求：
- 优先补沉默、呼吸、手部失稳、眼神停住、群体静止
- 不得为了“更抓马”乱加砸东西、尖叫、跪地等剧本外动作

`story_planner` 执行要求：
- 可以允许更长的受击与回味窗口
- 但必须保证动作、空间和背景简单，不把情绪极点写成复杂调度

禁止：
- 把情绪极点误做成对白堆积
- 刚到顶点就立刻切回普通节奏

### 规则 06：Cliffhanger（`cliffhanger`）
触发词示例：
- 你敢吗
- 倒计时
- 最后一句威胁
- 门后是谁
- 枪口抬起
- 即将揭晓

节拍判断：
- 片段尾拍必须承担阻断
- 不是把事情讲完，而是把观众卡住
- 命中后不允许再走缓和路线

`rhythm_rewrite_director` 执行要求：
- 优先把尾拍写成动作顶点、信息顶点或关系顶点
- 不得在尾拍后追加解释性缓冲

`story_planner` 执行要求：
- `boundary_reason` 必须明确说明为什么在这里切断
- 尾帧必须留下可续接的关系、空间或动作状态

禁止：
- 把普通转场、普通停顿包装成 Cliffhanger
- 钩子落地后又补完整解释或情绪释怀

---

## 五、多信号并发时的裁决

### 规则 07：每个片段最多 1 个主信号 + 1 个次级信号
若同时命中多个信号，必须先选出主信号，再决定次级信号是否保留。  
优先级建议：
1. Cliffhanger / 权力反转
2. 冲突升级 / 情绪极点
3. 悬念揭晓
4. 误解错位

### 规则 08：先看“这一拍最重要的戏剧变化”，不要平均分配权重
如果一段里既有误会、又有冲突、又有悬念，但真正让观众想继续看的，是“门打开之后谁站在外面”，那主信号应为 `suspense_reveal` 或 `cliffhanger`，而不是把三者写成并列。

---

## 六、节奏改写层边界

### 规则 09：节奏改写只写真实反应，不写抽象气氛
`rhythm_rewrite_director` 在根据戏剧微粒补写动作层和氛围层时，只允许写可拍摄、可观察、可验证的外在反应：
- 视线、停顿、呼吸、手部动作、姿态变化
- 屏幕、门口、桌面、道具、对方脸上的可见落点
- 当前场景内群体或未命名龙套的短促反应

禁止把节奏判断落成抽象句、文学化比喻、拟人化气氛或纯心理独白。

### 规则 10：允许补辅助层与逻辑承接，但不得改主线骨架
若原剧本在当前片段内存在轻微逻辑断口，`rhythm_rewrite_director` 可以补写或删减以下内容：
- 当前场景内未命名龙套的简短反应
- 关键台词前后的动作卡顿、视线落点、短停顿
- 不服务节奏的重复性、概括性、不可拍辅助描述

但不得因此改变：
- 双引号内台词原文
- 主线剧情和关键事件顺序
- 角色认知状态、关系走向与结局方向
- 关键道具因果、空间关系和下一段连续性状态

允许出现的龙套仅限当前场景内合理存在的未命名旁观者，不得新增命名角色，不得让龙套承担关键证据、关键判断或剧情转折功能。

### 规则 11：节奏改写遵守“单拍单锚点”
`rhythm_rewrite_director` 在补写受击、愣住、回神、尴尬、迟疑等人物反应时，每一拍只保留 1 个主反应锚点：
- 优先姿态与站位
- 其次视线
- 再次呼吸或停顿
- 最后才是手部或道具细节

若同一情绪已经由姿态、视线或停顿成立，不得再追加手指、发梢、衣角、杯沿、工牌等次级微观细节。  
只有当该细节承担连续性锚点、关键道具因果或当前唯一受击锚点时，才允许保留。

---

## 七、禁止事项

- 不得把戏剧微粒识别表当成镜头模板表使用。
- 不得把所有高能短剧都硬标为 `power_reversal` 或 `cliffhanger`。
- 不得因为命中了高权重信号，就擅自改写台词、添加新人物或补写剧本外事件。
- 不得让上游 Agent 在没有结构支持时强行捏造新字段；但也不得完全不体现节拍判断。

---

## 八、一句话总纲

**戏剧微粒决定“这一拍为什么成立”，节拍结构决定“这一拍怎么推进”，而节奏改写层只负责把它翻译成真实可拍的反应、停顿与逻辑承接，不负责改写主线骨架。**
