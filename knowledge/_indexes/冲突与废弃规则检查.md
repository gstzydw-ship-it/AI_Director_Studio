# 冲突与废弃规则检查

## Active 规则中声明了 conflicts_with 的条目

```dataview
TABLE rule_id, title, conflicts_with, priority, agent_scope
WHERE status = "active" AND length(conflicts_with) > 0
SORT rule_id ASC
```

## 已废弃规则

```dataview
TABLE rule_id, title, supersedes, agent_scope
WHERE status = "deprecated"
SORT rule_id ASC
```

## 缺少 agent_scope 的规则

```dataview
TABLE rule_id, title, priority, status
WHERE rule_id AND !agent_scope
SORT rule_id ASC
```

## 缺少 rule_id 但疑似规则文档

```dataview
TABLE file.mtime AS "last modified"
WHERE !rule_id AND contains(file.name, "规则")
SORT file.mtime DESC
```
