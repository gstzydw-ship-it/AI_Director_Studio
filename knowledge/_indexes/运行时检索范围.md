# 运行时检索范围

这个页面用来区分“会进入 Agent 检索”的正式规则，以及只用于人工复盘的原始材料。

## 会进入运行时检索

```dataview
TABLE rule_id, title, agent_scope, priority, rule_type
WHERE runtime_retrieval = true AND status = "active"
SORT priority ASC, rule_id ASC
```

## 不进入运行时检索

```dataview
TABLE rule_id, title, status, doc_type, canonicalized_into
WHERE runtime_retrieval = false
SORT status ASC, rule_id ASC
```

## Hard Rules

```dataview
TABLE rule_id, title, agent_scope, priority, applies_to
WHERE runtime_retrieval = true AND status = "active" AND (priority = "P0" OR priority = "P1")
SORT rule_type ASC, rule_id ASC
```
