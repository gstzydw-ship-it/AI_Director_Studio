# 按规则类型索引

## 规则文档

```dataview
TABLE rule_id, title, agent_scope, priority
WHERE doc_type = "rule_document" AND status = "active"
SORT rule_type ASC, rule_id ASC
```

## 手册与参考库

```dataview
TABLE rule_id, title, doc_type, agent_scope, priority
WHERE doc_type = "manual" OR doc_type = "reference_library" OR doc_type = "example" OR doc_type = "casebook" OR doc_type = "governance"
SORT doc_type ASC, rule_id ASC
```

## 原始材料与测试提取

```dataview
TABLE rule_id, title, status, runtime_retrieval
WHERE doc_type = "raw_source" OR doc_type = "extraction_test"
SORT rule_id ASC
```
