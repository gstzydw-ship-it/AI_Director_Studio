# 01_导演分镜总手册

## 文件用途
所有分镜参数的基础定义层。为 02-08 所有文件提供术语基底。

## 适用范围
- 分镜参数的术语对照查询
- 景别/机位/角度/运镜的定义确认

## 不适用范围
- 具体决策逻辑（查对应专项文件）

---

## 一、主体景别七级定义表

| 景别代码 | 中文名 | 画面范围 | 核心叙事功能 |
|----------|--------|----------|--------------|
| ELS | 极远景 | 人物极小或不可见，环境主导 | 建立地理/世界观，上帝视角 |
| LS | 远景 | 人物全身可见，环境占主导 | 交代空间位置，建立格局 |
| MLS | 中全景 | 人物膝盖以上 | 展示完整肢体动作 |
| MS | 中景 | 腰部以上 | 平衡人物与环境，对话基础景别 |
| MCU | 中近景 | 胸部以上 | 人物情绪与动作兼顾 |
| CU | 近景/特写 | 肩部以上，面部占主要区域 | 强调面部表情，情绪核心 |
| ECU | 极限特写 | 面部局部（眼睛/嘴唇）或道具局部 | 最强烈的情绪聚焦，细节放大 |

**强制写法：** 景别前必须有主体。
- 错误：`特写`
- 正确：`陈明面部特写（CU）`

---

## 二、机位高度三级定义

| 名称 | 机位位置 | 叙事效果 |
|------|----------|----------|
| 仰拍（Low Angle） | 机位低于角色视线以下 | 角色显高大/威压/权力感 |
| 平视（Eye Level） | 机位与角色眼睛等高 | 中性客观，无权力倾向 |
| 俯拍（High Angle） | 机位高于角色头部 | 角色显渺小/被困/弱势 |
| 顶拍（Bird's-eye） | 机位正上方，垂直向下 | 上帝视角，地图感，宿命感 |
| 虫眼（Worm's-eye） | 机位极低，地面以下视角 | 极端压迫感，宏大感 |

---

## 三、拍摄角度定义

| 角度名称 | 英文 | 定义 | 使用条件 |
|----------|------|------|----------|
| 正面 | Frontal | 机位正对主体面部 | 直视感，无遮挡 |
| 斜侧面 | 3/4 Angle | 机位在主体 45° 方向 | 立体感，常用对白 |
| 正侧面 | Profile | 机位在主体正侧方 90° | 轮廓清晰，动作冲击力 |
| 背面 | Rear | 机位在主体身后 | 跟随感，主观性 |
| 过肩（OTS） | Over The Shoulder | 从 A 肩膀后方拍 B | 建立双人空间关系 |
| 荷兰角 | Dutch Angle | 画面水平线倾斜 | 心理失衡、环境崩塌 |
| 主观视角 | POV | 模拟角色眼睛看到的画面 | 必须先有建立镜头 |

---

## 四、运镜类型定义表

| 运镜名称 | 英文 | 动作描述 | 典型叙事效果 |
|----------|------|----------|--------------|
| 推镜 | Dolly In | 机位向主体物理推进 | 情绪累积，焦点深入 |
| 拉镜 | Dolly Out | 机位从主体物理后退 | 揭示环境，情绪冷却 |
| 横移 | Truck/Track | 机位水平横向移动 | 跟随角色移动 |
| 横摇 | Pan | 机位固定，镜头水平转动 | 扫视空间，展示关系 |
| 垂直摇 | Tilt | 机位固定，镜头垂直转动 | 展示高度，仰望/低视 |
| 升降 | Crane/Jib | 机位垂直上下移动 | 宏大感，揭示全局 |
| 变焦 | Zoom | 焦距改变，不移动机位 | 快速聚焦（与推镜效果不同） |
| 稳定器跟拍 | Steadicam | 跟随主体移动，画面流畅 | 长镜头，流畅动作展示 |
| 手持 | Handheld | 手持摄像，轻微晃动 | 纪实感、混乱、即时性 |
| 固定机位 | Static | 机位完全固定不动 | 客观观察，稳定叙事 |

**硬规则：每个分镜只允许一种主导运镜。**

## 五、分镜基础格式模板

每个分镜必须包含以下字段（缺一不可）：

```
[时间段] [主体+主体景别] [焦段] [景深] [机位高度] [拍摄角度] [唯一运镜] [动作/表演描述] [光源描述]
```

**完整示例：**
```
[00:00-00:05]
主体：陈明面部特写（CU）
焦段：85mm，浅景深，背景虚化
机位：平视，正面
运镜：固定机位
动作：陈明嘴唇微动，未发声，视线看向画面左侧
光源：左侧冷白窗光，硬光，侧打左脸
```

## 六、POV 视角使用硬规则

主观视角（POV）的正确使用，必须按以下顺序：

```
步骤1：建立镜头（Looker Shot）
  → 客观拍摄"谁在看"，写明角色视线方向

步骤2：POV 镜头
  → 拍摄"这个角色眼睛看到的内容"，方向与步骤1视线一致
```

**禁止：** 跳过步骤1，直接给 POV 镜头。
