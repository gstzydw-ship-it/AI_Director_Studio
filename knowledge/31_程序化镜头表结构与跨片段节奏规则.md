# 程序化镜头表结构与跨片段节奏规则

## 一、核心目的

镜头库和机位库不能只是一堆自然语言案例。它们需要可检索、可路由、可降级、可质检的表结构。表结构可以使用内部字段，但最终导演输出必须转为中文镜头句。

## 二、镜头条目的程序化字段

每个镜头条目至少包含以下字段：

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| 镜头类型 | 关系、发言、反应、动作、信息、转场 | 反应 |
| 主体数量 | 单人、双人、三人、群戏 | 双人 |
| 景别范围 | 远景、全身、七分身、半身、中近、近景、特写 | 半身中景 |
| 观看位置 | 正面微侧、侧面关系、肩后、纵深前后、跟随背侧等 | 从甲肩后看乙 |
| 机位高度 | 平视、略低、略高、高位、低位 | 平视 |
| 运动方式 | 固定、轻推、轻拉、跟随、摇移、手持 | 固定 |
| 适用任务 | 建立、压迫、揭示、受击、回收、动作锚点 | 受击 |
| 触发条件 | 台词落点、动作开始、视线转向、门口出现 | 话音落下 |
| 禁用条件 | 会越轴、会新增道具、会造成多人拥挤 | 入口不明确 |
| 可生成性 | 稳定、中等风险、高风险 | 稳定 |
| 预算等级 | 低、中、高 | 中 |
| 画幅适配 | 9:16、16:9、1:1、2.39:1 | 9:16 |
| 自然中文模板 | 最终可交付表达 | 从甲肩后看向乙，乙停住半拍 |

## 三、机位条目的程序化字段

每个机位条目至少包含：

- 观看对象：看谁。
- 观看路径：从哪里看向哪里，不用左右作为唯一依据。
- 与轴线关系：同侧、跨轴风险、需要关系镜头复位。
- 空间锚点：桌子、门、沙发、车门、走廊、窗边等真实物。
- 人物锚点：近处人物、远处人物、说话者、听者、被打断者。
- 可见范围：全身、半身、肩部、手部、道具等。
- 交接条件：台词意群、动作锚点、视线转向、反应出现。
- 下游改写建议：把内部术语翻译成可见画面语言。

## 四、跨片段景别节奏管控

镜头导演不能只看单个片段。每次输出前要检查最近三到五个片段的开头镜头、结尾镜头和主力景别。

基础规则：

- 上一片段以强特写结束，下一片段优先用关系镜头或半身中景重新建立空间。
- 上一片段连续两次用同类中近景，下一片段应换成关系、动作、纵深或不同观看位置。
- 同一场景连续约三十到四十五秒，应出现一次关系复位、空间复位或视觉模式变化。
- 如果尾帧要求强继承，允许连续景别，但必须改变任务：上一镜是受击，下一镜可以是回收或反击。
- 不要为了多样性破坏轴线、人物位置和剧本事实。

## 五、动作戏专项规则

动作戏优先可读性，不优先炫技。

基础链条：

1. 动作前摇：拍清谁先动、身体重心怎么变。
2. 动作切点：接触前、接触瞬间或动作完成一半时切出。
3. 受击反应：拍身体后退、停住、扶住、回头、看向对方。
4. 结果回收：拍距离变化、道具状态、其他人反应。

禁用：

- 一个镜头同时写快速运镜、快速动作和快速切镜。
- 只写“打斗很激烈”“动作凌厉”，没有身体部位、方向和结果。
- 把复杂动作完整塞进一个长镜头。

可用表达：

- 人物甲抬手逼近，镜头在他肩侧跟住半步，手还没碰到人物乙时切出。
- 人物乙后退半步撞到桌边，手按住桌沿稳住，抬眼看回人物甲。

## 六、群戏与动作混合场面

四人以上动作不能让所有人同时乱动。先锁定主动作，再锁定受影响区域。

- 主动作区：动作发生点。
- 受击区：被动作影响的人。
- 旁观区：只有有信息变化的人才给反应。
- 出入口区：有人进入或离开时才切。

## 七、长焦极端焦段边界

极端长焦或强压缩只用于：

- 远距离审视或监视。
- 公共空间里人物被压扁、被隔开。
- 危险感、被跟踪感、不可接近感。
- 道路、走廊、玻璃、会议室长桌形成的压缩关系。

不用于普通亲密对白，不作为默认高级感。

## 八、表结构到自然输出的翻译

内部表结构：

| 镜头类型 | 景别 | 观看位置 | 任务 |
| --- | --- | --- | --- |
| 反应 | 中近景 | 肩后 | 听者受击 |

最终输出：

乔熙中近景，从商北琛肩后看过去，商北琛的肩线只留在画面边缘；乔熙听完后停住半拍，眼神压回他身上。

禁止输出：

肩后反应中近景，听者受击。

## 九、人工确认项的临时规则

- 景别匹配权力差：系统可自动提示，但不强制每次执行；显性用户要求和剧情事实优先。
- 正反切是否独立编码：运行时保留检索标签，最终输出不用编码。
- 四十秒节奏规则：先作为软约束，不拦截输出，只提示风险。
- Seedance 稳定性排序：目前为经验排序，后续需要实测表回写。
