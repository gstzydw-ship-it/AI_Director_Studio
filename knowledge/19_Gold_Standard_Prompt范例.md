# 19_Gold Standard Prompt 范例

日期：2026-04-13（v2.0 修订）
版本：v2.0
用途：为 Prompt Compiler 提供最终输出的完整范例，所有编译输出必须在格式、结构、语言风格上对齐本范例。

---

## 一、本文件的地位

本文件是 **最终输出格式与语言风格的唯一权威标准**。

规则冲突时的优先级：
1. 本文件的范例风格 > 其他文件的格式描述
2. 剧本原文忠实度 > 任何规则的扩展建议
3. 逻辑正确性（空间/动作/方向） > 表情堆砌
4. 简洁的导演调度语言 > 文学化描写

---

## 二、输出格式模板（必须严格遵守）

每个片段的输出必须严格按以下结构：

```
片段{N}｜{场景名}｜{情绪/动作关键词，用+连接}｜~{秒数}秒

【风格锚点】
{一句话风格定义。}

【画幅锚点】
{画幅比例+方向。如"9:16竖屏"或"16:9横屏"。}

【空间与首帧总控】
{场景空间布局、轴线方向、光线基底、人物首帧位置关系。不写时间码。}

【时间轴】

{起始秒}-{结束秒}秒：{用简洁的导演调度语言描述画面内容。}

{起始秒}-{结束秒}秒：{同上。}

{起始秒}-{结束秒}秒：{同上。}

【约束】
{空间轴线、人物服装发型、道具连续性、禁止项。简洁列出；不得写“主体锁定”“不抢中心”“镜头保持稳定”等压死调度的霸王约束。}

片段{N} prompt 已输出。
请生成视频后，上传：

片段{N}的尾帧截图
当前人物位置关系（若有变化）

我将基于实际尾帧继续输出片段{N+1}。
```

### 范例 A：商北琛空降大堂（9:16竖屏，实际验证通过）

```
片段1｜天御集团大堂｜空降入场+冷面发令+人群四散+进入电梯｜~15秒

【风格锚点】
都市职场冷感现实风，镜头克制干净，权力感通过调度和表演传递。

【画幅锚点】
9:16竖屏。

【空间与首帧总控】
天御集团大堂挑高明亮，主入口在后方，前台与电梯厅在前方，众员工分列两侧让出一条中轴通道，严飞站在商北琛右前方的通道边线，半侧身让出中轴。场面轴线沿入口到电梯方向建立，整体是冷白商务顶光，空间干净克制。

【时间轴】

0-4秒：玻璃门打开，商北琛穿深色西装大步走进大堂，镜头正前方中景后退跟着商北琛，众员工分列两侧安静让路，商北琛目光淡淡扫过左右人群，步速稳定不减。

4-7秒：严飞停在右前方边线，半侧身让路，微微弓身说："商总，欢迎。" 镜头保持商北琛胸部以上近景，严飞只以侧前景或画外声进入，商北琛不接话，只是眉头轻皱，视线越过严飞落向前方电梯。

7-12秒：商北琛停步半转身，目光扫过两侧主管，冷声说："十分钟后开会，总监以上级别，必须到场。" 话音落下，几名主管立刻四散离开，脚步声急促穿过大堂。

12-15秒：商北琛重新转身走向电梯，镜头从斜侧跟到电梯门前，电梯门打开又开始缓缓合拢，商北琛进入电梯，尾帧收在正在合上的门缝。

【约束】
本片段中商北琛是主导主体，不寒暄，不停顿；严飞始终保持侧前方让路姿态，不迎上阻挡中轴，不穿越商北琛行进路线；众员工只做让路和散开；大堂冷白顶光、入口到电梯的空间轴线、商北琛深色西装状态全程连续。

片段1 prompt 已输出。
请生成视频后，上传：

片段1的尾帧截图
当前人物位置关系（若有变化）

我将基于实际尾帧继续输出片段2。
```

### 范例 B：室内情绪压制场景（9:16竖屏）

```
片段1｜公寓内｜情绪压制 + 自我命令 + 出发｜~12秒

【风格锚点】
欧美真人豪门短剧风格。

【画幅锚点】
9:16竖屏。

【空间与首帧总控】
清晨室内，柔和的自然光从画面一侧窗户方向透入，光线偏暖但不浓烈。乔熙坐在沙发边缘或床沿，微微低头，手中捏着一张照片，书包放在身旁触手可及的位置。小豆丁不在首帧画面主区域内，在乔熙身后或侧后方。空间安静、私密。

【时间轴】

0-4秒：乔熙半身中景，镜头正面平视固定机位。乔熙猛地回过神，手中照片微微一抖，嘴唇压紧，眼眶有一层极薄的水光但没有落泪。她垂下视线看着手里的照片，柔和侧光勾出她脸侧轮廓，背景退成柔虚暖色块。

4-8秒：保持乔熙半身景，平视固定机位。她深吸一口气，视线从照片上移开，把照片果断塞回身旁的书包里，动作干脆但手指最后离开照片时有一丝迟滞。乔熙OS："It's been four years. He's married with a kid now. Sunny, wake up." 说到"wake up"时她眼神重新聚焦，嘴角微微收紧，像在给自己下一道命令。

8-12秒：乔熙中近景，镜头轻微推近。她吐出一口长气，肩线慢慢松下来，表情迅速收回，嘴角撑起一个不太自然的微笑。她转头看向小豆丁方向，声音轻快但底下还压着一点沙哑："Come on, baby, let's go. Gonna be late." 她伸手拿起书包，站起身，一只手自然地伸向孩子方向。

【约束】
当前主体为乔熙，小豆丁仅作为视线和动作对象存在。全程平视，不使用仰拍。镜头慢、稳、克制。乔熙情绪从内伤压制到强撑温暖，不夸张表演，不掉泪。照片塞回书包后不再出现在手中。画面洁净，不额外生成人物。

片段1 prompt 已输出。
请生成视频后，上传：

片段1的尾帧截图
当前人物位置关系（若有变化）

我将基于实际尾帧继续输出片段2。
```

### 范例 C：过肩对话镜头（9:16竖屏，对话场景核心拍法）

```
片段3｜电梯内｜过肩对峙+挑衅对白+听者受击+松手退步｜~13秒

【风格锚点】
都市职场冷感现实风，电梯内逼仄空间感，镜头克制不乱动。

【画幅锚点】
9:16竖屏。

【空间与首帧总控】
电梯内封闭空间，门已关闭。商北琛背靠电梯内壁站在画面纵深处，面朝镜头方向。乔熙在商北琛身前，扑在他身上，双手抓着他的西装前襟。商北琛右手扶在乔熙腰侧。镜头从乔熙肩后方向拍向商北琛面部——乔熙的后脑和肩线在画面前景虚化，商北琛的面部在后景清晰可见。冷白电梯顶光，空间窄。

【时间轴】

0-4秒：过肩中近景，乔熙后脑和右肩在画面左侧前景轻微虚化，商北琛面部在后景清晰。商北琛视线低垂看着怀里的乔熙，嘴角微微上扬，带一丝冷意。他开口，语调轻慢："Long time no see—since when did you start throwing yourself at people?" 说话时下颌微抬，眼神居高临下。

4-8秒：保持过肩构图不变，镜头不动。商北琛说完停了一拍，嘴唇轻抿。乔熙在前景虚化处身体微微僵住，后脑轻微一顿——能感到她被这句话钉住了。商北琛紧接着补上第二句："You gonna keep holding on or what?" 眉梢轻挑，嘴唇收句后微抿，眼神带着审视的等待。

8-13秒：镜头从过肩构图缓缓推近到商北琛胸部以上中近景，乔熙前景肩线退出画面。与此同时乔熙触电般松开双手，向后退半步——她的动作在画面边缘以身体位移的形式可见。商北琛站在原位不动，看着她退开，嘴角的冷意淡去，表情回归平静审视。尾帧定格在商北琛中近景独占画面，乔熙已退出前景。

【约束】
镜头类型为过肩镜头，前景始终是乔熙（虚化），焦点始终在商北琛面部。全程平视。乔熙只以前景虚化身形和动作参与画面，不切到她的正面。道具状态链：0-8秒乔熙双手抓着西装→8秒松开→8-13秒双手空出。商北琛全程右手扶腰→13秒乔熙退开后手自然放下。

片段3 prompt 已输出。
请生成视频后，上传：

片段3的尾帧截图
当前人物位置关系（若有变化）

我将基于实际尾帧继续输出片段4。
```

```

9:16竖屏。

电梯内封闭空间。乔熙胸部以上中近景，正面平视，浅景深。乔熙面朝镜头方向，视线斜上方看向画面外的商北琛（商北琛不在画面中）。电梯内壁在乔熙身后虚化。乔熙双手仍抓着商北琛西装前襟（手在画面下方边缘可见）。

片段2 prompt 已输出。
请生成视频后，上传：

片段2的尾帧截图

### 范例 F：双人关系变化 + 受击递进（9:16竖屏，同一片段内焦点转移）

```

都市情感冷暖交织，镜头从克制的双人关系景逐步收窄到受击者。

【画幅锚点】
9:16竖屏。

咖啡厅半封闭包间。双人面对面坐在小桌两侧，徐斯礼坐在画面纵深处面朝镜头方向，时知渺坐在近景侧背对镜头。桌面上两杯咖啡，暖色壁灯从画面左侧打出柔光，背景虚化。镜头从时知渺肩后方向拍向徐斯礼——过肩构图，时知渺后脑和肩线在前景轻微虚化。

0-4秒：过肩中近景，时知渺肩线在前景虚化，徐斯礼面部在后景清晰。徐斯礼端起咖啡杯轻抿一口，放回桌面，视线从杯子缓缓抬起落在时知渺方向，语调平静：“你那天从医院出来，是第几次了？”

8-13秒：镜头从过肩构图缓缓平移加转向，越过徐斯礼肩侧，最终落到时知渺中近景正面。时知渺的表情从侧面逐渐转为正面可见——嘴唇压得发白，下颌线绷紧，视线从徐斯礼方向移开落向桌面咖啡杯，右手无意识握紧杯身。呼吸停了一拍后缓慢恢复，喉间压下一次吞咽。尾帧定格在时知渺中近景独占画面，视线低垂，手指仍握着咖啡杯。

| 范例 D | 反应特写 | 只拍听者，说话者以画外音存在 |
| 范例 E | 建立镜头 | 先拍空间全景，再逐步引入人物 |
| 范例 F | 焦点转移 | 同一片段内从说话者过渡到受击者，过肩到正面 |

编写 prompt 时，应根据当前片段的拍摄意图选择最接近的范例作为风格参考。

## 五、从范例中提取的硬约束

### 语言风格核心原则
1. **用简洁的导演调度语言**，不用文学化描写。"大步走进大堂"而不是"肩背挺直几乎无晃动，步幅均匀"
2. **表情只写关键状态**：眉头轻皱、目光淡淡扫过、嘴唇压紧。不堆砌微表情（不写"眉心压出一道浅褶，睫毛几乎不动，呼吸节奏平稳却冷硬"）
3. **运镜用口语化调度**："镜头正前方中景后退跟着商北琛""镜头切到商北琛近景""镜头从斜侧跟到电梯门前"
4. **一句一个动作**，不在一句中塞多个并列的微表情
5. **逻辑正确性是第一优先级**：人物进出方向、空间位置、动作顺序不能出错

### 格式硬约束
1. **标题行格式**：`片段N｜场景名｜关键词｜~秒数秒`，使用全角竖线 `｜` 分隔
2. **必须包含5个方括号段落**：【风格锚点】、【画幅锚点】、【空间与首帧总控】、【时间轴】、【约束】
3. **时间轴格式**：`起始-结束秒：` 开头，然后是简洁的画面描述
4. **尾部交互提示**：每个片段末尾必须附带尾帧上传提示模板

### 逻辑正确性检查清单（最高优先级）
1. 人物进出画面的方向是否合理？（不能倒着走进电梯）
2. 人物空间位置是否前后一致？（不能上一句在左边下一句跳到右边）
3. 动作顺序是否合理？（先走到门前，才能开门）
4. 道具状态是否连续？（手里的东西不能凭空消失）
5. 视线落点是否合理？（不能看着对方说话但视线在别处）

### 禁止项
1. 禁止使用 YAML 格式输出
2. 禁止使用教学标签（"主分镜1：""子分镜2.1："）
3. 禁止堆砌微表情描写（一句话同时写眉头+睫毛+呼吸+下颌+鼻翼）
4. 禁止编造剧本中不存在的台词、对白、旁白或新情节
5. 禁止把场景名当主体写景别（"大堂中景"应改为具体镜头描述）
6. 禁止使用过于专业的技术术语（"平视3/4角度"应改为自然的"镜头正前方""镜头斜侧跟"）

## 六、一句话总纲
**最终输出像范例 A-E 那样——根据当前片段的镜头类型（跟随/过肩/反应/建立/细节），用简洁的导演调度语言，一句一个动作。不同类型的镜头有不同的写法重点：跟随镜头重动作，过肩镜头重空间关系，反应镜头重微表情，建立镜头重全局。核心是保证人物空间、动作方向、逻辑顺序不出错。**
