# 18_情绪锚点与逐段交互与仰拍限制补丁

日期：2026-04-11
版本：v1.0
用途：补足三个高频问题——情绪表现缺失、片段首尾帧连接弱、仰拍滥用。本文件不改写原导演体系，只把三项新规则提升为硬约束。

---

## 一、人物情绪锚点规则

### 问题描述
时间轴频繁只写功能动作（走、坐、说、拿），人物像没有情绪的执行机器。故事节奏划分虽然有炸点和受击标注，但最终 prompt 中缺少对应的情绪可见表现。

### 规则 01：每个时间段必须至少有一个情绪表现锚点
当前主体人物在每个时间段中，必须有至少一个可见的情绪表现。
可见情绪表现必须落到可拍层级，包括但不限于：
- 眼神：定住、游移、躲闪、下垂、锐利、失焦
- 睫毛：僵住、颤动、快速眨动、停顿
- 嘴唇：压紧、发白、微张、抿住、嘴角下拉、咬住下唇
- 下颌：绷紧、收住、轻微打颤、一字线
- 吞咽：喉结上下、干咽
- 呼吸：停顿、发紧、加速、深吸一口、屏住
- 鼻翼：轻张、抽动
- 手指：收紧、松开、指节发白、无意识搓动、握拳
- 肩背：发僵、塌下、后缩、前倾
- 重心：后退半步、前倾、站不稳、重心偏移

### 规则 02：禁止空泛情绪词独立使用
以下词汇不得单独作为情绪描写：震惊、难过、复杂、压抑、冷淡、克制、紧张、害怕、愤怒、心虚。
若必须使用，后面必须跟可见的身体表现。
- 错误：时知渺很震惊。
- 正确：时知渺眼神一下定住，嘴唇微张又收住，喉间压下一次吞咽。

### 规则 03：情绪变化节点必须有可见转折标记
当人物情绪在片段内发生变化（如从平静到受击、从克制到崩溃前兆），变化节点必须有明确的可见转折：
- 原本平静的嘴唇突然压紧
- 原本稳定的视线突然躲开
- 原本放松的手指突然收紧
- 呼吸节奏突然断了一拍

### 规则 04：不同节拍功能的情绪写法侧重
- 建立段：情绪基底状态（平静、警觉、疲惫等），用姿态和呼吸节奏体现
- 预压段：微小紧张信号（手指无意识动作、视线频率变化、呼吸略快）
- 逼近段：压力逐步上升（嘴唇越来越紧、肩背越来越僵、视线越来越集中）
- 炸点段：命中瞬间的身体反应（停顿、定住、呼吸卡住）
- 受击段：第一反应必须是身体和面部（不是心声和解释）
- 压入段：旧情绪未消化 + 新压力叠加（面部尚未恢复 + 新的视线被迫转移）
- 停顿段：悬住（所有微动作暂停，画面安静）
- 收束段：情绪着陆（呼吸缓慢恢复、视线重新落定、手指慢慢松开）


### 规则 04-1：情绪锚点数量与写法精度

情绪锚点的数量和精度应与节拍功能匹配，不堆砌：

- **建立段 / 收束段**：1 个核心情绪锚点即可（用姿态或呼吸节奏体现）
- **预压段 / 逼近段**：1-2 个递进锚点（微小信号逐步升级）
- **炸点段 / 受击段**：1 个核心命中反应 + 最多 1 个身体伴随反应
- **停顿段**：0-1 个，停顿本身就是锚点

写法原则对齐 19 号 Gold Standard：
- 一句一个情绪动作，不在一句中堆砌多个并列微表情
- "嘴唇压紧" 优于 "嘴唇压紧、发白、微微发颤、嘴角下拉"
- 核心锚点要精准命中，不是越多越好

### 规则 05：情绪状态链必须跨片段连续
- 上一片段结尾人物处于受击状态，下一片段开头不得直接恢复正常
- 情绪恢复必须有过程（哪怕只是一句"呼吸慢慢回来"）
- 情绪升级也必须有过渡（不得从平静直接跳到崩溃，除非有极强炸点命中）

## 二、逐段交互式输出规则

### 问题描述
一次性输出所有片段时，片段之间的首尾帧连接很弱，人物朝向、姿态、光线、道具状态经常断裂。原因是系统无法看到实际生成的尾帧画面。

### 规则 06：默认工作流为逐段交互
用户输入剧本后，执行以下工作流：

**阶段一：整场拆片**
1. 完成整场的戏剧任务分析
2. 完成整场的拆片骨架（所有片段边界、主分镜骨架、完整发言单元）
3. 向用户展示拆片方案（列出每段的时间范围、核心戏剧任务、主体）
4. 确认拆片方案后，进入逐段输出

**阶段二：输出第一段**
5. 输出第一段的完整 Seedance prompt
6. 在输出末尾提示：
   ```
   第一段 prompt 已输出。
   请生成视频后，上传：
   1. 第一段的尾帧截图
   2. 当前人物位置关系图（若有变化）
   我将基于实际尾帧继续输出第二段。
   ```

**阶段三：后续每段**
7. 用户上传尾帧图或完整视频（和/或人物位置关系图）后：
   - 先分析尾帧图/视频中的实际状态：人物朝向、姿态、位置、表情状态、光线、道具、服装细节、微小物理状态
   - 将分析结果与已锁定的下一段拆片骨架对照
   - 确认首帧总控（基于实际尾帧/视频分析而非想象）
   - 输出当前段的完整 Seedance prompt
   - 再次提示上传下一段尾帧图/视频
8. 重复至所有片段输出完毕

### 规则 07：尾帧图分析必须覆盖的信息
收到尾帧图后，必须从中提取并写入下一段首帧总控：
- 人物实际朝向（面朝哪个方向）
- 人物实际姿态（站/坐/倚靠/前倾/后仰）
- 人物实际位置关系（谁在左、谁在右、距离感）
- 手部状态（手放在哪、是否握物）
- 道具状态（手中物、身边物、桌面物）
- 服装状态（领口、袖口、外套、配饰）
- 表情/情绪残留状态（上一段结尾的情绪是否还在脸上）
- 光线实际方向与色温
- 景深与构图关系

### 规则 07-1：视频分析的额外信息（优先级高于静态尾帧）
当系统提供了完整视频分析结果时，除上述尾帧图分析项外，还应从中提取：
- **运动方向与速度**：人物在视频末尾是否正在移动，朝什么方向，速度多快
- **空间锚点变化**：人物在整段视频中的位移轨迹，最终停在什么位置
- **透视与机位关系**：镜头在视频中是否有运动，最终停在什么角度
- **动作完成度**：主驱动动作是否已完全结束，还是正在进行中
- **环境变化**：光线是否变化（如电梯门关闭导致光线变暗）

视频分析结果比静态尾帧提供更丰富的时间维度信息。  
当视频分析结果与预规划的空间描述冲突时，**以视频分析结果为准**（地面真相优先）。

### 规则 08：尾帧图/视频分析不改写拆片骨架
已锁定的拆片骨架（片段边界、主分镜骨架、完整发言单元）不因尾帧图或视频分析而改变。
尾帧图/视频分析只影响：
- 首帧构图继承
- 人物朝向确认
- 姿态接续
- 光线基底
- 道具状态确认
- 微小物理状态
- 情绪残留状态
- 运动趋势接续（视频分析独有）

### 规则 09：用户可跳过逐段交互
若用户明确要求以下任一：
- "一次性输出所有片段"
- "不用等尾帧图"
- "先全部输出再说"
则跳过逐段交互，按原有工作流一次性输出。
但需在输出开头提醒："注意：一次性输出模式下，片段间首尾帧连接基于推测而非实际画面，建议生成后逐段校验连续性。"

## 三、仰拍限制规则

### 问题描述
输出的 prompt 中出现大量仰拍镜头，但绝大多数场景不需要仰拍。仰拍被当成了"让画面更有力"的通用手段，而非叙事工具。

### 规则 10：默认机位高度为平视
除非有明确叙事理由，所有镜头默认使用平视（Eye Level）。
平视是最中性、最客观、最稳定的机位高度，适用于绝大多数场景。

### 规则 11：仰拍的合法使用场景（穷举）
仅以下情况允许仰拍：
1. 剧本明确写"仰望""抬头看""从下方看"等动作
2. 当前戏剧任务为"权力压制"，且需要视觉强化压制方的威压感
3. 建筑、天空、高处物体等空间场景，且有明确叙事动机（如角色仰望高楼表现渺小）
4. POV 镜头中，视角主体正在仰望某人或某物

### 规则 12：仰拍的禁用场景
以下场景禁止使用仰拍：
- 日常对白
- 解释段
- 受击段（受击者不应被拍得高大）
- 情感段（告白、安慰、温暖场面）
- 没有明确权力关系差异的双人对话
- 群体场面中无特殊叙事需求的人物

### 规则 13：一个 15 秒片段最多 1 次仰拍
即使场景合法，一个片段内仰拍也不得超过 1 次。
若已有 1 次仰拍，后续镜头必须回到平视或其他机位高度。

### 规则 14：俯拍同样需要叙事理由
俯拍（High Angle）比仰拍限制略宽，但同样需要叙事理由：
- 表现角色弱势/被困/渺小
- 上帝视角建立空间
- 顶拍展示地理关系
不得把俯拍当成"另一种让画面更有趣"的随意选择。

### 规则 15：输出前仰拍自检
输出前，若发现当前片段中出现仰拍，必须完成以下自检：
1. 当前场景是否属于规则 11 列出的合法使用场景？
2. 若改为平视，是否能完成同样的叙事效果？
3. 若平视可以完成，则改回平视。
4. 若确实需要仰拍，在约束段中写明理由。

## 四、同一片段内切镜道具连续性规则

### 问题描述
现有道具状态链规则只管跨片段的连续性。但在同一个15秒片段内部，当镜头从角色A切到角色B再切回角色A时，角色A手中的道具会凭空消失或变化，没有任何放下/收起的过渡动作。

### 规则 16：切镜不等于道具重置
同一片段内部的镜头切换（切到其他主体、切到局部、切到受击者），不改变任何角色的道具持有状态。
切回该角色后，道具必须仍在原位，除非在切镜前后的时间轴中显式写出了状态变化。

### 规则 17：单手持物变双手做事，必须写过渡
当角色需要从"一只手拿着某物+另一只手做事"变成"双手做事"时，必须在时间轴中显式写出以下任一过渡：
- 挂断/关闭 → 放到桌上/口袋/旁边
- 夹在肩膀和耳朵之间（如手机）
- 递给旁边的人
- 塞进口袋/包里
不得在切镜后让物品默认消失。

### 规则 18：约束段应写明道具状态时间线
当同一片段中道具状态发生变化时，约束段中应写明完整的道具状态时间线。
格式示例：
`道具状态链：0-3秒手机在右手 → 3秒挂断放到桌上 → 3秒后双手空出 → 12秒拎起书包`

### 规则 19：输出前逐时间段道具自检
输出完成后，逐时间段检查：
1. 上一个时间段角色手中有什么？
2. 当前时间段角色手中有什么？
3. 若有变化，中间是否写了过渡动作？
4. 若没写，必须补写。

### 典型错误案例
- 错误：乔熙0-3秒一只手拿手机打电话，3-7秒切到小豆丁视角后乔熙双手穿衣服——手机凭空消失。
- 正确：乔熙说完电话后，显式写"挂断电话，把手机放到旁边桌上"，然后双手穿衣服。
- 错误：角色端着咖啡杯说话，切到对方反应再切回来，角色双手交叉抱胸——咖啡杯消失。
- 正确：切回前写"把咖啡杯放到桌面上"，或切回后角色仍端着咖啡杯。

## 五、与现有知识库的边界

本补丁不改写：
- 15 秒拆片规则（见 05）
- 主分镜 / 子分镜层级（见 03）
- 对白嵌入方式（见 04）
- 景别定义与画幅策略（见 01、13）
- 焦段与景深（见 02）
- 空间连续性（见 06）
- 动作精细化（见 14）
- 故事节奏与分镜联动（见 15）
- 运镜联动（见 16）
- 最终 prompt 结构（见 07）
- 模型适配（见 10）

本补丁只补足：
1. 时间轴中人物情绪表现的可见化
2. 逐段交互式输出工作流
3. 仰拍限制
4. 同一片段内切镜时的道具连续性

---

## 六、一句话总纲
**每个时间段必须有可见的情绪表现锚点；每段 prompt 输出后等用户上传尾帧图再出下一段；默认平视，仰拍需要明确叙事理由；同一片段内切镜时道具不得凭空消失，状态变化必须显式写出过渡动作。**
