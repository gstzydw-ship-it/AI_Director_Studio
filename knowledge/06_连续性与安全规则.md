# 06_连续性与安全规则
日期：2026-04-07  
用途：用于约束场面总控、人物空间连续性、场景继承、参考图继承、视线轴线、道具动作接续与私密场景安全。

---

## 一、总原则
连续性不是结尾总结，而是要压进每一个镜头。  
人物、场景、道具、动作、朝向、轴线、视线关系都必须在分镜层面保持稳定。

一句话要求：  
**新场景先做场面总控，同场景继承参考图；后续镜头只写变化，不得丢失人物关系与动作接续。**

---

## 二、场面总控规则

### 规则 00：场面状态合同优先于镜头描述
连续性必须先以结构化状态合同存在，再进入自然语言分镜。  
每个片段至少要有：
- 当前活跃人物名单：谁允许出现在本段。
- 退场/不可见人物名单：谁来自上一段尾帧，但本段必须不出现。
- 首帧状态：人物、轴线、门、车、道具、身体接触的初始状态。
- 尾帧状态：本段结束时必须留下的状态。
- 状态转移：门/车/道具/人物接触如何单向变化。
- 禁止项：不得复活的人、不得回弹的门、不得提前发生的反应。

镜头导演可以改变景别、机位和切镜，但不能改写状态合同。  
Prompt 编译器只能把状态合同翻译成可执行语言，不能因为尾帧里看见某人就把他重新带进当前戏份。

### 规则 01：新场景无参考图时，必须先做场面总控
若为新场景且用户尚未提供位置参考图，则必须在正式分镜前先输出一段**场面总控 / 人物位置关系**。  
场面总控至少交代：
1. 谁在什么位置
2. 谁和谁相对而坐 / 站
3. 谁在左前方 / 右前方 / 对侧 / 门口 / 窗边
4. 主要视线对象是谁
5. 场面轴线如何建立
6. 关键光线关系是否稳定

### 规则 02：场面总控不是分镜
场面总控不属于任何单个分镜条目。  
因此：
- 不写时间码
- 不写成某个具体镜头内容
- 不计入某个具体分镜时长

场面总控的作用是：
- 建立空间底图
- 让后续分镜有继承依据
- 避免把空间说明误写成镜头说明

### 规则 03：同场景且有参考图时，默认继承，不重复总控
若用户已为同一场景上传人物位置参考图、站位图、调度图或构图图，则该参考图视为该场景的空间母锚点。  
后续所有分镜默认继承该空间关系，不得随意改动：
- 谁在左、谁在右
- 谁与谁对坐 / 对站
- 谁在门口 / 窗边 / 桌侧 / 床边
- 主体朝向对象
- 主要场面轴线

### 规则 04：同一场景默认继承，不重复乱建
在同一场景内，如果人物没有明确移动、换位、起身、靠近、退开、绕行、转身，则后续镜头应默认继承原有空间关系。  
不要在每个镜头里重新发明人物站位。  
正确做法：
- 继承旧锚点
- 只写新变化
- 镜头只交代本次取景部分

---

## 三、空间连续性规则

### 规则 05：不能只用“画面左/右”代替人物关系
“看向画面左侧 / 右侧”只能作为补充，不得作为唯一空间描述。  
必须优先写成：
- 看向桌对面的时知渺
- 看向自己右前方的徐斯礼
- 朝门口方向抬眼
- 视线越过桌面落到对面人的脸上

### 规则 06：切近、切特写、切反应时不得丢失对象锚点
镜头切近以后，不能只剩脸部或局部。  
仍须保留以下任一信息：
- 正在看谁
- 正在对谁说话
- 正在被谁击中
- 机位落在谁的肩线外
- 视线落到场景哪个具体位置

### 规则 07：切镜不等于重建空间
若同一场景的空间关系已经由参考图或场面总控建立，后续切到近景、特写、反打、局部镜头时，默认仍沿用原有空间关系。  
不得因为镜头变近就随意改写人物左右、对坐、朝向。

---

## 四、视线与轴线规则

### 规则 08：首次建立后，后续镜头必须守轴
场面轴线一旦建立，后续镜头不得无理由翻轴。  
需要切到对方特写或反打时，仍应保持可理解的左右关系与对视关系。

### 规则 09：视线方向必须服务对象，而不是服务画面文字
优先写“盯着时知渺”“朝桌对侧的人抬眼”“看向门口方向”，不要优先写“看向画面右侧”。

### 规则 10：反打镜头必须保住原场面关系
反打时不得把原有对坐关系拍成并排关系，不得把原本右前方对象写成左后方对象。

---

## 五、人物动作接续规则

### 规则 11：动作接续必须落到具体身体部位
当人物在前一镜已做出明确动作时，后一镜要延续该动作，而不是重新开始一个不相关动作。  
例如：
- 前一镜手势悬在半空，后一镜不能直接变成双手垂下，除非说明放下
- 前一镜视线盯住对方，后一镜不能突然望向别处，除非说明转移
- 前一镜正在起身，后一镜不能已经站稳，除非补足起身过程

### 规则 12：局部特写必须承接前镜动作逻辑
局部特写不是插图。  
若切到手、腹部、钥匙、衣角、桌角、门把等局部，必须说明它为何在此刻出现，并承接上一镜的心理或动作逻辑。

### 规则 12-1：尾帧可见人物不等于当前戏份人物
上一段尾帧/视频分析只提供首帧空间事实，不自动把尾帧里所有人物继承为下一段可见人物。  
当前片段允许继续出现的人，必须满足以下至少一项：
- 当前 `source_script_events` 明确包含该人物动作或台词。
- 当前 `main_shots` 明确将该人物作为主体、关系对象或受击者。
- 当前剧本事件需要该人物维持同框关系，否则剧情无法理解。

如果尾帧里可见的人在当前片段没有动作/台词：
- 不调用该人物参考图。
- 不把该人物写成门外、侧后方、前景或背景残留。
- 可以写“该人物已退出画面/不再出现”，但不要继续安排站位。

判例：严飞在上一段大堂中可见，只说明上一段空间关系；若下一段剧本只写商北琛进电梯、乔熙冲入，则严飞必须退出画面，不得保留为电梯门外侧后方人物。

### 规则 12-1-1：尾帧图本身承担场景继承
如果上一段尾帧图已经包含当前主要场景、构图、光线和人物站位，则该尾帧图同时承担：
- 首帧参考
- 场景参考
- 构图参考
- 光线参考
- 轴线参考

此时不需要再重复调用单独场景参考图，除非下一段会进入尾帧图外的新空间。  
Prompt 中只需用短句绑定尾帧图，不要把尾帧图内容长篇重写。  
文字应只补充尾帧图不能直接保证的动作连续性：谁开始动、朝哪里动、门/道具状态如何变化、谁不再出现。

### 规则 12-2：门与阈值状态必须单调
电梯门、房门、车门、闸门等阈值物体在同一片段内必须按一个物理方向推进。  
常见合法链路：
- 门开着 → 人物进入 → 门开始合拢 → 门继续合拢
- 门半开 → 人物从门缝进入 → 门继续合拢
- 门关闭 → 人物停在门外等待

禁止链路：
- 人物已进入电梯 → 电梯门又打开
- 门缝已经收窄 → 又被人物“重新冲开”
- 门正在合拢 → 外部人物仍稳定站在门外可见并参与调度

除非原剧本明确写了“按开门键、门被挡住、门重新打开”，否则不得使用“重新打开、再次打开、被冲开”等回弹词。

### 规则 12-3：意外碰撞不得写成亲密拥抱
冲入、撞上、扑到等动作如果在剧本中是意外或阻拦，不得被写成恋爱化拥抱。  
正确表达：
- 短促失衡
- 一手稳住腰侧或手臂
- 重心被拉回
- 两人没有亲密凝视，距离迅速恢复

禁止表达：
- 扑进怀里
- 紧紧抱住
- 贴在胸口/身前
- 近距离深情对视

## 六、场景与道具接续规则

### 规则 13：道具必须延续存在状态
已出现的道具、服装、伤痕、领口状态、手中物、身侧物不能随镜头切换突然消失或重置。  
必须保持：
- 领口是否敞开
- 钥匙是否仍在手边 / 手上
- 桌上文件是否存在
- 椅子位置是否改变
- 人物是否还靠墙 / 靠桌 / 倚门

### 规则 14：光线状态默认延续
同一场景同一时间段内，光线方向、色温、压光关系默认连续。  
除非场面出现明确光源变化，否则不得一镜冷白顶光，下一镜突然变暖或变侧逆光。

---

## 七、私密场景安全规则

### 规则 15：私密场景要看情绪，不看身体
处理怀孕、流产、性、身体羞耻、亲密关系崩塌等内容时，镜头重点应落在情绪承载动作、受击反应和安全景别，而不是刺激性身体观看。  
优先写：
- 手摸腹部
- 呼吸发紧
- 视线躲开
- 下颌收紧
- 手指绷住
- 肩背发僵

### 规则 16：身体部位镜头必须有叙事动机
若必须拍腹部、手腕、腿部、锁骨、后颈等身体局部，必须确保其存在的原因是：
1. 承接人物动作
2. 承接受击反应
3. 承接道具关系
4. 承接叙事信息
而不是为了制造观看刺激

---

## 八、执行流程

### 流程 A：同场景且有参考图
1. 先继承参考图中的空间关系
2. 判断本次镜头只需要写哪些变化
3. 保留视线对象与轴线
4. 仅在人物移动时更新空间描述

### 流程 B：新场景且无参考图
1. 先输出场面总控
2. 确定主轴线与主要视线关系
3. 再进入正式分镜
4. 后续镜头沿该空间关系切换

---

## 九、禁止事项
1. 禁止把场面总控写进某个时间码分镜
2. 禁止同场景里人物左右位置反复漂移
3. 禁止只写“看向画面左侧 / 右侧”，不写在看谁
4. 禁止切近后丢失对象锚点
5. 禁止特写和反打导致视线关系翻转
6. 禁止动作接续断档
7. 禁止已存在道具和服装状态在下一镜突然消失
8. 禁止私密场景用身体观看替代情绪承载

---

## 十、一句话总纲
**新场景先做场面总控，同场景默认继承参考图作为空间母锚点；后续镜头只写变化并持续保留朝向对象、视线关系、动作接续、道具接续与安全景别。**
