14_动作描述精细化控制规则
日期：2026-04-10
版本：v1.0
用途：用于把剧本中的动作含义，稳定编译成可执行、可拍、低歧义的导演动作描述，避免模型把“拎起”误生成为“扔出”、把“递过”误生成“甩过”、把“上前拉门”误生成错误门位等问题。

---

## 一、总原则
动作不是剧情标签，而是需要被准确执行的物理行为。
最终 prompt 中，凡是会影响人物关系、表演力度、道具状态、空间关系、连续性或生成稳定性的动作，都应尽量写成：
- 谁执行
- 对什么执行
- 从哪里开始
- 如何移动
- 动作落点在哪里
- 以什么力度完成
- 最终停在什么状态

一句话要求：
**不要只写“发生了什么事”，要写“这个动作是怎么被做出来的”。**

---

## 二、适用范围
本文件适用于：
- 人物拿起 / 放下 / 递出 / 接住 / 推开 / 拉开 / 扶住 / 拎起 / 背上 / 抱住 / 松手
- 开门 / 关门 / 拉门 / 推门 / 上车 / 下车 / 递物 / 迎接 / 护送
- 靠近 / 后退 / 转身 / 停住 / 让开 / 蹲下 / 起身 / 坐下 / 站起
- 耳语 / 俯身 / 探身 / 抬手 / 收手 / 视线落点变化
- 所有会造成模型误读力度、方向、路径、对象或结果的动作

---

## 三、不适用范围
本文件不负责：
- 决定是否拆片（见 05）
- 决定主分镜 / 子分镜层级（见 03、05）
- 决定对白是否完整保留（见 04、05）
- 决定画幅与景别策略（见 13）
- 决定空间连续性总控（见 06）
- 决定焦段与景深（见 02）

本文件只负责：
**在既定拆片、既定镜头和既定主体下，把动作写得更可控。**

---

## 四、动作编译基本规则

### 规则 01：动作必须优先写成执行句，而不是结果句
错误写法：
- 他帮她开门
- 她把书包拿起来
- 助理上前拉门
- 她靠近耳边说话

正确方向：
- 他先走到她侧前方，停在门把手旁，伸手替她拉开门。
- 她伸手抓住书包提带，把书包从桌边拎起，顺势提在身侧，不甩动。
- 助理快步到车后排门外侧，停住后伸手拉开后排车门。
- 她侧身贴近乔熙耳边，压低声音快速说话，身体不过度挤压对方。

### 规则 02：动作要写清执行者、对象、落点
每个高价值动作至少要让模型知道：
1. 谁在做
2. 对什么做
3. 动作做到哪里停

例如：
- 乔熙伸手抓住书包提带，把书包拎离桌面，提在右手身侧。
- 助理停在车后排门边，伸手拉开后排车门，门向外打开后停住。

### 规则 03：动作路径不清时，必须补路径
当“上前、走近、靠过去、递过去、转过去、迎上去、拉开门”这类动作存在方向歧义时，必须补：
- 从哪边
- 到哪边
- 停在谁 / 什么旁边

### 规则 04：动作力度必须显式约束
剧本动作若本意温和、中性、克制、试探，不得让模型自行升级为剧烈动作。
需要时明确写：
- 轻
- 稳
- 克制
- 小幅
- 不猛
- 不甩
- 不砸
- 不拽
- 不扑
- 不突然发力

例如：
- 她把书包轻轻拎起，不甩动。
- 他稳稳推开门，不猛地撞开。
- 她把文件递过去，不是甩过去。

### 规则 05：动作完成后的状态要保留
不要只写动作发生，要写动作结束后：
- 手停在哪
- 物停在哪
- 人停在哪
- 门停在哪
- 视线停在哪

因为生成错误常常发生在“动作结束状态不明”。

## 五、道具动作规则

### 规则 06：拿起 / 拎起 / 放下 / 递出 必须区分
- 拿起：从接触面离开，进入手中控制
- 拎起：通常抓带、抓把、抓边，物体自然下垂，不甩飞
- 放下：受控下降并落稳
- 递出：朝对象方向送到可接位置，不是抛或甩

### 规则 07：书包、手袋、文件、手机等动作要防止暴力误读
当剧本是：
- 拎起书包
- 放下包
- 递出文件
- 把手机拿出来

建议写法：
- 她伸手抓住书包提带，把书包从椅边拎起，提在身侧，不甩动。
- 她把包稳稳放到桌面边缘，不砸下去。
- 他把文件往前递到对方手边，停在可接的位置。
- 她从外套口袋里拿出手机，手机握在掌心，不做夸张晃动。

---

## 六、门、车门、上下车动作规则

### 规则 08：凡涉及开门、拉门、车门，必须写清门位
必须尽量写清：
- 哪扇门
- 谁对应这扇门
- 人停在门的哪一侧

错误写法：
- 助理上前拉开车门

正确方向：
- 助理快步到车后排门外侧，停在门边，伸手拉开后排车门。

### 规则 09：车到场动作要写人物服务关系和门位关系
当场面是迎接、商务到场、司机 / 助理服务高位人物时：
- 不要只写“有人去拉门”
- 要写清服务者站位、门位、服务对象可能的出场位置

### 规则 10：上下车动作要写顺序
可按：
- 车停稳
- 服务者到门边
- 拉开门
- 视线汇聚
- 乘坐者准备下车 / 露出
来写，避免动作顺序打架。

---

## 七、人物位移动作规则

### 规则 11：靠近、后退、转身、停步必须写相对对象
错误写法：
- 她靠近
- 他转身
- 她退了一步

正确方向：
- 她朝乔熙侧近半步，停在耳边可低声说话的距离。
- 他转身看向门口方向。
- 她下意识向后退半步，肩背微微绷住。

### 规则 12：动作距离尽量具体化
当动作会影响关系感和镜头读法时，尽量写：
- 半步
- 一步
- 侧近
- 贴近耳边
- 停在桌边
- 站到门边
- 走到车门外侧

---

## 八、对白伴随动作规则

### 规则 13：对白动作不能只剩“说”
对白段若伴随重要动作，应写成：
- 靠近 + 压低声音说
- 手停住 + 说到某句
- 视线变化 + 说
- 呼吸停一下 + 再说

### 规则 14：耳语、贴近、俯身要控制力度
像“靠近耳边说”这类动作，模型容易误解成过度身体接触。
建议补：
- 只侧近到可低声说话距离
- 不整个人压上去
- 不遮挡对方脸部
- 说完可迅速退回原位

---

## 九、动作与镜头的关系

### 规则 15：动作精细化不改变拆片骨架
动作写得更细，不代表要增加片段数量；
只在原有主分镜 / 子分镜结构内增强动作可执行性。

### 规则 16：动作精细化不等于镜头堆砌
不要为了写清动作而把镜头写得过碎。
优先在当前镜头中写清动作起点、动作路径和动作落点。

### 规则 17：动作精细化优先服务生成稳定性
当一个动作如果不写细，模型就容易误做、误读、误放大、误换方向、误换对象，就优先把它写细。

---

## 十、常见错误与纠偏

### 错误 01：把“拎起”生成成“扔出”
原因：动作力度和落点缺失。
纠偏：补“抓住提带”“从桌边拎起”“提在身侧”“不甩动”。

### 错误 02：把“递过”生成成“甩过去”
原因：只写结果，没有路径和停位。
纠偏：补“往前递到对方手边”“停在可接位置”。

### 错误 03：把“扶住”生成成“猛拽”
原因：接触强度未约束。
纠偏：补“轻扶住手臂 / 肩侧”“不猛拽”。

### 错误 04：把“拉开车门”生成成错误门位
原因：未写门位、服务关系、站位与对象。
纠偏：补“停在后排门外侧”“拉开后排车门”。

### 错误 05：把“靠近耳边说”生成成过度贴靠
原因：距离与接触边界未写。
纠偏：补“侧近到可低声说话距离”“不过度挤压”。

---


## 十-A、动作精度分级标准

### 规则 18：动作精度按冲击等级分三档

为平衡生成稳定性（精细写法）与执行简洁性（Gold Standard 写法），动作精度按以下分级执行：

**S级（必须精细）—— 高冲击 / 高歧义动作：**
适用：开门/关门/推门/拉门、上下车、递接物品、拎起/放下/扔出、扑/撞/拍/抓等接触动作
写法：必须写清执行者、对象、路径、力度、落点、终止状态（完整执行句）
原因：模型对这类动作的力度和方向最容易误读

**A级（建议精细）—— 中冲击动作：**
适用：靠近/后退/转身/起身/坐下/停步、视线大幅转移、道具状态变化
写法：写清执行者、大致路径和终止状态即可，不必逐一写力度约束
示例："她转身看向门口方向，停在桌边" 而非 "她以中等速度逆时针转身约120度"

**B级（简洁即可）—— 一般动作：**
适用：走路/站着/坐着/正常说话时的姿态、轻微手势、视线微调
写法：一句一个动作，用 Gold Standard 的导演调度语言（19号范例风格）
示例："商北琛大步走进大堂" / "她垂下视线"

## 十一、一句话总纲
**高价值动作不能只写剧情结果，必须写成可执行的物理动作：执行者、对象、路径、力度、落点、终止状态都尽量明确。**
