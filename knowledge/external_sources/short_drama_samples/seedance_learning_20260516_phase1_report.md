# 94集真人短剧样片 Seedance 2.0 对齐学习 Phase 1

## 目标

本轮不是把真人短剧镜头直接复制进 prompt，而是把样片拆成可审核的候选知识：

1. 短剧节奏候选模板。
2. 镜头 coverage 候选模板。
3. 首帧/尾帧承接候选模板。
4. Seedance 2.0 降级规则和禁止规则。

所有样片结论默认状态都是 `candidate`，必须经过人工/视觉复核和 Seedance 测试后，才能升级为 runtime rule。

## Seedance 2.0 能力边界

官方资料确认 Seedance 2.0 支持文字、图片、音频、视频四类输入，支持图片/视频/音频作为多模态参考，并支持 4-15 秒直接生成。官方模型卡列出的开放平台参考上限为最多 9 张图片、3 段视频、3 段音频，原生输出分辨率为 480p 和 720p。

但本项目采用保守生产解释：

- 默认生成单元优先控制在 4-8 秒。
- 默认 1-2 名主要角色。
- 默认一个核心动作链、一个情绪落点、一个尾帧状态。
- 8-12 秒只给低复杂度关系/对话/情绪停顿段。
- 12-15 秒、多镜头、多主体、复杂动作、强口型同步默认进入 R1 或 X，不直接编译。
- 依赖画面内文字、字幕、文件文字、手机屏幕文字完成剧情信息的设计必须禁止。

## 初步视觉复核结论

1. 样片大量使用关系镜和半身镜承载剧情压力。它们比连续大特写更适合短剧主干叙事，也更适合 Seedance 默认 W1 模板。

2. 反应镜通常是胸部以上中近景或肩部以上近景，动作预算很小。它的价值不是“镜头更漂亮”，而是给受击、忍住、犹豫、回神一个清楚落点。

3. 真实样片自带大量字幕、竖排文字、片头字和场景内标志。学习时只能学习镜头组织和节奏，不能学习字幕生成。最终 prompt 仍必须写入严禁字幕、屏幕文字、英文字幕和文字浮层。

4. OpenCV 标记的 `prop_or_information_insert_proxy` 只是“无人脸/环境/局部”的粗分类，不等于一定是道具特写。必须经过视觉复核后，才能升级为 `COV-SD20-W1-PROP-INSERT`。

5. R1 快速运动样本中大量是群体走位、快速入场、曝光变化、特效或短切重音。Seedance 默认不能直接复刻，应该降级成 W1/W2 的清楚动作顶点、关系镜或尾帧承接。

6. X 长段样本不代表不可用。它们常常是真人短剧里靠演员、台词和剪辑撑住的长关系段。对 Seedance 来说，只有低动作、低主体变化、尾帧清楚的部分能降为 W2；其余必须拆分。

7. 样片里的复杂法术、群体站位、片头海报、强特效和多人同时反应，只能作为负面 QC 学习，不能成为短剧生成默认模板。

## 对 agent 的直接学习目标

### rhythm_rewrite_director

需要从样片学习：

- 一段戏的压力曲线，而不是平均分秒。
- 快节奏不等于一直切，关键是镜头承担的信息密度变高。
- 爆点前需要压缩动作，爆点后需要反应停顿。
- 反应归属必须明确：谁被击中，谁承担停顿，谁负责尾帧。

后续合同字段应强化：

- `rhythm_mode`
- `pressure_curve`
- `beat_budget`
- `pause_points`
- `reaction_ownership`
- `tail_state_required`
- `shot_budget_hint`

### story_planner

需要从样片学习：

- 一个生成单元只保留一个可见事件主轴。
- 道具触发、身份揭示、情绪受击、闪回入口通常要拆出明确单元。
- 反应如果是剧情落点，不能被压成动作说明。
- 复杂长段必须拆成 Seedance 可控片段。

### shot_director

需要从样片学习：

- 先判断镜头任务，再选景别和视角。
- 优先使用关系镜、半身镜、中近景反应镜、道具近景、尾帧关系复位。
- 视角语言必须是自然可拍位置：平视、固定机位、过肩、反打、双人半身关系镜。
- 禁止输出抽象视角：关系视角、空间关系视角、职责视角、沙发与地毯之间的关系视角。

### storyboard_designer

需要从样片学习：

- 首帧先锁空间和人物位置。
- 关键帧只锁状态变化顶点。
- 尾帧必须保留下一段需要继承的手部、道具、视线、门/车/电梯状态。

### prompt_compiler

需要从样片学习：

- 把真人短剧复杂镜头降译成 Seedance 可执行自然句。
- 不把多镜头剪辑术语直接塞进最终 prompt。
- 遇到 R1/X 候选时必须拆分、降级或打回。
- 始终写入严禁字幕、屏幕文字、水印、logo、文字浮层。

### quality_inspector

需要从样片学习：

- 检查是否把字幕当剧情信息。
- 检查是否把快切误写成同段多次硬切。
- 检查关系镜是否丢失人物距离和方向。
- 检查反应镜是否被新动作抢走。
- 检查尾帧是否可承接下一段。
