# Playbook：母女争吵 / 摔门短剧

## 适用场景

用于“母女争吵”“回家质问”“玄关对峙”“摔门离开”“亲子冲突升级”等短剧任务。目标是把争吵写成可拍的行动链，而不是单纯互相吼台词。

## 核心原则

- 冲突先有目标和阻力：女儿想离开、回房或解释；母亲想拦住、追问或确认。
- 台词不乱改，新增台词必须得到用户确认。
- 摔门是剧情动作，不是万能结尾；必须有门状态、人物位置和尾帧状态。
- 情绪通过可见反应表达：停住、握门把、后退半步、避开视线、按住门边。
- 不新增邻居、手机录音、监控、陌生来电等关键证据，除非用户明确要求。

## 推荐 Agent 顺序

1. `scene_analyst`：锁定玄关/卧室/客厅空间、门状态、人物站位、视线轴线、参考图。
2. `director_showrunner`：把概括争吵增强成动作剧本，保留原台词和主线。
3. `rhythm_rewrite_director`：诊断冲突强度，给起速、刹车、再启动、摔门钩子。
4. `story_planner`：按戏剧微粒拆片，避免平均切分，给单层时间轴和尾帧承接。

## 操作流程

### 1. 场景分析

必须先锁：

- 人物：母亲、女儿，以及是否有父亲/弟弟等已出现角色。
- 空间：门内、门外、玄关、客厅、卧室门口。
- 门状态：开、半开、被按住、关上、摔上。
- 道具：书包、钥匙、手机、照片、成绩单等是否来自原文。
- 轴线：母亲与女儿的对峙线，或女儿与卧室门的逃离线。

### 2. 冲突增强

可直接增强：

- 女儿进门时的急促：钥匙卡顿、书包带滑落、鞋没摆正。
- 母亲的阻挡：站在门内侧、不让开、按住门边。
- 声音压力：门锁声、楼道声、手机震动，只能使用原文已有或暗示的信息。
- 道具阻碍：书包、成绩单、照片、钥匙串，必须有来源和去向。

不能直接增强：

- 新增“邻居听见了”“老师打来电话”“监控拍到了”等剧情证据。
- 新增“其实她不是亲生女儿”等关系反转。
- 新增解释性旁白或内心独白。

### 3. 节奏曲线

推荐曲线：

```yaml
起速点: "女儿进门或母亲第一句质问"
加速动作:
  - "女儿想越过母亲"
  - "母亲挡住或按住门边"
刹车点: "母亲说出真正伤人的一句"
慢拍原因: "让女儿受击，不急着解释"
再启动点: "女儿转向卧室门或重新抓住书包"
爆点: "女儿明确拒绝继续解释，或母亲误会升级"
钩子落点: "门被摔上后，母亲停在门外或女儿停在门内"
```

### 4. 拆片建议

- 片段 1：进门与第一轮质问，主信号多为 `misunderstanding` 或 `conflict_escalation`。
- 片段 2：争吵升级，保留完整发言，不在句中切断。
- 片段 3：摔门动作，按阈值段做减法，只保留转身、门状态单向推进、尾帧。
- 片段 4：门后或门外受击反应，若是情绪极点，可给更长停顿。

## 输出模板

```yaml
scene_lock:
  props:
    玄关门: { state: "半开" }
  axis: "母亲与女儿在玄关门内外形成对峙线"
增强版剧本: |
  女儿推门进来，书包带滑下，她一把拉住。
  母亲站在玄关内侧，没有让开。
  母亲：“你去哪了？”
速度曲线:
  起速点: "推门进来"
  刹车点: "母亲挡住去路并质问"
  钩子落点: "女儿转向卧室门"
segments:
  - rhythm_function: "conflict_escalation"
    boundary_reason: "争吵从质问升级到阻挡"
    reaction_need: "片段内承接"
```

## 好例

“女儿转身进卧室，母亲追到门口。女儿抓住门把，回头看了母亲一眼，没有接话，门从她手里重重合上。母亲的手停在半空，没有立刻敲门。”

好在：摔门动作单向推进，人物位置清楚，尾帧可续接，未新增剧情。

## 坏例

“女儿摔门后，邻居出来指责母亲，母亲突然发现女儿手机里有秘密录音。”

坏在：新增人物和关键证据，冲突来源漂移，摔门尾帧被新事件冲掉。

## 自查清单

- 原台词是否原样保留。
- 门状态是否单向推进，没有反复开合。
- 女儿离开或关门前的位置是否清楚。
- 母亲的受击反应是否归属明确。
- 是否把镜头语言混进剧情增强层。
- 是否新增了未确认的人物、证据或反转。
