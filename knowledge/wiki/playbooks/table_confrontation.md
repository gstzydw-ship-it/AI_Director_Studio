# Playbook：桌边对峙与高压对白

## 适用场景

两人或多人隔桌谈判、质问、冷战、审判、摊牌。桌边戏的核心是轴线、权力关系、道具信息和受击反应。

## 先定桌面空间

摆位前先写清：

- 谁在桌哪一侧，谁站立，谁坐下。
- 桌面上有哪些关键道具：文件、手机、杯子、合同、照片。
- 主要轴线沿桌面对峙，还是一方从侧面压近。
- 视线对象是对面人、桌面物、门口，还是旁观者。
- 谁处于权力高位：站立、居中、更靠近镜头，还是占据桌面物。

## 摆位模板

推荐主镜头链：

1. `establish_relation`：双人或多人桌边关系景，桌面关键物可见。
2. `pressure_source`：施压者中近景或过肩，保持对方肩线/桌缘。
3. `impact_reaction`：受击者反打中近景，视线和身体反应明确。
4. `action_insert_slot`：文件、手机、杯子、手按桌面的短插入。
5. `relationship_reset`：回到桌边双方关系，确认距离和道具状态。

9:16 不要连续大头。表情升级优先用胸口以上中近景，保留桌缘或前景肩线。

## 对话与反应

高压对白不能只拍说话的人。每个信息炸点后都要检查：

- 受击者是否有可见反应。
- 反应落在哪个镜头编号。
- 是否需要半拍停顿。
- 对方是否仍在前景、边缘或画外同一侧。

推荐节奏：

```text
关系景压住局面 -> 施压者落点 -> 受击者反应 -> 桌面道具重音 -> 关系景复位
```

## 道具锚点

桌面道具适合做短子分镜，但必须有信息增量：

- 手机震动暴露信息。
- 文件被推到对方面前。
- 手按住合同阻止拿走。
- 杯子落桌打断对白。
- 照片滑出或被翻正。

无信息的手指、杯沿、衣角不要单独开子镜头。

## 轴线与视线

桌边对峙一旦建立轴线，反打必须守住：

- 对坐不能变成并排。
- 视线要写对象，不只写“看向画面左侧”。
- 过肩镜头要说明前景是谁的肩线。
- 切到单人时，桌面或前景关系要保留。

需要越轴只能用于明确心理错乱、主观破裂或特殊叙事目的，普通对话不要越轴。

## 常见错误

- 施压者连续说完所有台词，受击者没有镜头。
- 反打后双方位置被重置，桌子方向变化。
- 桌面关键物在下一镜消失或换边。
- 竖屏只拍脸，桌边权力关系和道具都丢失。
- 子分镜只写“眼神特写”，没有信息增量。

## 最小修复

- 给每个信息炸点补 `reaction_coverage`，落到已有镜头或短子镜头。
- 补 `companion_visibility`：对方肩线、桌缘、画外方位。
- 补 `state_chain`：文件/手机/杯子/手的位置变化。
- 把无信息脸部特写降为带桌缘的中近景。
- 尾镜头回到桌边关系，或明确谁离桌、谁留下、道具停在谁手里。
