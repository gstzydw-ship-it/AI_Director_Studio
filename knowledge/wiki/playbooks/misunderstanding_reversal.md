# Playbook：误会建立 / 误会反转短剧

## 适用场景

用于“母亲误会女儿”“女儿被冤枉”“真相晚到半拍”“一句话反转关系判断”等短剧任务。重点是让误会先命中人物，再让真相反转，不要一开始替角色解释清楚。

## 核心原则

- 误会建立时，优先保留听者受击、视线躲闪、关系发冷。
- 反转前必须有命中前半拍：角色或观众先相信错误判断。
- 真相揭示后先给受击反应，再决定是否解释。
- 不新增关键证据。短信、照片、录音、医院单、监控都必须来自原剧本或用户确认。
- 反转后不要立刻把意义说满；保留黄金停顿或 Cliffhanger。

## 戏剧微粒判断

```yaml
misunderstanding:
  hook_weight: 0.7
  用途: "建立错误认知，让关系变冷"
suspense_reveal:
  hook_weight: 0.8
  用途: "揭示被隐藏的信息"
power_reversal:
  hook_weight: 1.0
  用途: "真相改变场面权力归属"
emotional_peak:
  hook_weight: 0.9
  用途: "角色被真相击中后少说、多留"
cliffhanger:
  hook_weight: 1.0
  用途: "在真相命中后 0.5-2 秒内阻断"
```

每个片段最多 1 个主信号 + 1 个次级信号。不要把每个反应都标成反转。

## 推荐结构

### 1. 误会建立

让错误判断先落地：

- 母亲挡住女儿或不让她越过。
- 女儿试图解释但被打断。
- 原有道具造成错位，例如成绩单、照片、未接电话、门外脚步。
- 受击者先沉默、停住或避开视线。

### 2. 误会加深

只用原文已有信息加压：

- 时间压力：等了一晚、错过约定、电话无人接。
- 空间压力：玄关、门口、客厅众人注视。
- 道具压力：书包、照片、报告单、礼物盒。
- 声音压力：门声、电话声、消息提示，必须有原文锚点。

### 3. 反转揭示

按“发现前停顿 -> 揭示 -> 反应”组织：

```yaml
发现前停顿: "母亲看到原有道具或听到原有台词前停住"
揭示: "真相信息出现，保持原台词或原道具事实"
反应: "谁被击中、谁失控、谁重新掌场"
```

### 4. 反转后收束

- 若是情绪极点：少说、多留、少动作。
- 若是权力反转：写秩序被翻面，谁停住、谁失控、谁重新掌握场面。
- 若是 Cliffhanger：只写到阻断点，不补缓和尾巴。

## Agent 分工

- `director_showrunner`：只能把误会的可见压力增强，不能新增误会源。
- `rhythm_rewrite_director`：标速度曲线与主戏剧微粒，给反应归属。
- `story_planner`：按误会建立、揭示、受击、阻断拆片，不改写原文。
- `scene_analyst`：锁道具、视线、门状态和参考图，避免反转时空间重建。

## 好例

原文已有：母亲看到女儿书包里的医院缴费单，误以为女儿偷钱；后面台词说明女儿是替母亲复查缴费。

处理：

```yaml
误会链:
  错误判断: "母亲以为女儿偷拿家里的钱"
  误会来源: "原文已有医院缴费单"
  被误会者目标: "女儿想先回房，不想当场解释"
  误会持有者目标: "母亲要女儿立刻说明钱的去向"
反转链:
  揭示来源: "原文台词：我是给你复查交的钱"
  命中前半拍: "母亲拿着缴费单停住"
  真相落点: "缴费对象是母亲"
  第一受击者: "母亲"
  权力变化: "质问者失语，被质问者重新掌场"
节奏策略:
  起速点: "缴费单被翻出"
  刹车点: "女儿说出复查"
  爆点: "缴费对象反转"
  钩子落点: "母亲拿着单据停在原地"
```

## 坏例

“母亲误会女儿偷钱。突然医院打来电话，医生证明女儿是好人，母亲痛哭道歉。”

问题：新增电话和医生证明；真相由外部角色代劳；反转太快说满，缺少命中前半拍和受击反应。

## 自查清单

- 误会来源是否来自原剧本。
- 真相揭示是否没有新增关键证据。
- 是否先保留听者受击，再进入解释。
- 反转后是否留下停顿或阻断。
- 是否把误会、揭示、权力反转混成同一个片段。
- 是否避免了心理旁白和镜头命令。
