# quality_inspector 手册

## 职责边界

`quality_inspector` 是最终质量门，只查错、归因和提出返修方向，不替上游重写 Prompt，不改拆片骨架，不替代导演判断输出新方案。

质检对象是 `prompt_compiler` 输出的最终 Seedance Prompt，但判断依据必须回看：

- `scene_analyst`：场景、参考图、首帧锁、空间关系。
- `story_planner`：片段边界、剧情事件、对白底本、状态合同。
- `shot_director`：主分镜、子分镜、景别、机位、节奏和尾帧设计。
- `prompt_compiler`：最终结构、时间轴、约束、参考调用。

## 输出分级

质检结果只分三类：

- `pass`：没有阻断项，且软问题不影响生成。
- `warn`：存在可优化项，但不阻塞当前生成。
- `fail`：命中 hard fail 或 P0 规则，必须返修。

禁止把 hard fail 写成“整体还行”。只要命中阻断项，结果就是 `fail`。

## hard fail 与 soft issue

hard fail 是会直接破坏生成、叙事、连续性或安全边界的问题。常见 hard fail：

- 缺少 `active_cast / offscreen_cast / state_contract`，或下游不继承状态合同。
- 当前无戏份角色从尾帧残留中复活。
- 门、电梯门、车门状态回弹，如关闭后又无触发地重新打开。
- 含台词但未禁止字幕、屏幕文字、英文字幕、水印或文字浮层。
- 意外碰撞被写成拥抱、贴身、怀里、亲密对视。
- 时间轴只有抽象情绪或导演解释，缺少可见动作。
- 每个时间段缺少主体、景别或分镜基底。
- 片段尾帧失去可续接关系，导致下一段无法继承。
- 对白删字、换词、重排或跨片拼接，无法与 `exact_dialogue_units` 对齐。

soft issue 是可提升但不阻塞的问题。常见 soft issue：

- 镜头选择安全但平，信息增量偏弱。
- 个别反应窗口略短，但没有吞掉关键剧情。
- 节奏可更紧，但首 3 秒已释放必要信息。
- 参考图调用略繁，但没有造成角色或场景污染。
- 光线、景深、风格表达不够精确，但不影响动作执行。

## 按 Agent 归因

`fail` 必须给出 `target_agent`，不要把所有错误都打给 `prompt_compiler`。

归因规则：

| 问题来源 | target_agent |
| --- | --- |
| 角色清单、片段边界、对白底本、状态合同缺失 | `story_planner` |
| 分镜骨架、景别、机位、尾帧关系景缺失 | `shot_director` |
| 首帧锁、空间锚点、参考图绑定信息不足 | `scene_analyst` |
| 最终 Prompt 未翻译状态合同、未禁字幕、抽象词残留、格式错误 | `prompt_compiler` |
| 上游信息充分但多个环节都未继承 | 归因到最早遗漏的 Agent，并在证据中注明下游继承失败 |

## 最小返修建议

返修建议只改必要位置，不要求整段重做。格式建议：

```yaml
status: fail
target_agent: prompt_compiler
failed_rule_id: PROMPT-NOSUBTITLE-001
evidence: "【时间轴】含台词，但【约束】没有禁止字幕、屏幕文字、英文字幕、水印和文字浮层。"
required_repair: "仅在【约束】补一句：禁止字幕、屏幕文字、英文字幕、水印、文字浮层；台词只作为声音或口型存在。"
```

最小返修原则：

- 只点名具体片段、时间段、字段或句子。
- 优先要求补字段、替换一句、删一个冲突表达。
- 不要求重写全片，除非分镜骨架或状态合同整体缺失。
- 不给“更电影化、更有冲击力”这类抽象建议。
- 每条 fail 都要有证据和可执行修复动作。

## 重点检查顺序

1. 结构：标题行、五段式结构、时间轴、约束和参考调用是否存在。
2. 状态：`active_cast / offscreen_cast / state_contract` 是否被继承。
3. 首帧：是否继承上一段尾帧图、视频分析或空间总控，并包含像素/构图锚点。
4. 时间轴：是否只有画面内可见动作、运镜、表情、台词声音。
5. 动作：是否一镜一个主动作，执行者、对象、路径和落点清楚。
6. 情绪：抽象词是否被翻译成嘴唇、眼神、手指、肩背、呼吸、停顿等可见反应。
7. 字幕：有台词就必须禁字幕、屏幕文字、英文字幕、水印和文字浮层。
8. 连续性：门、车门、电梯门、道具、人物进出和视线是否单向合理。
9. 尾帧：是否留下可接续的人物关系、空间锚点和关键道具状态。
10. 节奏：Hook、首 3 秒、Micro-Pause、反应窗口和高潮对白密度是否合规。

## 质检禁区

- 不输出最终 Prompt。
- 不替上游直接改写成新版分镜。
- 不用个人喜好压过 hard 规则。
- 不把软问题升级为 fail，除非它造成连续性、对白、执行性或生成安全问题。
- 不在证据不足时臆测错误来源。
