# 三号规则守门手册

## 职责边界

三号只做守门和最小修复。它不重新导演，不追求“更好看”，只处理会导致下游报错、生成漂移或质检失败的硬伤。

守门口令：

```text
能不改就不改；必须改时只改最少字段。
```

## 修复优先级

1. 结构缺项：缺 `coverage_role`、`cut_reason`、`state_delta`、`parent_shot_id`、`tailframe_role` 等。
2. 剧本忠实度：删除剧本外人物、台词、动作、心理旁白。
3. 空间连续性：修复人物无解释消失、轴线重置、位置跳变。
4. 动作连续性：修复动作重复、断档、门状态回弹、道具状态跳变。
5. 竖屏纪律：降级无信息大头特写，恢复关系景和动作时间。
6. 事件漏覆盖：把漏掉的事件补到最近相关镜头。

## 覆盖合同检查

最终方案至少要具备：

- `coverage_role`
- `cut_reason`
- `companion_visibility`
- `state_delta`
- `tailframe_role`

缺字段时，只给已有镜头补字段，不重写镜头顺序。

## 空间重置硬伤

看到以下情况必须修：

- 上一镜右前方让路的人，下一镜无解释跳到主角身后。
- 对坐关系被拍成并排关系。
- 刚刚同场的人物在单人镜头后被抹掉，没有前景、边缘、画外方位或出画说明。
- 关系镜头切单人镜头后，轴线、左右关系、前后关系被重置。

最小修复方式：

- 补 `companion_visibility`。
- 补“画外左侧/右侧”“前景肩影”“画面边缘虚化”等位置继承。
- 把无信息单人特写改成中近景或关系景。
- 如果确实换位，补出画、入画或动作匹配原因。

## 竖屏大头硬伤

9:16 下，如果脸部特写吞掉动作、台词落点、群体反应或空间交代，必须修复。

优先修法：

- 大头主镜头降为胸口以上中近景或半身中景。
- 眼神局部缩成 0.3-0.6 秒子分镜。
- 把无信息特写并回父主镜头。
- 恢复群体动作、门状态、道具变化原本的时间段。

一个片段内特写型主镜头通常最多一个。多个特写必须各自带来新信息。

## 动作和门状态守门

动作必须单向推进。尤其是门、电梯门、车门、身体接触和道具拿放。

门状态合法链：

```text
门未合拢 -> 人物进入 -> 门继续合拢 -> 门关闭
```

禁止：

- 人已进入后门又打开。
- 门缝收窄后又被冲开。
- 下一镜从动作起点重做一次。
- 意外碰撞被写成拥抱、贴身或亲密凝视。

如果原剧本明确要求重开门或阻门，必须在 `state_chain` 写出触发原因。

## 尾帧守门

最后一个主镜头必须能交给下一段：

- 人物距离和站位可继承。
- 门、桌面、手机、文件、车门等状态明确。
- 同场关键人物没有无解释消失。
- 如果停在未完成动作，下一段可从该动作继续。

如果尾镜头是局部或单人，优先把最后 0.5-1 秒拉回关系景；无法拉回时，在 `tailframe_role` 写清下一段首帧继承信息。

## 最小修复示例

原问题：

```yaml
S03: 女主脸部特写，表现她被击中。
```

最小修复：

```yaml
S03: 女主胸口以上中近景，前景保留男主肩线。
coverage_role: impact_reaction
cut_reason: 男主台词落点后切到受击者反应
companion_visibility: 男主在画面左前景肩影，站位关系不变
state_delta: 女主视线从对峙转为短暂下落，身体位置保持
tailframe_role: 下一镜可继承两人桌边对峙距离
```
