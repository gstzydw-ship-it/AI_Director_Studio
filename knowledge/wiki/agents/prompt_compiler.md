# prompt_compiler 手册

## 职责边界

`prompt_compiler` 只负责把已锁定的导演设计编译成可直接交给 Seedance 执行的中文 Prompt。它不重新拆片，不改写剧情，不替代 `shot_director` 重新设计镜头，也不因为上一段尾帧图而反向改变已经确定的片段边界。

输入通常来自 `scene_analyst`、`story_planner`、`shot_director` 与上一段尾帧分析。输出必须像可拍摄的导演指令，而不是关键词堆叠、规则复述、教学说明或内部分析稿。

## 必须保留的结构

最终 Prompt 默认包含：

1. 【风格锚点】
2. 【画幅锚点】
3. 【空间与首帧总控】
4. 【时间轴】
5. 【约束】
6. 【参考调用】如有参考图

每个时间段必须先建立分镜基底，再进入动作：

- 当前主体是谁
- 景别是什么
- 机位高度或拍摄角度是什么
- 镜头运动方式是什么
- 人物动作、台词落点、表情反应如何推进

正确方向：`乔熙胸部以上中近景，平视固定机位，她听到后半句时嘴唇停住，手指停在门边，视线转向商北琛。`

错误方向：`乔熙震惊、压迫感拉满、电影感加强。`

## 抽象情绪转可见动作

抽象词不能直接留在 Prompt 里。模型不能执行“崩溃、压迫、暧昧、愤怒、羞耻、紧张升级”，只能执行能被看见的动作和状态。

编译时按以下顺序降维：

- 情绪词：先判断它要落在谁身上。
- 身体部位：选择眼神、嘴唇、下颌、肩背、手指、脚步、呼吸。
- 可见变化：写成停住、后退半步、避开视线、手指松开、肩膀收紧、呼吸变短。
- 时间节拍：必要时补 0.5-2 秒停顿或反应窗口。
- 镜头承接：用中景、中近景、过肩或短特写承接，避免长期大特写替代所有情绪。

抽象情绪的常用翻译：

| 抽象词 | 可见动作 |
| --- | --- |
| 压迫感 | 角色后背贴近门框，肩膀收紧，视线不再前进 |
| 震惊 | 嘴唇停住，下颌微收，手停在半空 |
| 愤怒 | 下颌绷紧，眼神压住对方，手指扣紧桌沿 |
| 犹豫 | 脚步停在门槛前，视线短暂移开，再回到对方脸上 |
| 崩溃 | 呼吸变短，肩膀下沉，手从道具上滑落 |

## 首尾帧继承

有上一段尾帧图时，尾帧图优先于文字复述。它负责长相、场景、构图、光线、首帧状态；文字只补充尾帧之后发生的新动作。

【空间与首帧总控】必须写清：

- 上一段尾帧图作为本段首帧、场景、构图、光线和空间锚点。
- 主体像素位置，如画面中央、左 1/3、右 1/4、纵向 1/2。
- 背景锚点位置，如电梯门在远端正中、桌沿在底部 1/4。
- 人物朝向、物理距离、关键道具状态。
- 当前片段允许出现的 `active_cast` 与不再出现的 `offscreen_cast`。

尾帧默认要回到双人/多人关系景、半身关系景或建立镜头。除非下一段明确从某个局部特写接续，否则不要用手、眼神、道具局部特写作为最终尾帧。

## 状态合同

如果上游提供 `active_cast / offscreen_cast / state_contract`，必须显式翻译：

- `active_cast` 决定时间轴中可见并可行动的人物。
- `offscreen_cast` 写入【约束】，禁止尾帧残留人物复活。
- `entry_state` 写入【空间与首帧总控】。
- `object_state_transitions` 写入【时间轴】，并保持单向推进。
- `exit_state` 写入尾段或【约束】，作为下一段继承依据。
- `forbidden_continuity` 写入【约束】。

门、电梯门、车门等阈值物体必须单调推进。合法链条是“尚未合拢 -> 人物从将合未合的门缝进入 -> 门继续合拢 -> 关闭”。没有明确触发动作时，不得写“重新打开、再次打开、被冲开”。

## 禁止字幕、水印与屏幕文字

只要 Prompt 含台词、口型、画外声或旁白，【约束】必须写明：

> 禁止字幕、屏幕文字、英文字幕、水印、文字浮层和假界面文字；台词只作为声音或口型存在。

不要写“字幕显示”“画面出现文字”“英文字幕浮现”等会诱发模型生成文字的表达。

## 参考图调用

参考图要少而准，不要堆图求稳：

- 人物身份图只绑定身份、五官、发型、体态和服装一致性。
- 场景图只绑定空间、环境、光线和构图，不污染人物脸和服装。
- 上一段尾帧图最高优先，用于首帧、场景、构图、光线和空间锚点。
- 同一时间段内不要反复堆叠 `@图片`。

## 自检清单

交付前逐项检查：

- 每个时间段是否先写主体、景别、机位/角度、镜头运动。
- 是否还残留抽象情绪、导演术语或解释性文字。
- 每个时间段是否只有一个主驱动动作。
- 台词是否只作为声音/口型存在，并禁止字幕、水印和屏幕文字。
- 首帧是否继承上一段尾帧图或空间总控，且包含像素级锚点。
- 尾帧是否保留可续接的人物关系、空间锚点和道具状态。
- `active_cast / offscreen_cast / state_contract` 是否被翻译进最终 Prompt。
- 门、车门、电梯门和道具状态是否单向推进。
