# 镜头导演总手册

## 定位

镜头导演组负责把片段事件变成可生成、可续接、可质检的镜头方案。它不是“把剧本写得更有戏”，而是决定每个镜头为什么存在、承接什么状态、给下游留下什么尾帧。

三位导演分工：

- `shot_director_layout`：搭主分镜骨架，只决定主镜头覆盖链。
- `shot_director_blocking`：在骨架上补动作调度、反应落点、状态链和子分镜。
- `shot_director_guard`：守门与最小修复，只修硬伤，不重写创意。

## 总决策顺序

1. 先读当前片段的 `source_script_events`，确认必须覆盖的动作、台词、信息炸点。
2. 继承上一段尾帧或场面总控中的人物、轴线、门、道具、站位关系。
3. 判断当前片段主要任务：建立关系、施压、受击反应、动作过阈值、信息揭示、尾帧复位。
4. 先用主镜头覆盖关系和动作路径，再用子分镜处理短促重音。
5. 片段结束前必须留下下一段可继承的尾帧状态。

## 镜头选择原则

镜头不是景别列表，而是覆盖职责。每个主镜头必须回答：

- `coverage_role`：这个镜头承担什么功能。
- `cut_reason`：为什么必须从上一镜切过来。
- `companion_visibility`：同场关键人物在画面内、前景、边缘还是画外哪一侧。
- `tailframe_role`：是否承担下一段首帧继承。

常用覆盖链：

```text
关系建立 -> 施压/行动起势 -> 受击/反应 -> 动作或道具插入 -> 关系复位/尾帧锁定
```

如果镜头只是“更好看”“更有电影感”“表情更强”，通常不该新增。

## 9:16 竖屏构图纪律

竖屏不是默认大头。主镜头优先级：

1. 双人半身关系景：保住站位、距离、权力关系。
2. 中景或中近景：承接表演，又不丢空间。
3. 肩部以上特写：只用于明确情绪顶点或信息命中。
4. 局部插入：只作为短子分镜，不能替代主镜头。

禁止把同一主体写成“中景 -> 脸部特写 -> 同角度中景”的碎切，除非特写带来新的动作、道具、视线目标或权力变化。

## 动作锚点

动作切点必须绑定可见身体或物体状态，不写“合适时切”。

优先锚点：

- 手触到、松开、按住、递出、收回。
- 脚迈过门槛、落地、停住、转向。
- 门缝收窄、门把被按下、门继续合拢。
- 视线撞上对象、避开对象、越过桌面落到对面人。
- 道具被拿起、滑落、翻正、露出关键信息。

动作跨镜时，上一镜最好切在动作完成前的 50%-70% 中间态，下一镜从同一动作状态继续，而不是重新开始。

## 尾帧到首帧

上一镜尾帧只提供已经发生的空间事实，不会自动授权新增人物、动作或台词。下一镜首帧必须明确继承：

- 谁仍在同场，谁已出画，谁只是画外存在。
- 人物相对位置、视线对象和场面轴线是否保持。
- 门、车门、桌面道具、身体接触等状态是否单向推进。
- 如果切到单人镜头，另一人在哪里被保留或被逻辑裁出。

片段尾镜头不应停在无法续接的局部特写。若前面用了手部、眼神或单人反应，最后 0.5-1 秒回到可继承关系景，或在 `tailframe_role` 中写清下一段可继承的状态。

## 最小修复原则

守门阶段只修会导致下游报错或质检失败的硬伤：

- 缺必填合同字段。
- 事件漏覆盖。
- 子分镜没有 `parent_shot_id`。
- 空间、轴线、门状态或人物位置跳变。
- 竖屏大头特写吞掉动作、台词或群体反应时间。
- 剧本外人物、动作、台词。

不为了更顺、更美、更戏剧化而新增镜头或重排结构。

## 交付检查

- 每个 `source_script_event` 都能落到一个已有主镜头或子镜头。
- 每个主镜头都有 `coverage_role`、`cut_reason`、`companion_visibility`。
- 每个子镜头都有 `parent_shot_id`、`trigger`、`cut_point`、`action_phase`、`duration_hint`、`state_delta`。
- 每个会跳变的对象都有 `state_chain`。
- 尾镜头提供下一段可继承的空间、人物距离和关键物体状态。
