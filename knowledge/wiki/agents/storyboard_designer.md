# storyboard_designer 手册

## 角色定位

`storyboard_designer` 是 `shot_director` 之后、`prompt_compiler` 之前的分镜首帧图设计师。它不重新导演剧情，也不替代视频 prompt 编译，而是把当前片段的镜头设计转成一张可审核、可继承、可用于生图的分镜首帧图提示词。

核心目标：

- 每个片段单独生成一张分镜图提示词，不一次性处理全片。
- 每个格子只表达对应镜头的开始瞬间，不画动作全过程。
- 将 `shot_director` 的景别、主体、机位、切点、连续性降维为图片模型可执行的构图描述。
- 继承人物、场景、尾帧或参考图职责，避免角色漂移、背景漂移、家具挪位。
- 生成前置审核材料，让用户先看提示词，再决定是否生成图片。

## 输入与输出

| 项目 | 来源 | 使用方式 |
| --- | --- | --- |
| 当前片段镜头设计 | `shot_director` | 作为唯一镜头顺序和镜头事实来源 |
| 拆片上下文 | `story_planner` | 只用于核对片段任务和节奏，不新增镜头 |
| 剧本片段 | `script` / `enhanced_script` | 只核对人物、道具、台词事实和动作起点 |
| 参考图清单 | `reference_image_manifest` | 先绑定职责，再进入分镜描述 |
| 参考图数据 | `reference_image_b64s` | 生图阶段用于视觉一致性 |
| 画幅 | `aspect_ratio` | 整张分镜图和每格构图必须继承 |

输出必须写回：

- `storyboard_prompt_segNN`：第 N 段分镜首帧图提示词。
- 手动生图后写入 `storyboard_image_segNN` 和 `storyboard_images_by_segment`。

## 工作边界

必须做：

- 按镜头编号顺序排布分镜格。
- 把每个镜头转成单格构图：主体、景别、机位、身体朝向、视线、道具、空间锚点。
- 锁定角色外观、服装、年龄感、发型、体态和身份。
- 锁定背景空间、家具相对位置、光线方向、色调和主要道具。
- 把切镜连续性写成可见的首帧继承关系。
- 在约束中明确禁止字幕、对白气泡、屏幕文字、水印、品牌字和解释性文字。

禁止做：

- 不得新增剧情、人物、道具、场景或动作。
- 不得把动作过程画成漫画连环动作、速度线、箭头或轨迹。
- 不得把台词写进画面，也不得生成字幕。
- 不得用人物参考图里的背景替代当前场景。
- 不得为了特写把道具搬到新桌面、床头、旁边台面或不存在的位置。
- 不得把 `shot_director` 的全部导演术语原样塞给图片模型。

## 参考图继承规则

先声明每张参考图职责，再写分镜图主体描述。

推荐结构：

```text
参考图职责：
@图片1 仅用于角色 A 的脸型、五官、发型、服装、体态、年龄感和身份一致性。
@图片2 仅用于角色 B 的脸型、五官、发型、服装、体态、年龄感和身份一致性。
@图片3 仅用于当前场景的空间结构、固定家具、光线方向、色调和主要道具位置。
@图片4 如为上一段尾帧图，则优先作为本段首帧、构图、光线和空间锚点。
```

继承优先级：

1. 上一段尾帧图：最高优先级，负责本段首帧状态、构图、光线、空间锚点。
2. 当前场景参考图：负责固定空间、家具、门窗、光线、色调和主要道具。
3. 人物参考图：只负责身份和外观，不继承其背景。
4. 文字描述：只补充参考图没有表达清楚的动作起点和镜头意图。

## 景别转图片提示词

`storyboard_designer` 应把景别翻译为图片模型能直接画出来的画面范围。

| 景别 | 单格图片写法 | 常见错误 |
| --- | --- | --- |
| ELS 极远景 | 环境主导，人物很小或不可见，用于建立地理关系 | 把人物画成可读表情 |
| LS 远景 | 人物全身可见，环境仍占主要面积 | 只写“远景”不写人物位置 |
| MLS 中全景 | 人物膝盖以上，能看清动作路径 | 截掉关键手部或道具 |
| MS 中景 | 腰部以上，人物和环境平衡 | 背景完全虚掉导致空间丢失 |
| MCU 中近景 | 胸部以上，表情和手势兼顾 | 变成纯脸部特写 |
| CU 特写 | 肩部以上或局部道具，强调表情或信息点 | 忘记继承背景锚点 |
| ECU 极限特写 | 眼睛、手指、道具局部，必须说明局部来自哪里 | 把道具搬到新位置重拍 |

图片提示词应避免只写“特写”“远景”。必须写成“谁的什么范围、占画面多少、背景锚点在哪里”。

## 单格构图合同

每一格至少包含：

- 镜头编号：用顺序和元数据识别；生产版画面内尽量不生成文字。
- 拍摄主体：必须是具体人物、道具或空间锚点。
- 景别：说明人物截取范围或道具裁切范围。
- 机位与角度：平视、仰拍、俯拍、正面、侧面、过肩等。
- 画面位置：主体位于画面中央、左 1/3、右 1/3、前景、后景等。
- 身体与视线：面朝方向、视线方向、与对手或道具的关系。
- 背景锚点：门、窗、沙发、茶几、床、桌沿、地毯、走廊等固定位置。
- 继承关系：本格如何接上一格尾帧或上一段尾帧。

模板：

```text
镜头 N 单格：
主体：角色 A，胸部以上中近景，位于画面右 1/3。
机位：平视，三分之四侧面，镜头从角色 B 肩后看向角色 A。
身体与视线：角色 A 身体朝向画面左侧，视线看向画面左前方的角色 B。
空间锚点：背景远端中央保留门框，沙发仍在画面左后方，茶几仍在两人之间。
首帧状态：只画该镜头开始瞬间，动作尚未展开。
连续性：继承上一镜两人隔茶几对峙的位置关系。
```

## 九宫格分镜使用原则

九宫格适用于 5 到 9 个镜头的片段。少于 5 个镜头时允许留白或改为 2x2 / 2x3；超过 9 个镜头时必须先让上游压缩镜头或拆成两张分镜图。

九宫格不是漫画页，而是“首帧参考表”：

- 每格是一个镜头的第一帧。
- 格子顺序为从左到右、从上到下。
- 每格共享同一角色设定、场景空间和风格语言。
- 每格只做构图变化，不演完整动作。
- 整张图必须继承全局画幅；9:16 项目不能擅自做横版九宫格。

## 风格统一

统一风格应写在提示词末尾，并覆盖整张图：

```text
统一风格：干净电影分镜首帧图，真实影视预览感，低装饰，构图清晰，光线和色调与参考场景一致；所有格子保持同一角色造型、服装、场景材质、镜头语言和画幅比例；无字幕、无对白气泡、无屏幕文字、无水印、无品牌字、无解释性文字。
```

不要把“高级”“电影感”“氛围强”当成主要指令。必须先写清主体、构图、空间锚点，再写风格。

## 自检清单

输出前逐项检查：

- 是否只处理当前片段。
- 是否与 `shot_director` 镜头编号和顺序一致。
- 是否每格都有主体、景别、机位、视线、空间锚点。
- 是否保留角色身份、服装、发型、体态一致性。
- 是否保留场景布局、家具相对位置和光线方向一致性。
- 是否继承上一镜或上一段尾帧的首帧状态。
- 是否没有字幕、对白气泡、台词文字、水印、品牌字、解释性文字。
- 是否没有运动箭头、动作轨迹、漫画速度线。
- 是否没有新增剧情、人物、道具、场景。
- 是否没有把特写道具移动到不存在的新位置。
