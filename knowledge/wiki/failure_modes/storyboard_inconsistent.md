# 分镜图不一致失败模式

## 定义

`storyboard_inconsistent` 指分镜图虽然按镜头生成了格子，但角色、场景、画幅、道具位置、镜头顺序或风格没有稳定继承，导致它不能作为后续视频生成的可靠首帧参考。

它通常不是单一错误，而是一组连续性失效：

- 角色换脸、换发型、换服装、年龄感漂移。
- 场景换房间、家具挪位、光线方向改变。
- 特写道具被搬到不存在的新位置。
- 上一段尾帧没有作为下一段首帧继承。
- 九宫格顺序与镜头顺序不一致。
- 图中出现字幕、对白气泡、解释性文字、水印或品牌字。
- 动作被画成漫画过程，出现速度线、箭头、轨迹。

## 高危触发条件

| 触发条件 | 风险 |
| --- | --- |
| 只写“保持一致” | 图片模型不知道该保持哪些视觉字段 |
| 参考图职责未绑定 | 人物图背景污染场景，场景图影响人物长相 |
| 忘记上一段尾帧 | 段间首帧跳位、光线跳变、角色站位重置 |
| 特写没有空间锚点 | 道具被移动到新桌面或新房间 |
| 九宫格要求生成编号文字 | 容易诱发乱码、水印、假字幕 |
| 把动作全过程画进格子 | 分镜图变漫画，失去首帧参考价值 |
| 镜头过多硬塞九宫格 | 每格太小，角色和空间锚点都不可读 |

## 典型症状

角色不一致：

- 同一角色在不同格里脸型、发型、服装颜色、年龄感不同。
- A / B 两个角色的左右位置突然互换，但没有过渡镜头。
- 角色从参考图的现代服装变成随机古装、制服或礼服。

背景不一致：

- 客厅变成卧室、办公室变成走廊。
- 沙发、茶几、窗户、门的位置在不同格里跳变。
- 光线从左侧窗光变成右侧顶光，且没有剧情原因。
- 背景色调在九格内随机变化。

首帧不一致：

- 上一段尾帧中人物站在画面中央，下一段首帧突然位于画面边缘。
- 上一格道具在茶几上，下一格特写变成在床头或旁边桌面。
- 上一格两人隔桌对峙，下一格变成并肩站立。

画面污染：

- 出现字幕、台词、对白气泡、英文单词、假品牌、乱码水印。
- 出现镜头说明文字、箭头、运动轨迹、漫画速度线。
- 图片模型把“镜头1”画成大标题，压住人物或场景。

## 根因

1. 只继承语义，没有继承像素锚点。
2. 参考图没有先绑定职责。
3. 景别翻译不完整，只写“特写”“中景”。
4. 过度依赖风格词，缺少空间与构图描述。
5. 把视频动作 prompt 当作图片 prompt 使用。
6. 把审片说明文字直接要求生成在画面内。
7. 没有把固定家具、主要道具写成不可移动锚点。

## 检测规则

质检时逐项判断：

- 每格是否能对应一个 `shot_director` 镜头。
- 每格主体是否具体，不能是“氛围”“紧张感”“关系”。
- 每格景别是否写清画面范围和主体占比。
- 每格是否有至少一个背景锚点。
- 同一角色的脸、发型、服装、体态是否稳定。
- 同一场景的门窗、家具、道具、光线是否稳定。
- 特写是否继承原道具位置，而不是新建位置。
- 上一段尾帧图是否优先于文字复述。
- 是否存在字幕、对白气泡、屏幕文字、水印、品牌字。
- 是否存在动作线、箭头、轨迹、漫画拟声词。

## 修复策略

### 1. 先绑定参考图职责

坏例：

```text
参考图片作为角色和场景参考，保持一致。
```

修复：

```text
@图片1 仅用于角色 A 的脸型、五官、发型、服装、体态和年龄感一致性，不继承背景。
@图片2 仅用于当前客厅的空间结构、沙发、茶几、窗户、门、光线方向和暖色调，不影响人物长相。
```

### 2. 把“保持一致”展开成字段

坏例：

```text
九格里人物和背景保持一致。
```

修复：

```text
九格内角色 A 始终为短黑发、深色西装、肩宽较直、冷静表情基底；客厅始终保持沙发在左后方、茶几在两人之间、窗户在右后方、暖色台灯来自画面左侧。
```

### 3. 特写只裁切，不搬动

坏例：

```text
切到手部特写，戒指放在旁边桌面上。
```

修复：

```text
切到手部特写，戒指仍在上一格茶几中央偏右的位置，只通过裁切和推近让手与戒指占据画面主体，茶几材质和边缘位置继承上一格。
```

### 4. 去掉画面内文字

坏例：

```text
每格左上角写“镜头1”，并显示角色对白。
```

修复：

```text
通过九宫格顺序对应镜头，不在画面内容中生成文字；无字幕、无对白气泡、无屏幕文字、无水印、无品牌字、无解释性文字。
```

### 5. 把动作过程改成首帧状态

坏例：

```text
第 4 格画角色冲过去抢走文件，带速度线和运动箭头。
```

修复：

```text
第 4 格只画抢文件动作开始前的瞬间：角色 A 身体前倾，右手刚离开桌沿，视线锁定茶几上的文件；不画运动轨迹、速度线或箭头。
```

## 阻断条件

出现以下情况，分镜图提示词必须退回重写：

- 参考图职责未声明。
- 角色身份、服装或发型在格子间无法保持。
- 场景固定家具位置冲突。
- 上一段尾帧图存在但没有被优先继承。
- 出现字幕、对白气泡、屏幕文字、水印或品牌字。
- 动作被画成过程漫画，而不是首帧。
- 镜头顺序与 `shot_director` 不一致。
- 画幅与项目全局画幅不一致。

## 最小修复模板

```text
请在不改变镜头顺序、不新增剧情、不新增人物和不新增道具的前提下，修复分镜图提示词：
1. 先声明每张参考图职责。
2. 每格只保留镜头开始瞬间。
3. 每格补齐主体、景别、机位、视线、空间锚点和连续性。
4. 角色外观字段逐格继承：脸型、发型、服装、体态、年龄感。
5. 场景字段逐格继承：固定家具、门窗、主要道具、光线方向、色调。
6. 特写只能裁切或推近原位置，不移动道具。
7. 删除字幕、对白气泡、文字说明、水印、品牌字、动作线、运动箭头。
```
