# Failure Mode：场景空间不清

## 定义

场景空间不清指镜头方案没有让观众和下游模型理解人物、门、桌、道具、轴线和视线之间的关系。它不一定是“镜头不好看”，而是缺少可继承的空间合同。

## 典型症状

- 切近后，另一名关键人物消失。
- 反打把对坐关系拍成并排关系。
- 门内外方向、桌两侧方向或走廊纵深在下一镜翻转。
- 只写“看向画面左侧”，没有写视线对象。
- 竖屏连续脸部特写，门、桌、队列、车门都不可见。
- 尾帧停在局部，下一段不知道人物距离、门状态或道具位置。

## 根因

常见根因：

- 没有场面总控或 `continuity_anchor`。
- `coverage_role` 只是景别，没有说明镜头职责。
- 单人镜头缺 `companion_visibility`。
- 过早使用特写，关系景不足。
- 切镜被当成重建空间，而不是继承空间。
- 尾帧没有 `tailframe_role`。

## 识别清单

逐镜检查：

- 谁在画面内，谁在画外，谁已出画。
- 被裁掉的人是否有前景、边缘、画外方位或出画解释。
- 视线对象是否命名，而不是只写左右。
- 门、桌、车、队列等空间锚点是否持续存在。
- 轴线是否被无理由翻转。
- 最后一个主镜头是否能作为下一段首帧。

## 竖屏空间策略

9:16 要更主动保空间：

- 双人压迫优先半身关系景。
- 门口和电梯用门框做纵向边界。
- 桌边用桌缘、前景肩线和道具位置守轴。
- 群体调度保留左右可移动空间。
- 特写只在有新信息时短暂出现。

不要把“竖屏适合脸”误解成“空间可以不要”。

## 最小修复顺序

1. 补 `continuity_anchor`：站位、轴线、门/桌/道具状态。
2. 补 `companion_visibility`：另一人如何存在或为何离开。
3. 把无信息大头降为胸口以上中近景、半身中景或关系景。
4. 给切镜补 `cut_reason`：动作、视线、信息、空间或权力变化。
5. 补 `tailframe_role`：下一段继承什么空间状态。
6. 若轴线已翻转，优先补同侧视线和前景关系；无法补时才最小调整镜头角度。

## 场景锚点模板

门口：

```text
人物 A 在门内左侧，人物 B 在门外右侧；门半开，主要轴线沿门内外对峙。
```

电梯：

```text
人物 A 已在电梯内靠左，人物 B 从将合未合的门缝进入；门继续合拢。
```

桌边：

```text
人物 A 坐在桌近侧，人物 B 站在桌对面；文件在桌面中线偏 B 一侧，视线沿桌面对峙。
```

## 修复示例

问题：

```yaml
S02: 女主脸部特写，看向画面左侧。
```

最小修复：

```yaml
S02: 女主胸口以上中近景，桌缘仍在画面下方。
coverage_role: impact_reaction
cut_reason: 男主说出信息炸点后切到受击反应
companion_visibility: 男主在画外右侧，女主视线越过桌面看向他
state_delta: 女主身体仍坐在桌近侧，位置不变
```

## 不要这样修

- 不要新增与剧本无关的人物移动来解释空间。
- 不要把所有镜头重排。
- 不要用“情绪压迫”解释缺失空间。
- 不要让局部特写承担场景建立。
- 不要在普通对话里无理由越轴。

## 通过标准

修复后，即使只读字段，也能知道每个人在哪、看向谁、门或桌处于什么状态，以及下一镜如何继承这些事实。
