# 失败模式：Prompt 过于抽象

## 定义

最终 Prompt 使用“悲伤、愤怒、压迫感、张力升级、电影感、孤独感、暧昧、命运感”等抽象词承载画面任务，但没有把这些词降维成可见动作、身体状态、表情变化、视线落点、停顿时长或镜头承接方式。

这类失败通常发生在 `prompt_compiler` 把导演意图直接搬进 Seedance Prompt，而没有完成模型可执行翻译。

## 典型表现

- 时间轴写成情绪标签：`她崩溃，气氛压抑，张力拉满。`
- 用导演解释代替画面：`这里体现她退无可退的心理。`
- 用空泛风格词堆叠：`高级感、电影感、强冲击、宿命感。`
- 把反应写成结果：`他被震住了。`
- 用长期大特写替代所有表演：`特写她悲伤的脸，持续 5 秒。`
- 忘记主体景别和机位，只写动作或情绪。

## 风险

- 模型无法稳定生成，因为抽象词没有明确的物理动作。
- 情绪被模型误读成夸张表演、乱切特写或无意义慢推。
- 台词落点没有可见反应承接，导致受击窗口丢失。
- 质检无法判断首尾帧是否可继承。

## hard fail 触发

满足任一条件时判 `fail`：

- 时间轴主要由抽象情绪、导演解释或风格词构成，缺少可见动作。
- 关键剧情点、反转点、受击点后没有任何嘴唇、眼神、手指、肩背、呼吸、停顿等可见反应。
- 每个时间段没有主体+景别+机位/角度/镜头运动中的基本分镜信息。
- 抽象表达导致台词、动作、人物位置或尾帧状态无法执行。

若只是个别形容词残留，但主体、动作、反应、镜头都清楚，可判 `warn`，要求局部替换。

## 归因

默认归因：

- `prompt_compiler`：最终 Prompt 未完成抽象词降维。
- `shot_director`：上游分镜只给“情绪升级、压迫感增强”等抽象调度，没有主体、景别、动作和反应窗口。
- `story_planner`：剧情事件或对白落点缺失，导致下游无法判断谁受击、谁反应。

归因时优先找最早缺失的可执行信息；如果上游已给清楚动作而最终 Prompt 写抽象，归因给 `prompt_compiler`。

## 最小返修建议

返修时不要要求“整体更具体”。要指定替换方式：

- 把“压迫感拉满”替换为“乔熙肩膀收紧，后背贴近门框，视线避开商北琛 0.8 秒”。
- 把“他震惊”替换为“商北琛嘴唇停住，下颌微收，手指停在文件边缘”。
- 把“气氛凝固”替换为“两人都不说话，镜头固定在双人半身关系景 1 秒”。
- 把“更电影化”替换为“台词落点后短切到听者胸部以上中近景，再回到双人关系景收尾”。

## 修复模板

```yaml
status: fail
target_agent: prompt_compiler
failed_rule_id: PROMPT-VISIBLE-BODY-LANGUAGE-001
evidence: "3.0-5.0 秒只写“压迫感升级”，没有可见动作或表情承接。"
required_repair: "把该句替换为可见身体反应：乔熙嘴唇停住、肩膀收紧、视线从商北琛脸上移开，停 0.8 秒后再回到对方。"
```

## 自检问题

- 这句话能不能直接拍出来？
- 画面里谁在动，动了什么部位？
- 观众能从哪个表情、动作或停顿看出情绪变化？
- 镜头是中景、中近景、关系景还是短特写？
- 这段结束后，尾帧还能被下一段继承吗？
