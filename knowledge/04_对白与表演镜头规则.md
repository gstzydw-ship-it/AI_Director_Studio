# 04_对白与表演镜头规则
日期：2026-04-07  
用途：用于约束对白场景、表演镜头、信息炸点分配、面部特写写法、完整发言单元的承载方式。

主分镜/子分镜的定义与切换规则见 03 号文件，本文件不重复定义，只描述对白戏中的专属策略。

---

## 一、总原则
对白戏不是“台词说明”，而是“镜头内完成的戏剧动作”。  
输出时必须把**谁在说、说到哪一句、说这句时在做什么、对方如何承接、信息炸点落在哪个镜头里**写进分镜 prompt 本体，不得把台词和动作拆成两个层级。

一句话要求：  
**台词必须嵌入分镜内部，并与动作、停顿、表情、受击反应合写；完整发言单元优先保持完整；主分镜负责承载完整动作段，子分镜负责承接内部镜头重音。**

---

## 二、对白写入规则

### 规则 01：台词必须嵌入分镜 prompt
所有参与叙事推进的台词，必须直接写入对应分镜 prompt。  
禁止写法：
- 先写镜头动作，再在分镜外补台词
- 把台词单独放在括号说明里
- 只写“人物在解释 / 在争辩 / 在反驳”，不写具体台词内容

### 规则 02：台词不能与动作分开
对白镜头必须把台词、动作、口型、停顿、视线、表情写在同一个分镜句子里。  
正确写法：
- 女孩A急着解释，双手在身前比划，说：“我朋友就是跟我开玩笑……”
- 女孩A说到“是不是偷偷怀孕”时动作顿住，手势悬在半空
- 徐斯礼盯着时知渺，嘴唇一字一顿说出“时、知、渺”

### 规则 03：完整发言单元优先保持完整
当同一人物在同一动作段内持续发言，且这段话仍属于一个完整意思单元时，应优先将其视为一个**完整发言单元**。  
完整发言单元的判断条件：
1. 同一人物持续发言
2. 说话目标没有改变
3. 戏剧任务没有改变
4. 身体动作仍属于同一连续行为
5. 场面关系没有被新的动作打断

### 规则 04：完整发言单元不得机械拆碎
完整发言单元可以在**同一个主分镜内部**切子分镜，但不应被拆成多个互不相连的平级主分镜条目，更不应因片段边界而从中间断开。  
正确逻辑：
- 允许同主分镜内切近
- 允许同主分镜内切受击者
- 允许画外补句
- 但整段发言仍是同一戏剧动作的连续表达

### 规则 05：连续台词可在同一主分镜内部切子分镜
连续台词若需要强调信息点、口型、情绪变化或叙事重音，可以在**同一个主分镜条目内部**进行子分镜切换。  
允许使用的连接方式：
- 子分镜 2.1 / 2.2 / 2.3
- 镜头切至……
- 硬切至……
- 转到……
- 带到……

示例：
- 主分镜 2：女孩A胸部以上近景起说“小姐姐，我们特别无辜”，子分镜 2.1 保持中近景，子分镜 2.2 硬切至面部特写，她继续说“我朋友问我前几天还有小肚子，今天怎么没有了，是不是偷偷怀孕”。

### 规则 06：信息炸点必须落到具体台词片段
对白中出现高冲击信息时，必须写清**炸点落在哪句台词上**。  
正确写法：
- 说到“偷偷怀孕”时手势停在半空
- 画外补到“又偷偷流产”时，时知渺睫毛颤一下
- 说出“她已经知道了”时，对方下颌线绷住

### 规则 07：高冲击台词不得只由说话者单镜头承载
当对白包含冲击性信息时，不得只让说话者把整句信息完整说完而不给受击者镜头。  
必须优先考虑：
1. 说话者起句
2. 炸点命中时切受击者
3. 必要时再回到说话者补完尾句

### 规则 07.1：【强制执行】画外音（L-cut）句间切镜法
当人物说出一句较长的挑衅、揭晓或质问台词（如半句引子+后半句重点，或超过2秒长句）时，**禁止用单一镜头让说话者平铺直叙地把话完整说完**。
必须在前半句说完时（或即将说完时），使用“子分镜”切向受击者，让后半句的爆发砸在听者脸上！具体写法：
- **前半句（开口引子）**：画面为【说话者全脸】或过肩，交代开口状态和起势。
- **后半句（压迫落点）**：画面硬切至【受击者反应特写（CU/ECU）】。此时让说话者还没说完的后半段话，以 **（画外音/OS）** 的形式在受击者的脸侧继续播放。
- **作用**：台词不断而画面先切，能营造深度的听觉空间压抑感，极大提升该句落点的杀伤力。

### 规则 08：双重炸点必须拆落点，不可糊成一团
如“怀孕 + 流产”“背叛 + 怀孕”这类双重炸点，应拆成两次落点。  
要求：
- 第一炸点先命中
- 给受击者第一次反应
- 第二炸点再补入
- 形成递进受击，而非信息堆叠

## 三、对白镜头的主分镜 / 子分镜分工

### 规则 09：主分镜优先服务完整动作段
对白戏中的主分镜，优先承载：
- 一个完整解释段
- 一个完整压迫段
- 一个完整命名段
- 一个完整受击段

主分镜回答的是：
- 这一段戏的动作功能是什么
- 这段话是解释、逼问、命名还是受击
- 这一段的主体是谁

### 规则 10：子分镜只服务内部表演与重音
对白戏中的子分镜，优先承载：
- 说话者句中信息炸点
- 受击者即时反应
- 面部特写表演重音
- 局部动作与道具落点

不得把每一个句中重音都抬升为新的主分镜。

### 规则 11：对白镜头不能只有站桩正反打
对白场景不得长期依赖机械正反打。  
要根据戏剧任务决定：
- 谁当前掌握主动
- 谁在施压
- 谁在试探
- 谁是信息受击者
- 谁需要被看见表演细节

---

## 四、面部特写写法

### 规则 12：面部特写必须细写脸部表演
凡镜头为面部特写，必须细写人物可拍摄、可见的面部表情。  
不得只写抽象情绪词，例如：
- 震惊
- 难过
- 复杂
- 冷淡
- 克制
- 停住

### 规则 13：面部特写必须写到可见层级
优先写：
- 眼神落点与是否躲闪
- 眼睑 / 睫毛 / 眼眶变化
- 嘴角 / 嘴唇 / 张口 / 闭口 / 停顿
- 下颌线收紧或发僵
- 吞咽
- 呼吸停顿或发紧
- 鼻翼轻张
- 面部肌肉的绷紧、松动、短暂失控

### 规则 14：信息炸点打在脸上时，子分镜要交付表情落点
若一条台词的叙事任务是“击中对方”，则应优先考虑用子分镜切到受击者面部特写。  
特写必须把“脸上发生了什么”写出来，而不是只写“她很震惊”。

---


### 规则 15：关键动作后补表情锚点
不仅面部特写要细写脸部表演。凡关键动作、羞辱点、反转点、信息炸点与受击点，分镜句子中都应尽量补写可见的面部或身体反应。
普通关键动作后，尽量补一个表情锚点；信息炸点、羞辱点、反转点后，必须补一个受击表情锚点。
优先写：
- 眼神定住或躲闪
- 睫毛僵住、轻颤、停顿
- 嘴唇压紧、发白、张开又收住
- 下颌线绷紧或收住
- 吞咽、呼吸卡顿、鼻翼轻张

### 规则 16：避免空泛情绪词替代表情
对白镜头不得只写“震惊、难过、复杂、压抑、冷淡、克制”这类抽象词。
必须尽量把情绪转成镜头可见的表情和生理反应。

## 五、对白分镜标准骨架

### 骨架 A：连续解释型对白
主分镜 2：人物A中近景起说“前半句”；子分镜 2.1 承载解释起句，子分镜 2.2 切至面部特写继续说“后半句”；子分镜 2.3 切人物B反应特写承接关键词；必要时人物A画外补完尾句；人物B动作落点完成。

### 骨架 B：冲击信息型对白
主分镜 3：人物A起句交代背景；子分镜 3.1 在炸点命中时切受击者；必要时画外继续补句；子分镜 3.2 让受击者用表情或动作完成内化。

### 骨架 C：压迫命名型对白
主分镜 4：人物A先抬眼锁定对象；子分镜 4.1 切至更近的面部；一字一顿说出名字 / 指控 / 命令；子分镜 4.2 让受击者延迟接收。

---

## 六、禁止事项
1. 禁止把连续台词按每两秒切成多个独立主分镜
2. 禁止台词写在镜头外说明区
3. 禁止只写“解释、控诉、辩解、发怒”而不写实际台词
4. 禁止高冲击台词只给说话者，不给受击者
5. 禁止面部特写只写抽象情绪，不写脸部细节
6. 禁止把完整发言单元拆碎后分摊到多个主分镜 / 多个片段
7. 禁止把子分镜层面的景别变化误当成新的戏剧动作段

---

## 七、一句话总纲
**对白必须嵌入分镜内部并与动作、停顿、表情、受击反应合写；完整发言单元优先保持完整并由主分镜承载；句中信息炸点、受击反应与表情重音由子分镜承接。**
