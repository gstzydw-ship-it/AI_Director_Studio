# 任务开发日志：节奏总控导演与视频知识提取集成
**日期：** 2026-04-16
**目标：** 将编剧思维与视听法则嵌入大模型控制管线，并解决本地巨量视频转常驻知识库的技术路径。

## 1. 节奏总控导演 (Rhythm & Rewrite Director) 节点集成
* **架构升级**：在原有的 5 步工作流最前端，插入了全新的 `rhythm_rewrite_director` 节点，使流水线升级为 6 步。
* **职能明确**：该节点不决定机位，专门负责增强画面动作细节以及生成 `atmosphere_strategy` 氛围指导，在不修改台词的基础上向镜头发起调控。
* **规则库建立**：全面编写与定稿了 `09_节奏总控与剧本改写规则.md`，划定了“不篡改台词、不臆造人物、只增补动作细节”的边界。
* **全量测试结果**：通过执行 `test_full_pipeline.py` 测试了从“节奏改写 -> 场景分许 -> 拆片规划 -> 分镜分配”的全链路。结果证明下游的镜头导演（Shot Director）可以完美继承上游的氛围建议。

## 2. L-cut (画外音/OS) 高级运镜法则注入
为了解决传统大模型“一句话一镜头”、“面对长对白只会站桩输出”的局限，向知识库写入了强制 L-cut 设计要求：
* 更新了 `04_对白与表演镜头规则.md`：要求在遇到包含前半句引子与后半句重音的指控/揭晓对白时，必须中途切向受击者的面部，使用“画外音(Voice-Over)”砸下半句。
* 更新了 `09_节奏总控与剧本改写规则.md`：要求节奏导演遇到长对白时，必须主动在 `atmosphere_strategy` 中向镜头导演提出明确的“画外音切入点”建议。

## 3. 全量视频知识智能提取工具 (Video Learner)
* **技术突破**：修复了代理端的 Base64 大 JSON 发送超时与 `RemoteDisconnected` 问题，并将专属路线指定为 `gemini-3.1-flash-lite-preview` 支持极速视频原片直传解析。
* **落地成果**：编写了具备重试、容错与断点续传能力的批量挂机脚本 `tools/batch_video_learner.py`。
* **当前状态**：该脚本目前正在后台异步扫描解析 `E:\学习合集` 目录下的 48 个实战微短剧导演视频（总计 300+MB），提取的金牌规则正源源不断地写入追加到全局汇总库 `knowledge/23_视频教学提取_全场景分镜与转场库.md` 中。
